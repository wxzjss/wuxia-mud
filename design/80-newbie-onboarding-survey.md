## 二、「现在该干什么」今天由谁在传

### 2.1 一共有 5 条通路，其中 4 条要玩家自己先想到

| 通路 | 位置 | 要不要点 | 开局状态 |
|------|------|---------|---------|
| A. 大框 `.story-todo`（ui.js:281，写死「▸ 现在做什么：」） | `#story-box` 内 | 不用点 | **不出现**（story 为空） |
| B. 右栏「当前任务」那一行 | `#scene-quests`（ui.js:657-669） | 不用点（但点一下跳任务面板） | 出现，一行 |
| C. 指令输入框 placeholder | `#cmd-input` | 不用点，但**要读** | 出现，一句 |
| D. 快捷条「帮助」 | `#quickbar` | 1 次点击 | 出现，按钮 |
| E. 侧栏「指令帮助」 | `#sidebar` | 1 次点击 | 出现（≤820px 时侧栏消失，只剩 D） |

**注意 A**：代码里真的有一行叫「现在做什么」的渲染（`ui.js:281`），
数据源是 `storybeat.questChapter()` 返回的 `todo`（storybeat.js:257 `todo: stage.desc`）。
**这条通路是通的，只是开局被 `p.track = null` 关掉了。**

### 2.2 上方大框 = 任务追踪屏，此刻是关的

链路（逐跳都核过）：

```
engine.js:281      p.track = null;          ← 开局不追任何任务（主人 2026-10-12 口径）
engine.js:603      track:  p.track || null
engine.js:596-601  story:  syncTrack() 后取 currentStory()
storybeat.js:316   if (!p.track) return null;
ui.js:233          renderStory(v.story || null)
ui.js:290-295      hasBody 为假 → box.classList.add('hidden') + 清空 + room-desc 取消隐藏
```

`syncTrack()`（storybeat.js:287-304）规则③写得很清楚：
`p.track` 是 null = **玩家亲手取消过 → 什么也不做**。
开局走的就是这一条，所以大框**不会自己填上**。

`engine.js:267-280` 那段注释把主人原话记着：
> 「删除新手教程，屏幕上方那个大方框的默认为**没有追踪任何任务会显示的界面**」
> 「初始主线任务回滚到第一个任务是加入一个门派（**默认不追踪**）」

**所以：大框关着，是有意为之，不是 bug。** 这条要在盘点里说清楚，别让下一个人当 bug 修。

### 2.3 右栏「当前任务」那一行，写的是什么

`renderScene()`（ui.js:657-669）给每个进行中任务画一张卡：
`q.name` + `q.stageDesc`。

- `stageDesc` = `questList()` 里 `stage.desc`（engine.js:1110）
- 开局玩家任务簿里**有且只有一条** `q_main_jianghu`（world.js:3517-3529 自动接无 `giver` 的主线）
- 它的第 0 步 desc（60_quests.json:1070）：
  > **「拿引荐信拜入一个门派（茶摊老汉给的那封）」**

**这行字是今天屏幕上唯一的"目标句"。** 三个前提它没说：

1. **玩家身上没有引荐信。** `letter_intro` 只在 `tutorial.handOutLetter()`（tutorial.js:699-720）里发出，
   调用点是 `commands.js:3511` 与 `commands.js:3804`，**都挂在"跟老汉说话"上**。
   全仓 `letter_intro` 的生产者只有这一处（已核：`game/data` 里只有定义，`births` 的 `items` 里没有它）。
   ⇒ 开局那一秒，「当前任务」叫你去拿一件**你还没有、且没人告诉你去哪儿拿**的东西。
2. **没说去哪座山门。** 满世界 13 家势力，目标门派由 `BIRTH_SECT`（tutorial.js:239+）按出身定，
   但那句话只在**老汉把信给你时**才由 NPC 说出（tutorial.js:711）。
3. **没说"引荐信"三个字要怎么变成动作。** 拜师指令 `join` 的帮助在 `helpHtml()`（ui.js:3575）里，要点开。

### 3.2 层级上的两个硬事实

**事实一：唯一不用点的目标提示（右栏「当前任务」），在 ≤1024px 时不存在。**

```
main.css:2062-2063   @media (max-width:1024px) { #scene { display:none } }
main.css:2074-2075   @media (max-width: 820px) { #sidebar { display:none } }
```

- 桌面（≥1025px）：右栏在，目标句看得见。
- 平板（821–1024px）：**右栏没了**，目标句消失；左栏还在。
- 手机（≤820px）：**左右两栏都没了**，只剩顶栏 + 中栏 + 快捷条 + `☰ 菜单`（ui.js:4582，CSS 在 ≤820px 才显形）。
  ⇒ 手机上开局那一屏，**没有任何一行字告诉玩家目标是什么**，
  只有输入框 placeholder 那句「输入 help 查看全部指令」。

**事实二：信息按"系统分类"排，不按"新手此刻需要"排。**

左栏 5 组的分组是「角色 / 行囊 / 江湖 / 世界 / 系统」——这是**数据域**分组。
一个刚落地的人要找的"我该干嘛"，不属于其中任何一组，所以它没有位置。
同理快捷条 11 项（查看四周 / 背包 / 装备 / 武学 / 状态 / 打坐 / 运功疗伤 / 地图 / 飞行 / 任务 / 帮助）
是**动作全集**，不是**下一步**。

## 五、盘点过程中冒出来的、需要有人拍板的分叉（我只陈述，不定）

下面三条是我**没被授权下结论**的，但下一步无论派谁都得先知道：

### 5.1 「默认不追任务」与「不知道该干啥」是同一件事的两面

- `p.track = null`（engine.js:281）是主人 2026-10-12 **亲口**定下的口径，不是 bug。
- 但这个 null 同时关掉了唯一的 `.story-todo`「现在做什么：」渲染通路（§2.2）。
- ⇒ 「大框默认为空」和「玩家不知道该干啥」是**一个开关的两端**。
  这不是我能判的：要动它就得回到主人那条口径上重新问一次。

### 5.2 「引荐信」的目标句与物品发放是**脱节的**

- 目标句（60_quests.json:1070）开局就让玩家「拿引荐信拜入一个门派」。
- 信的唯一生产者是 `talk 卖茶的老汉`（tutorial.js:699-720）。
- 从"看见目标句"到"知道要去跟老汉说话"之间，**今天没有任何一行字**。

⇒ 这是**链路断口**还是**有意留白**，我判不了：
design/72:394 明写挪缸手动件要「替代现在"点一下交谈就拿信"」——
也就是说设计上是打算**换掉**这个"点一下就拿"的，但换的东西没做（§4.2）。
**现在是"旧的没拆、新的没装"的中间态**，还是"就打算这样"，得主人定。

### 5.3 三处注释与现实不符（不影响功能，但会误导下一个人）

| 位置 | 注释说 | 实际 |

## 六、一句话总结（给下一步派活用）

> 今天的新手引导 = **一张只演一次的出身卡** + **一行藏在右栏的目标句** + **输入框里一句"输入 help"**。
> 曾经撑住这一块的四个东西——教程剧情、右侧指引块、教程面板、`挪缸`手动件——
> 剧情与 UI 是 2026-10-12 **按主人口径主动删的**，手动件是**从没做**。
> 系统仍在后台记录十种引导标记（§4.3），**一个都不显示**。
> 目标句指向的引荐信，玩家开局**身上没有**，且**没人告诉他去哪儿拿**（§5.2）。

**这份盘点能支撑的两个派活方向（供裁决，不是我的建议）：**
- 若"引导讲什么"没定 → 先派**游有方**：`楔子末段要不要落到老汉`、`挪缸` 那一件还要不要、`docdata` 那三处错话改不改。
- 若"讲什么"已在设计里（design/72 §T-A / design/74 辰时）→ 派**寇豆码**：那是一条**从没落地的实现**，不是修复。
