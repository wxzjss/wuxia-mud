## §1 门派性别门槛核对（主人第一问）

**核了一遍，5 家里有 2 家是错的。**

| 门派 | 原来 | 核对后 | 依据 |
|---|---|---|---|
| 少林派 | 只收男 | **保留** | 寺院，武僧皆男 |
| 峨眉派 | 只收女 | **保留** | 郭襄所创的尼庵女派，门中皆女 |
| 古墓派 | 只收女 | **保留** | 林朝英一脉，本就只有女子 |
| 华山派 | ~~只收男~~ | **去掉** | **岳灵珊就是华山女弟子** |
| 恒山派 | ~~只收女~~ | **去掉** | **令狐冲这个男的就接了恒山掌门** |

改完之后只有三类门派按规矩限性别：**和尚庙 / 尼庵女派 / 只有女子的隐世门派**。
其余的设了都是拦玩家的假门槛 —— 恒山改成「悟性 ≥ 12」（尼庵重悟性、要背药方），门槛还在，只是不限男女。

## §2 触发式支线剧情（`data/89_stories.json` + `core/encounter.js`）

12 段剧情，玩家**路过匹配的房间**时按概率撞上（0.10~0.22，一次一辈子只撞一次）：

| id | 场景 | 匹配的房间名 | 内核 |
|---|---|---|---|
| `s_cliff` | 失足坠崖 | 崖 / 绝壁 / 峰顶 | 攀住老藤时，崖上的人喊的是**别人的名字** |
| `s_cave` | 山洞 | 山洞 / 岩洞 | 灶是凉的，壁上刻着个名字，草铺上的旧衫叠得整齐，人没回来 |
| `s_statue` | 无名石像 | 石像 / 祠 / 庙 | 像没有脸。老汉说刻的人学问不高 |
| `s_chase` | 有人追杀 | 道 / 路 / 巷 / 林 | 追的人先开口：「这是我妹子，家里的事」——那女子连喊都不敢喊 |
| `s_runaway` | 千金偷跑 | 巷 / 街 / 桥 / 墙根 | 她不是来闹的，只想站远些看一眼是哪家的姑娘 |
| `s_loiter` | 鬼祟的人 | 衙 / 府 / 牢 | 他在数更鼓，怀里揣着个油纸包，往通牢房的侧门去了 |
| `s_angry` | 满脸愤愤 | 街 / 市 / 门口 | 地契上的名字换了，笔迹还是他爹的——「我爹死了七年」 |
| `s_revenge` | 想报仇的人 | 道 / 庙 / 亭 | 练了十年，仇人去年冬天咳死了。「那我这十年算什么」 |
| `s_jailbreak` | 密谋劫狱 | 牢 / 更楼 / 巷 | 「他是我兄弟，他是冤枉的」——另一个声音说卷宗里他确实动了刀 |
| `s_famine` | 逃荒的人 | 官道 / 城门 / 渡口 | 妇人把最后半块饼掰了三次，第三次手停住了 |
| `s_grave` | 年年添土 | 墓 / 坟 / 岗 | 无名坟，土是新的。「那年翻船，他把我推上来的」 |
| `s_arena` | 比武招亲 | 擂台 / 校场 | 台后帘子动了一下又不动了。「肯不肯的，规矩就是规矩」 |

写这些字的时候盯的是**具体处境**，不是情绪：地契、更鼓、油纸包、锅底的黑垢、
叠整齐的旧衫、掰了三次的饼。主人要的「古代真实情况」就是这些 ——
卖地契不认人、牢里等初七、逃荒的队伍把锅翻过来当凳子。悲剧不在于谁死了，在于**这事没法办**。

## §3 路遇提示（有故事的人）

**310 个 NPC 身上挂着支线**，但玩家不知道谁是谁。现在路过时先给一句：

> 岳不群坐在角落里，茶已经凉了也没让人换。你进去的时候，他的视线在你身上停了一瞬，随即挪开。

写法：**按性格挑句式**（九种性格各一句），不重复用画像原文 ——
画像那几句是留给「细看此人」的，两处重复读第二遍就没味道了。

分寸：
- 一进屋**最多一条**（二十号人各来一句，玩家只会把字全刷过去）
- **同一个人只说一次**
- 优先挑层级高、好感高的（那些人身上的事更值得追）

## §4 顺手修掉的两个静错

1. 🔴 **`spawnNpc` 不 clone `quests` / `sidequest`** ——
   房间里拿到的人身上根本没这两个字段，`hasStory(npc)` 会恒为 false，
   路遇提示**一个都不会出**，且不报错。改成同时看实例与模板（`npc.def.quests`）。
2. 🔴 **顶层数组键被合并器吃掉** —— 剧情库第一版顶层写的是 `{"stories": [...]}`，
   `stories` 不在 `collections` 名单里 ⇒ **整个键被静默跳过**，12 段剧情一段都加载不到。
   包一层 `{"storybook": {...}}` 才好。

## §5 测试

`tools/smoke-stories.js`（**40 项全绿**）：门派性别核对（含岳灵珊 / 令狐冲两条原著反例）、
剧情库完整性（主人点名的 8 类场景逐一断言存在）、触发行为（概率 / 一次性 / 房间匹配 / 不误触发）、
路遇提示（实例与模板都判得出、九种性格各有句式、一次一条、同人不重复）、
端到端（真走一圈，故事与钩子都从 `movePlayerTo` 的 `extra` 通道出来）。
另有两条**文案质量断言**：不能出现 AI 腔（命运的齿轮 / 这一刻 / 不禁），
必须有具体器物（鞋 / 锅 / 纸 / 饼 / 锄 / 剑鞘 / 更鼓 / 地契 / 袖）。

全量回归 **72 套**全绿。
