## 3. 六大工程 · 总纲

### SPRINT-A 地图重做（地基，先做）

**为什么第一个做**：地图是玩家每次打开都要看的东西，现在最丑、最挤、最没有「江湖感」。
而且地图坐标是 `maplayout.js` 运行时算的，改布局不动任何数据文件，风险低、收益立刻可见。

**实测病灶**：

```
bounds: 33 × 73 格（620 格，每格 1 房间，零重叠 —— 但零重叠≠好看）
jiangnan 区域：184 房间塞进 15×19 = 285 格
洛阳 53 / 长安 50 / 成都 49 / 襄阳 45 —— 四座城各占 9×9 一小块
少林 7 间 = 3×5 十五格 → 空 8 格
```

**区域名缺失**：`50_map.json` 的 `regions` 只定义了 12 个（衙门府/青溪村/白鹿书院/醉春楼/
皇城/东市/田野/江口码头/洛阳城/长安城/成都府/襄阳城），但房间实际用了 **31 个 region tag**。
剩下 19 个（jiangnan / huashan / shaolin / wudang / emei / gusu / wild…）在
`packRegions()` 里 fallback 成英文 id —— **玩家看到的是「huashan」不是「华山」**。

**目标（主人钦定）**：

| 要求 | 现状 | 目标 |
|---|---|---|
| 两级地图 | ❌ 只有一张连续图 | 世界舆图（全国轮廓，33×73 → 压缩显示）+ 区域舆图（当前区域，默认展开） |
| 格子/区域名/城市名放大 | ❌ 11px 小字 | 区域名 ≥16px、城市名 ≥14px、格子 ≥44px（触屏可点） |
| 区域面积均衡 | ❌ 15×19 到 3×4 不等 | 按房间数动态定边长，最小 10×10 |
| 普通区域 ≥100 格 | ❌ 少林 15 格 | 野外/山林/道路区补足到 ≥100 格 |
| NPC 房屋不连片 | ❌ `meta.homeRooms` 42 间自由散布 | 聚落内房屋按村/坊成组，组间留街 |

**落地方式**：
- `maplayout.js` 加 `layoutWorld()`：把 31 个 region 按「州府 → 城 → 野外」三级归组，
  城与城之间拉出官道走廊，区域之间留 2 格空白带。
- `50_map.json` 的 `regions` 补齐到 31 条（每条带 `name` / `color` / `tier` / `desc`）。
- 房量不足的区域**不造假房间**，改用「网格底纸 + 雾区」把面积撑到 100 格（视觉上是有 wilderness 的原野）。
- `ui.js mapHtml()` 拆成 `worldMapHtml()` + `regionMapHtml()`，命令 `舆图` / `城图` 切换，
  区域舆图默认打开（主人钦定）。
- 新增 `tools/map-check.js`：断言 ① 每区域名非英文 ② 房间坐标全部在所属 region box 内
  ③ 无重叠 ④ 区域面积达标 ⑤ 每条出口的邻居坐标距离 = 1 或 合法斜角。

### SPRINT-B 动态世界（让江湖自己动起来）

**规格**：`design/02-world-dynamics-spec.md` 已完整，直接按它的落地顺序做，**不重写规格**。

分三步：

1. **传闻系统** —— `game/data/70_world.json` 顶层 4 键；玩家目击表 → 传闻种子 → 按区域扩散
   + 时间衰减；玩家在酒肆/青楼/镖局打听。**必须可观测**：传闻会改变 NPC 对你的称呼与态度。
2. **随机事件库** —— 4 条扩到 68 条（分类配额照规格 §2.4），需要 `world.js` 新增 4 个 hook：
   `onEnter` / `onKill` / `onTick` / `onLevelUp`（后两个已存在，缺 `onEnter`/`onTalk`）。
3. **势力消长 + 节庆日历** —— 月度 `onFactionTick` 结算，玩家能看见某门派势力涨落、
   节庆期间洛阳城 NPC 换台词、青楼加价、官府加派巡查。

**依赖**：A（事件触发需要区域 id）。**产出**：一个会自己运转的江湖。

### SPRINT-C 主线剧情 + Boss（任务的灵魂）

**为什么紧迫**：主线原来是**坏的**。`q_main_jianghu` 里每一处条件都断：

| 阶段 | 条件 | 原实测状态 | 2026-10-10 修复后 |
|---|---|---|---|
| 2 | `anySkill100` 技能等级 ≥100 | 等级制残留算出的上限只有 87 → **永远 false** | 上限公式改为纯武学维度（悟性×6+资质×9+内功×0.8），裸人 126 ✅ |
| 3 | `defeatLegend` 击杀 6 位 Boss | `onNpcDown` 不记 `killed_*` flag → **永远 false** | 已记 `killed_<defId>` ✅ |
| 4 | `flagsAny: learned_jiuyang...` | `learnSkill` 不设 flag，且 flag 名用简称与真 skillId 对不上 → **永远 false** | 已设 `learned_<真skillId>`，数据改正为 4 门绝学的真 id ✅ |
| 全程 | — | **主线没有委托人**（无 giver，NPC 也没挂它）→ 6 个阶段一个都交不掉 | 挂给冲虚道长 ✅ |
| 5 | Boss 只是 hp 高的普通 NPC | 无专属机制、无巢穴、无三阶段 | 故事书已定规范，机制待实现 ⚠️ |

**这条主线曾经 100% 走不完。2026-10-10 已修复，实测能从 stage0 走到 99**
（`tools/smoke-mainline.js` 47 项断言，含真·交任务全流程）。

**仍未完成**：Boss 只是 hp 4000~7000 的普通 `tag=swordsman`，
没有专属机制、没有专属场景、没有三阶段切招 —— 故事书 §3 已出设计表，代码待写。

**重写方案**（`design/10-mainline-story.md`，已于 2026-10-10 写定）：

五幕结构，**每幕推翻上一幕的认知**：变强→门派也不干净→你练的是假的→敌人不在江湖→赢了然后呢。

| 幕 | 名 | 核心问题 | 幕末转折 | Boss |
|---|---|---|---|---|
| 一 | 初入江湖 | 我为什么要变强？ | 救的人临死塞给你半块东厂铜牌 | 山贼头目（过场） |
| 二 | 门派之疑 | 谁在暗中收集武功？ | 门派内鬼确认 | 方证大师（试探，非仇杀） |
| 三 | 伪秘籍 | 那些秘典是真是假？ | 假秘籍是引你上钩的诱饵 | 血刀老祖、丁春秋 |
| 四 | 黑木之崖 | 主使者是谁？ | 主使者在朝堂，不在江湖 | 东方不败 |
| 五 | 江湖路远 | 我要走到哪一步？ | 名动天下，但江湖还是那个江湖 | 东厂提督（新增·冯保） |

**反派改判**：不设「魔教」当最终反派（当太多次了），改为**朝堂里的东厂提督**——
这样才能跟 SPRINT-D 的制度线咬合，也解释为什么名门正派会找你麻烦。

**Boss 设计规范**（每个 Boss 必备）：
- **专属战斗机制**（不是加血）：血刀老祖「化血」吸内、丁春秋「化功」+ 召弟子、
  东方不败三阶段（绣花针快攻 → 化生反伤 → 弃攻守势）、东厂提督「影卫」分身
- **专属场景**：不在野外随机刷，固定巢穴 + 前后哨卡 + 阶段转换演出
- **三阶段**（100% / 60% / 30% 血量切招），每阶段一句台词
- **不都是反派**：方证大师那一战是「试探」，打赢反而更信任你（总纲「Boss 不都是反派」首处落地）
- **背景故事画像**：每个 Boss 必须有完整 `portrait`（A 层规格），且 `arc` 写清动机与结局

**三结局设计**（第五幕）：交卷 / 拒交 / 半交 —— 三个都不是坏结局，也都不是好结局。
不给「统一了江湖」的假糖（承 §2 铁律）。

**任务数量目标**：主线 5 幕 × 4~6 阶段 = 25 个主线任务节点，替换掉现在这 1 条。

### SPRINT-D 制度线：科考 / 官府 / 九品 / 劫狱 / 参军

这是**把玩家从「江湖草莽」变成「社会人」的阶梯**，也是让 NPC 生态立起来的关键。

1. **科考** —— 每年秋闱，三场（帖经/诗赋/策问）。玩家需有名籍、无恶名（`p.kidnap.wanted` 影响）、
   身份证明（`p.identity`）。落第可复读，可作弊（行贿 `p.kidnap.bribes`），可被举报。
2. **九品人物** —— 散官→从九品上→正九品→…→一品。每一品给实权：调兵、征税、缉拿、
   开仓赈济。**官职越高，能做的事越多，但恶名与民怨的代价越大**（被掳 NPC 里的官方线会被清算）。
3. **官府日常** —— 巡街、断案、缉捕（接 `q_bounty_*`）、征粮、徭役。
4. **劫狱** —— 有势力线的玩家可买通狱卒 / 劫法场，代价是全城通缉 + 门派关系崩。
5. **参军** —— 边关（雁门/阴山）招兵，募兵制，有军功、军籍、抚恤；军功可换兵器装备。
   边关有独立地图 + 独立事件链（狼潮、契丹、军粮亏空）。

### SPRINT-E NPC 生态（把 320 个填满）

- **画像补全**：按 `01-*.md` 的配额表，A 层补到 40（现 11）、B 层 60（现 2）、
  C 层用槽位生成器补满。**`03-*.md` 的 12 例是写作范本，照它的语气写。**
- **生态闭环**：每个 NPC 画像里的 `arc`（人物弧光）要有可玩的触发条件；
  `hooks` 要能生成传闻种子（对接 SPRINT-B）；`feuds` 要真的打起来。
- **九品/官府 NPC**：新增约 60 个（从六品到一品，分布在州府、衙门、皇城），
  带完整画像与官职行为（可被贿赂、可下达任务、可得罪）。
- **妖兽鬼怪**：新增约 40 个（山林/洞穴/古墓），独立战斗机制（不是加血加攻），
  掉落材料进炼丹炼器配方。

### SPRINT-F 玩法外壳

- **功法逐级传承**（主人钦定）：宗门/官府功法逐级解锁，前置功法 + 贡献 + 身份地位 +
  同阶层竞争四重条件。核心是**同门竞争**：每代弟子争一个「真传」名额。
- **奇遇 + 秘境**：68 条事件库（对接 SPRINT-B），秘境 8~12 处（洞天、剑冢、
  藏经窟、魔教黑木崖），秘境有独立地图 + 守门人 + 退出机制。
- **制式装备**：军队/门派/官府各有制式套装，穿戴有加成，可缴获、可打造（对接 `25_craft.json`）。
- **战败求饶**：战败进谈判界面，选项「求饶 / 破财免灾 / 反击 / 逃跑」，
  结果取决于双方 `favor`、玩家恶名、有无护院（对接 SPRINT3-B）。
- **生育继承**：结婚（`marriage.js` 已落地）+ 生育 + 子嗣继承家产/功法/关系网。
