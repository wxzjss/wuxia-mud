## 0. 一句话现状

**底层（武学 + 数据规模）已经成型，中层（生态与剧情）刚搭骨架，上层（地图与制度）基本空白；而「沉浸感」是当下最短板——剧情能跑但没魂，NPC 有画像但世界不记得你。**

620 房间 / 329 NPC / 331 任务（主线仅 2 条）/ 112 物品 / 50 功法，底层跑得动。
但**「江湖」还没有真正活起来**：
- 世界地图是一张挤在 33×73 网格里的密集街区图；
- 传闻/势力/节庆系统只有一份规格书没有一行代码；
- **329 个 NPC 里只有 16 个有画像（A 13 / B 3），且 0 个明确反面形象**（恶霸/酷吏/贪官/奸商/魔头爪牙/背叛者/伪君子一个都没有）；
- **主线能跑通（0→99）但只有 2 条、五幕只落地 2 幕**，五个 Boss 里仅东方不败有机制/巢穴/三阶段，其余 4 个仍是 hp 高的普通 NPC；
- **313 条「支线」绝大多数是自动生成的薄任务（"小叫花请求"型），没有一个是从 NPC 背景故事长出来的**——这正是主人说「目前的剧情很垃圾」的根因。

**当前阶段：从「系统堆叠期」进入「世界塑造期」，并叠加「沉浸感工程」。**
接下来不再横向加孤立系统，而是**把已有的东西连成一张网**，并**优先补上玩家最能直接感受到的三件事：江湖味、真实感、代入感**——
让 NPC 有血有肉、让世界记得你做过什么、让新手一进游戏就被叙事裹着走。

**外部参考（2026-10-10 主人要求搜来对标）**：北大侠客行（pkuxkx）是中文 MUD 的标杆，
其设计印证了咱们「江湖味 / 真实感 / 代入感」的方向，具体可借鉴三点：
- **开场不教操作、用叙事裹人**：侠客行没有「打开背包」式弱智提示，新手在独立新手区被
  「投名状」灰色任务（被裘千丈收买干坏事）和「认亲」情感戏（「大哥，我终于找到你了」）
  直接卷进江湖；先天属性（悟性/福缘/容貌）配好才真正入江湖。**→ 咱们 #110 沉浸开场的方向。**
- **你的所作所为改变世界对你的看法**：侠客行有「道德 / 声望」系统，影响 NPC 态度与任务解锁；
  年龄还会逐年增长气血上限（14 岁出生、14~30 岁每年涨、60 后衰减）。**→ 呼应 #109 传闻 / #108 记仇 /
  `p.reputation`·`p.wanted` 组成的「世界记得你」闭环，数值层面可借鉴「道德驱动态度」。**
- **主线从人物关系长出来、有身份错位与正邪分支**：石破天「替死鬼」身份错位、长乐帮正邪分支、
  赏善罚恶令 / 侠客岛腊八粥 / 太玄经标志性物件、道德抉择决定走向。**→ 咱们五幕「每幕推翻上一幕认知」
  + 反面 NPC 支线「灰色抉择」的叙事母题来源，但细节不抄，只抄手法。**

## 3. 六大工程 · 总纲

### SPRINT-A 地图重做（地基，先做）

**为什么第一个做**：地图是玩家每次打开都要看的东西，现在最丑、最挤、最没有「江湖感」。
而且地图坐标是 `maplayout.js` 运行时算的，改布局不动任何数据文件，风险低、收益立刻可见。

**实测病灶**：

```
bounds: 33 × 73 格（620 格，每格 1 房间，零重叠 —— 但零重叠≠好看）
jiangnan 区域：184 房间塞进 15×19 = 285 格
洛阳 53 / 长安 50 / 成都 49 / 襄阳 45 —— 四座城各占 9×9 一小块
少林 7 间 = 3×5 十五格 → 空 8 格
```

**区域名缺失**：`50_map.json` 的 `regions` 只定义了 12 个（衙门府/青溪村/白鹿书院/醉春楼/
皇城/东市/田野/江口码头/洛阳城/长安城/成都府/襄阳城），但房间实际用了 **31 个 region tag**。
剩下 19 个（jiangnan / huashan / shaolin / wudang / emei / gusu / wild…）在
`packRegions()` 里 fallback 成英文 id —— **玩家看到的是「huashan」不是「华山」**。

**目标（主人钦定）**：

| 要求 | 现状 | 目标 |
|---|---|---|
| 两级地图 | ❌ 只有一张连续图 | 世界舆图（全国轮廓，33×73 → 压缩显示）+ 区域舆图（当前区域，默认展开） |
| 格子/区域名/城市名放大 | ❌ 11px 小字 | 区域名 ≥16px、城市名 ≥14px、格子 ≥44px（触屏可点） |
| 区域面积均衡 | ❌ 15×19 到 3×4 不等 | 按房间数动态定边长，最小 10×10 |
| 普通区域 ≥100 格 | ❌ 少林 15 格 | 野外/山林/道路区补足到 ≥100 格 |
| NPC 房屋不连片 | ❌ `meta.homeRooms` 42 间自由散布 | 聚落内房屋按村/坊成组，组间留街 |

**落地方式**：
- `maplayout.js` 加 `layoutWorld()`：把 31 个 region 按「州府 → 城 → 野外」三级归组，
  城与城之间拉出官道走廊，区域之间留 2 格空白带。
- `50_map.json` 的 `regions` 补齐到 31 条（每条带 `name` / `color` / `tier` / `desc`）。
- 房量不足的区域**不造假房间**，改用「网格底纸 + 雾区」把面积撑到 100 格（视觉上是有 wilderness 的原野）。
- `ui.js mapHtml()` 拆成 `worldMapHtml()` + `regionMapHtml()`，命令 `舆图` / `城图` 切换，
  区域舆图默认打开（主人钦定）。
- 新增 `tools/map-check.js`：断言 ① 每区域名非英文 ② 房间坐标全部在所属 region box 内
  ③ 无重叠 ④ 区域面积达标 ⑤ 每条出口的邻居坐标距离 = 1 或 合法斜角。

### SPRINT-C 主支线剧情 + Boss（任务的灵魂）

#### C-0 本次重构工作流顺序（铁律：先地图 + 画像，后细写剧情）

主人钦定的生产顺序（原话：**「做 NPC 前建议先把地图搞好，然后给每个地图分配一定数量 NPC，
这样写 NPC 背景画像时才不会出错」** + **「画像做好后根据这些画像来重做主支线剧情」**）：

```
① 地图分配（#111 · design/09）   ──→  ② 众生画像（#112 反面形象 / #113 C层批量）
        │                                      │
        └──────────────┬───────────────────────┘
                       ▼
              ③ 细写剧情（#114 主线三~五幕 / #115 支线 / #116 咬合）
```

- **① 地图分配是地基**：先把 31 个 region 的「门派 / 城市 / 野外」定死、把每个区域分配多少 NPC 定死，
  **画像 NPC 的 `def.region` / `def.sect` / 身份 才不会写错区域或写串门派**（历史上画像写错区域是高频 bug）。
- **② 众生画像是剧情原料**：每个有画像的 NPC 的 `portrait`（origin/now/want/fear/secret/feuds）
  **就是支线的剧情种子**——不先有画像，支线就成了无本之木（"目前的剧情很垃圾"根因正是 313 条支线与画像零咬合）。
- **③ 细写剧情必须最后**：**`design/10-mainline-story.md` 的第三~五幕细节、#115 支线数据，
  一律等 ① ② 完成后再动笔**（主人 2026-10-10 明确：「剧情的详细可以先不写，先写好大纲大致走向，
  等之后完成地图分配与众生画像后再动笔细写也不迟」）。五幕**大致走向**见 C-4，细节待补。
- **可并行穿插（不阻塞 ①②③）**：**#108 亲属记仇（已交付）**、**#110 沉浸开场教程**、
  **#109 世界记忆·传闻**——这三项不依赖画像 / 地图，可现在就做，且正好解决主人点名的三个出戏点。

**当前批次进度**：#108 ✅（亲属/至交在场暴怒记仇，33 项测试全绿，已随档留存）→
下一步按主人优先级推 **#110（教程）→ #109（传闻）→ 然后回 ① 地图分配 → ② 众生画像 → ③ 细写剧情**。

**根本目的（主人钦定，高于一切技术目标）**：主线与支线**不是任务清单，是让玩家代入江湖的载体**。
三条不可妥协的设计铁律（落到剧情上）：
1. **江湖味** —— 不用现代词、不写说明文；NPC 说话要有口音、有算计、有黑话；场景描写要「看得见烟火气」。
2. **真实感** —— 你做的事要在这个世界里留下痕迹（杀人有人记仇、行善有人传颂、抉择有人记得），世界不能对你失忆。
3. **代入感** —— 玩家是「无名之辈慢慢长出名字」，不是天选之子；新手一进游戏就被叙事裹着走，而不是被「打开行囊」这种弱智提示打断。

**为什么紧迫**：主线原来是**坏的**。`q_main_jianghu` 里每一处条件都断：

| 阶段 | 条件 | 原实测状态 | 2026-10-10 修复后 |
|---|---|---|---|
| 2 | `anySkill100` 技能等级 ≥100 | 等级制残留算出的上限只有 87 → **永远 false** | 上限公式改为纯武学维度（悟性×6+资质×9+内功×0.8），裸人 126 ✅ |
| 3 | `defeatLegend` 击杀 6 位 Boss | `onNpcDown` 不记 `killed_*` flag → **永远 false** | 已记 `killed_<defId>` ✅ |
| 4 | `flagsAny: learned_jiuyang...` | `learnSkill` 不设 flag，且 flag 名用简称与真 skillId 对不上 → **永远 false** | 已设 `learned_<真skillId>`，数据改正为 4 门绝学的真 id ✅ |
| 全程 | — | **主线没有委托人**（无 giver，NPC 也没挂它）→ 6 个阶段一个都交不掉 | 挂给冲虚道长 ✅ |
| 5 | Boss 只是 hp 高的普通 NPC | 无专属机制、无巢穴、无三阶段 | 故事书已定规范，**东方不败已落地，其余 4 个待写** ⚠️ |

**这条主线曾经 100% 走不完。2026-10-10 已修复，实测能从 stage0 走到 99**
（`tools/smoke-mainline.js` 47 项断言，含真·交任务全流程）。

#### C-1 支线剧情体系（本次重构的新增重点 · 主人的核心诉求）

现状：313 条「支线」绝大多数是自动生成的薄任务（「小叫花请求」型），**没有一个是从 NPC 背景故事长出来的**——这正是「剧情很垃圾」的根因。

**设计原则：每个有画像的 NPC，都按他自己的 `portrait` 长出一条（或多条）专属支线。**
支线不是「去打 10 个怪」，而是「帮他了却一桩心事 / 揭开一个秘密 / 了断一段恩怨」。

- **委托人** = 该 NPC 本人（必须有 `giver`，且 `def.quests` 挂上，否则交不掉——旧主线踩过的坑）。
- **剧情钩子** = `portrait.hooks[]`（画像解锁项），与 `trust` 门槛对齐；好感够了才解锁更深支线。
- **背景来源**：从 `origin`(来历) / `now`(近况) / `want`(所求) / `fear`(所惧) / `secret`(隐秘) / `feuds[]`(仇怨) 里取 1~2 条做主线索。
- **反面 NPC 的支线**（回应主人「没有反面形象吗」）：恶霸的支线是「被你揭发 / 收服 / 反杀」；
  酷吏是「构陷良民，你选择揭发还是同流」；奸商是「以次充好坑你，你报复还是入伙」；
  伪君子是「表面提携你、暗中算计你」——**让玩家在灰色的江湖里做选择，而非非黑即白**。
- **分级落地**：A 层 40 人每人 1 条精写支线（3~5 段，含抉择与代价）；B 层 60 人每人 1 条半模板支线；
  C 层用 `tag×region×gender` 生成「邻里琐事」型短支线（1~2 段），也要有 portrait 底色，不能纯随机。

**与现有 313 条的关系**：保留作「填充」，优先级低于画像支线；画像支线落地后，玩家遇到的每一个有名字的人，都「有血有肉、有求于你或你有所求」。

#### C-2 沉浸式开场 + 无缝衔接主线（解决「弱智教程」出戏点 · #110）

现状：10 步功能教程含「认清家当 / 打开行囊」等弱智引导，靠 `view()` 常驻侧栏触发，**没有叙事**。

**改为**：玩家一进游戏，**弹出沉浸式开场剧情 modal**（不是教程弹窗），一段有江湖味的叙事把玩家「扔」进世界：
- **开篇**：你是个无名之辈，一段旁白 / 遭遇戏（被劫、救人、或撞见一桩秘事）把「为什么要变强」立起来。
- **叙事化引导**：把「学移动 / 对话 / 看属性」揉进剧情动作（「你慌不择路往北逃」→ 教移动；
  「那人咽气前抓住你吐出半句」→ 教查看），**不出现「请打开背包」这种提示**。
- **落点**：开场戏直接把玩家送到第一幕 `q_main_jianghu` 起点，**无缝衔接主线**，没有「教程→游戏」割裂。
- **实现**：前端 `ui.js` 的 `renderGuide` 改为开场 modal + 叙事步骤；后端 `tutorial.js` 状态机改写为叙事脚本。
  专项测试 `tools/smoke-tutorial.js`。

#### C-3 世界记得你（剧情与世界记忆咬合 · 解决「剧情外失忆」出戏点 · #109 / #116）

现状：剧情里你救了人、杀了人、做了抉择，出了剧情所有人态度照旧——最出戏。

**设计**：剧情选择 / 重大行为 → 落到**持久世界状态**，被 NPC 态度、传闻、声望读取：
- 杀人 / 救人 → `#108` 已做亲属记仇；扩展到**全城声望**（`p.reputation` 按门派）+ **通缉**（`p.wanted`）。
- 抉择（如第二幕「禀报 / 按下不提」）→ 落 `choice_made` flag，相关 NPC 日后见你态度不同
  （`pstate.moodBias` / `favor` 随之变）。
- 传闻系统（`#109`，属 SPRINT-B）把你的事迹写成**会走样、会扩散、会衰减**的流言，
  NPC 用流言里的你对你表态（「听说你血洗了 X」可能是真的也可能是走样的）。
- **铁律**：任何剧情节点的 reward / choice，必须同时写「世界状态增量」和「NPC 态度增量」，否则就是「假剧情」。

### SPRINT-D 制度线：科考 / 官府 / 九品 / 劫狱 / 参军

这是**把玩家从「江湖草莽」变成「社会人」的阶梯**，也是让 NPC 生态立起来的关键。

1. **科考** —— 每年秋闱，三场（帖经/诗赋/策问）。玩家需有名籍、无恶名（`p.kidnap.wanted` 影响）、
   身份证明（`p.identity`）。落第可复读，可作弊（行贿 `p.kidnap.bribes`），可被举报。
2. **九品人物** —— 散官→从九品上→正九品→…→一品。每一品给实权：调兵、征税、缉拿、
   开仓赈济。**官职越高，能做的事越多，但恶名与民怨的代价越大**（被掳 NPC 里的官方线会被清算）。
3. **官府日常** —— 巡街、断案、缉捕（接 `q_bounty_*`）、征粮、徭役。
4. **劫狱** —— 有势力线的玩家可买通狱卒 / 劫法场，代价是全城通缉 + 门派关系崩。
5. **参军** —— 边关（雁门/阴山）招兵，募兵制，有军功、军籍、抚恤；军功可换兵器装备。
   边关有独立地图 + 独立事件链（狼潮、契丹、军粮亏空）。
