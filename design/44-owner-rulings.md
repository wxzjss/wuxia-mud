## R2 · 「单独激活 3 本」的判据 = **有没有对应的基础武学**（不是「是不是旁门」）

**主人原话（2026-10-10，纠正本文初稿的误解）**：
> 「可以直接激活的三本是属于**没有基本功法类型的**，像毒术之类的应该有**基本毒术**，
> 医疗类应该有**基本医术**可绑定激活，那种**没有基本武学的只能单独激活三本**」

1. 判据是「**这门武学有没有对应的基础武学**」，**与 `category` 无关**。
2. **有毒术就该有《基本毒术》、有医术就该有《基本医术》** → 这类**照样绑定激活**（同内功绑《基本内功》）。
3. 只有**真没有基础武学**的，才免绑、单独激活；**合计 ≤3 本，跨门类共用一个池子**。
4. ⇒ 基础武学这一层要按门类扩出 `basic_throw 基本暗器` / `basic_poison 基本毒术` / `basic_medicine 基本医术`
   （可能还有 `基本乐律` 等）。
5. 代码形态：角色上一个**数组** `standaloneActive = []`；
   ⚠️ **初稿的 `activeByCategory = {旁门: []}` 作废** —— 那是按类别分池，算不出「合计 3 本」。

> 详见 `design/40` §2（开头有【口径更正】横幅，§2.4 已整节重写）。

## R5 · 势力武学 / 藏经阁三层 / 藏宝阁 / 国库衙门 / 守卫规格

**主人原话（2026-10-10）**：
> 「除了门派武学，还有**各种势力武学**以及**非常多江湖武学**，**朝廷也相当于一流势力**，
> 门派**藏经阁也分三层存储非本门派武学**，**藏宝阁**是与**武器丹药符箓阵法特殊效果宝物天材地果**有关，
> **藏经阁得有一定身份地位才能通过花贡献进**，**皇宫也应该有国库**，**衙门也应该有对应的区域**，
> **不同势力也一样**，像这些地方应该被门内「**扫地僧**」级别的高手把守
> （**一流门派由一流高手把守，二流门派由二流高手把守以此类推**）」

**逐条拆解（待设计落稿）**：

| # | 要求 | 要点 |
|---|---|---|
| R5-1 | **武学的三来源** | ① 门派武学 ② **势力武学**（朝廷/东厂/镖局/帮会/盐帮/商会…非门派势力各有自家武学）③ **非常多「江湖武学」**（无势力归属的散学，靠奇遇/拍卖/藏经阁流通） |
| R5-2 | **朝廷 = 一流势力** | 朝廷按**一流**标准配武学与守卫（即品级 147 那一档）；东厂/锦衣卫等应各有武学 |
| R5-3 | **藏经阁 · 三层** | 存**非本门派武学**（即能在别派藏经阁学到别家武学）；**分三层**（与品级层次对应，如 入门/中阶/绝学）。⚠️ 需定：三层各放什么品级、是否可阅别派秘传 |
| R5-4 | **藏宝阁** | 与 **武器 / 丹药 / 符箓 / 阵法 / 特殊效果宝物 / 天材地果** 有关（即非武学类的藏品） |
| R5-5 | **藏经阁的进入门槛** | **要「一定身份地位」+ 花「贡献」**才能进（贡献 = 门派贡献 `sectContribution`？威望？需定） |
| R5-6 | **皇宫有国库** | 皇宫里要有「国库」区域（财货重地） |
| R5-7 | **衙门有对应区域** | 衙门也要有对应的库房/区域 |
| R5-8 | **不同势力一样** | 上述「重地 + 守卫」的规格**对所有势力通用**（不只门派） |
| R5-9 | **守卫规格 = 扫地僧** | 这些重地要有**扫地僧级别**的高手坐镇：**一流势力 → 一流高手把守，二流 → 二流，以此类推** |

> **落点提示（给设计）**：现有 `design/09` 已有 region 分区与房间规模口径，可直接用来新增「藏经阁三层/藏宝阁/国库/库房」的房间；
> 守卫可直接复用现有 `hostile` + `bossPhases` + 门派 `tier` 体系（`design/40` §5 正在定 tier）。
> ⚠️ 注意本项目既有语义：`hostile` 是**模板常驻标记**，不要拿它当「能不能打」的排除条件。
