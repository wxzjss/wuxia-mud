## 1 Mod 隐藏溯源 ID：防「下载 → 改两笔 → 当自己的发」

### 主人原话
> 「给每个 mod 发布成功时增加隐藏 id 并将该 ID 的 mod 记在 mod 发布者名下（发布时检测是否已有隐藏 ID，
>  且该隐藏 ID 的 mod 原始发布者是否是当前发布者）；防止有人下载（下载的 mod 本身自带隐藏 ID）别人的 mod
>  到自己这然后导入后（会把看不见的隐藏 ID 自动填写进去）修改一下当自己的发布上去（官方示例 mod 更是如此）」

### 机制
1. **发布时**分配一个隐藏 ID（`_wxTrace`，形如 `wxt-3f9a…`），写进站点保存的 `mod.json`
   —— 于是**下载回来的人拿到的文件天生带着它**。
2. 站点索引记下 `trace → { owner, name }`（**原始发布者**）。
3. **制作器导入时留住它**（`blankSpec` 里登记了 `_wxTrace`，界面不显示、也不进游戏世界数据）。
   再发布时服务端认这个 ID：
   - 查无此人 / 全新作品 → 发一个新的；
   - 指向**别人**（含官方示例）→ **拒绝**，并**点名**说出这是谁的作品。
4. **官方示例单独一档**：`mods/demo_*/mod.json` 各带一个固定 ID（`wxt-official-demo_npc` 之类），
   播种时归属记为 `@official`（与任何玩家账号都不同名）⇒ **谁都发不了**。

### 两个容易踩的点
- 🔴 **`jsonToSpec` 只拷 `blankSpec` 里已有的键**。隐藏 ID 不登记进 `blankSpec` 的话，
  **导入一次就被抹掉**，整套机制等于白做（`specToJson` 也要显式带出去）。
- 🔴 **下载时也要补 ID**：发布机制上线**之前**的那批记录身上没有这行，
  不补的话它们等于没被保护（`withTrace()`）。
- 边界说明：它挡的是「顺手拿来当自己的」；挡不住铁了心手工删字段的人（前端不可信）。
  真正的底线在服务端：**署名与归属由服务端写死**，前端说破天不作数。

### 测试
`tools/smoke-mod-trace.js`（**24 项**）：发布发 ID → 下载自带 → 别人换 ID 也发不上去（且点名）→
本人更新放行且 ID 不变 → 全新作品各发各的 → 官方示例谁都改不了 → 制作器导入导出不弄丢。

## 3 青楼「接客」接真实客人

### 主人原话
> 「青楼『接客』抓取附近单身异性 npc（根据 npc 设定来）接真实的客人（然后该 npc 身上的钱会真实花掉一些，
>  增加双方好感且下次遇到该 npc 时屏幕上会显示该 npc 看到你后的调侃语气语言表情动作等表现）」

### 改之前
客人是**六条写死的模板**（赶考举子 / 茶商 / 军汉 / 老秀才 / 年轻东家 / 两个行商），
跟楼里站着谁毫无关系 —— 屋里空无一人，照样「接」进来一位。

### 改之后
从**本屋 + 相邻一间**挑一个合乎规矩的活人：
`是个人（兽不算）· 异性 · 单身 · 没倒地 · 不是铺子老板 · 不是自家跟班 · 不是他自己的师父 · 不是楼里人`。

挑到了就接**真客**：
- **他身上的钱真花掉**（出得起多少赏多少，钱是从他口袋里出的，不是凭空印的）；
  兜里干净的照接，白陪一场但**人情记下**（好感涨得更多）。
- **两边好感真涨**；
- **这桩事记在他身上**（`npc.pstate.brothelMet`）。

台词按**路数**分院写：官面上的人 / 武人 / 商人 / 读书人 / 出家人 / 寻常人，每路三场。
挑不到人，才退回原来那六位过路的 —— 楼里没客人的夜里总得有过路的，不让玩法空转。

### 下次碰面
`npcMemory.greetLines` 的候选里加了一条 `brothelLine`（排在传闻前面 ——
那是一件**具体发生过的**事，比外头嚼的舌根近）。按性格分九档说话：

> 豪爽：「哟，这不是那晚那位？」话没说完自己先摆手，「罢了罢了，我不提。」
> 温婉：一见是你，脸先红了，把头低下去，手里的帕子攥紧了些。
> 侠义：干咳一声，正色道：「那日之事，只当没有过。」说完自己先别开了眼。

**同一人三天之内只说一回**（与 `heardLine` 同一套克制，不然他每转个身都要打趣你一次）。

### 踩到的两个坑
- 🔴 **判据别用 `def.teach` 当「教拳的」**：`77_npc_skills` 给**几乎每个** NPC 都配了功法，
  一挡就是全场 —— 第一版挑客永远返回 null，测试里表现为「接的还是模板客人」。
- 🔴 **函数写在本文件里，却 `require` 了别的模块**：`brothelLine` 定义在 `npcMemory.js`，
  调用却写成 `require('./work').brothelLine` ⇒ 那道候选**永远是 null**（`work` 上没这个名字），
  表现为「接完客下次见面一点反应都没有」。

### 测试
`tools/smoke-brothel-guest.js`（**28 项**）：挑客规矩六条 / 钱真花掉 / 好感真涨 / 事迹真记 /
下次真能打趣且三天不重复 / 没来过的人不会说这种话 / 台词按路数不重样。

> ⚠️ 断言口径：验「他说的正是那桩事」**不能拿「有没有『那晚』这种词」**——
> 温婉/怯懦那几档本来就写得含蓄（脸红、低头、走开），词面根本不提那件事。
> 判据落在**「这句确实出自专用台词池」**。
