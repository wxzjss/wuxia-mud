## 0. 本稿的三个解读约定

**① 五种行式，一眼分清"元信息"与"正文"：**

| 行式 | 含义 | 落地时对应 |
|---|---|---|
| `【场 3-x】…` + `▸ 房间` `▸ NPC` `▸ 前置` | **元信息**（不是玩家看到的字） | action 的 `cmd` / `cond` |
| `　　◆旁白：` | 玩家读到的旁白 | `{type:'narrate', raw:'…'}` |
| `　　◆「…」` | 玩家读到的台词（说话人写在名字里） | `{type:'say', raw:'…'}` |
| `　　〔选项〕` | 玩家读到的菜单选项文本 | `menu` 的选项 label |
| `　　▪战斗` / `　　▪落点` | 战斗触发 / flag 落点（元信息） | `combat` / `flag` |

**② 语感三条纪律**（沿用楔子）：
1. **具体压过形容**——不写"神秘的""危机四伏的"，写"锁口新得反常""秤砣擦得比货还干净"。
2. **不解释机制**——不出现"用某指令查看""本场可获得某物品"这类话；获得就是"他把东西塞进你手里"。
3. **不出现现代词**——无「系统/属性/任务/数值/触发/刷新」等。

**③ 楔子已定的四个硬约束（本稿照旧）**：
无失忆表述 · 不剧透"第一幕之前"的铜牌来源（本幕出现的铜牌是**二幕已在玩家身上**的那半块）· 不出现指令名 · 舞台与真实房间一致。

> **【设计说明 · 非正文 · 别给玩家看】**
> - **两路都拿铜牌**（设计如此）：`jiuye_fought` 与 `jiuye_stood_aside` **两路二选一必落一个**；`jiuye_done` / `know_east_depot` / 铜牌 / 接二幕 (`q_main_sect 0`) **两路完全相同**。
>   即：**这是"留下哪一道痕"，不是"拿不拿得到"。**
> - **`jiuye_stood_aside` 不是惩罚**：本场两路**没有任何数值差**（不加也不减 `karma`/`rep`/`favor`、不掉物），差别只在**世界记不记得你站在旁边** ——
>   第四幕 4-2 东方不败、第五幕 5-4 黄药师各有一句读它（正文见本稿 **场 4-2（第 1010–1014 行）**、**场 5-4（第 1420 行）**，**上一批已写，本批未动**；行号按本场自查时文件 1747 行的位置）。
> - **不剧透口径**：本场是**铜牌在全剧第一次出现**；通篇**不点"东厂"二字**，只给"公文 / 车上的人 / 半块硬东西"。
> - **胜负兜底**：动手打输也照§2.9.2「⑥ 无论胜负」拿铜牌（那人是趁乱脱身，不是靠你打赢），**不掉档、不结算失败**。

　　◆「看什么。镖车不写货单，不接搭脚的。」

　　〔选项一〕**（不提那面旗，只问她往北走哪条道）**

　　◆「……不问旗，倒是个懂规矩的。」

　　◆「我这趟也往北。你要跟，就跟半程——到山口我们分道。」

　　▪落点：`yue_zhi_road`

　　〔选项二〕**（那面旗，是华山的吧）**

　　◆旁白：她把旗捏皱了。

　　◆「谁跟你说的。」

　　◆「那旗是我借的。借了二十年。」

　　◆「头一趟镖，我车上插着它，道上没人敢劫。后来我早不靠华山了——旗还挂在车上。我没摘。」

　　◆「你去说啊。说乐知的镖是借华山的名头走稳的。」

　　◆旁白：她跳上车，抖了一下缰绳。骡子走了。走出十几步，一袋钱从车上落下来，砸在你脚边。

　　◆「拿着。当是我买你个不说。」

　　▪落点：`npv180_broken` · `+money 300`

## 附 C · 写文案时发现的"细纲 vs 文案"对不上的地方（照实列）

> 以下都是我落笔时撞到的真问题，**不是挑刺**——请 team-lead 定夺后我再回填 `design/21`。

**C-1（需改细纲标注）「3-0 行前场」其实只有三处是行前，第四处是"在路上"。**
`npcv_248` 俞初 的常驻房间是 `road_xixia_1`（西夏官道），**不在江南**。所以 3-0 的四处在空间上分两批：
江南三处（东市 / 醉春楼 / 果子摊）＝真·行前；西夏那处＝**去西域的路上**（3-6 之前随时可去）。
`design/21` §3.2 把 3-0 统称"行前场"不准确。**建议改称「四处人情（三处在江南，一处在西夏官道）」。**
本稿已按实际位置写元信息。

**C-2（实现方式与细纲不同）三处"堕落分支"的触发方式，我按"本地可完成"重写了。**
`design/21` 写的 break 动作是「说给毛清」（毛清在 `gusu_yanzi` 姑苏）、「告诉梅拾」（在 `jn_brothel_hall`）、
「把丢镖的事抖出去」（对谁抖？没写）。这些在**行前这一步**都要多跑一趟地图，对可选场太重。
本稿改为**触人物的忌讳**（画像 `voice.taboo`）就地触发：
- 乐知 → 提"那面旗是华山的"（触 `taboo: 借旗`）
- 陈语冰 → 把纸拿给楼下的梅拾（`jn_brothel_room` 的 `s` 就是 `jn_brothel_hall`，**同一步楼内，不用跑图**）
- 阮听 → 问他的箱子（触 `taboo`）
- 俞初 → 提常拂（触 `taboo`）
**效果等价（`*_broken` + 现钱/恶名 + 断线），但触发点搬到了本地。** 若工程要按细纲原文实现"说给毛清"，需要额外在 `gusu_yanzi` 加 action——**我不建议**（可选场不值得）。

**C-3（细纲漏洞）`beijiang_houzhai` 的"以抄本换"要求玩家"先摸寨再谈判"，但细纲没写清顺序。**
`design/21` §3.3 场 3-3 的选项二写"需 `flag:'xuedao_copy'`"，而 `xuedao_copy` 来自场 3-4（后寨）。
可 3-4 的 `cond` 是 `pass_shankou`——**也就是玩家可以在见刀主之前先绕去后寨**。
本稿把这个顺序**写成两条都通**（3-4 的元信息标注"可在 3-3 之前或之后"），并在 3-3 选项二前标注"需先拿到"。
**建议在 `design/21` §3.3 补一句顺序说明**（否则工程会按"3-3 → 3-4"的固定顺序实现，选项二永远出不来）。

### D-1 唯一未通过项：3-0-B 的「着呢」（**引擎误报，我建议保留原文**）

- **引擎原文**：`"redundancy": { "passed": false, "metric": 0.135, "threshold": 0.32, "redundant_pairs": ["着呢"] }`
- **根因**：引擎的 `_REDUNDANT_PAIRS` 把 `着的 / 着呢 / 的了 / 是在 …` 当作"虚词连缀（疑似笔误）"。
  但本场的「着呢」来自 **`npcv_252` 陈语冰 画像里写定的 `voice.catchphrase`：**
  > 「姐姐教我认的字，我都记着呢。」
  这是**白话里正当的句末语气词**（表持续状态），**不是笔误**。
- **两难**：team-lead 的写作要求写死了「有画像的 NPC **必须用其 `voice.catchphrase`**」，而引擎的冗余检测是**面向旁白的代理指标**，它把台词一起算了。
- **我的处置：保留画像原句**，理由是**人物语声优先级高于一个会被台词误伤的代理指标**——这跟上一轮「句号断句」那次不同：那次改的是**标点**、且改后读起来更对；这次若改，是**改人物的话**，代价是让"陈语冰"少了一点她自己的腔调。
- **【显式豁免记录 · release 前勿改】主理人已裁定：保留「着呢」，不得以"过审"为由修改。**
  > **豁免条目**：`design/24` 场 3-0-B，命中项 `redundancy.redundant_pairs = ["着呢"]`。
  > **判定**：**误报**。该短语是 `npcv_252` 陈语冰画像里**写定的 `voice.catchphrase`**（「姐姐教我认的字，我都记着呢。」），
  > 属白话里正当的句末语气词；引擎的 `redundancy` 检测是**面向旁白的代理指标**，它把台词一并算了。
  > **处置**：**刻意保留。保人物语声，不保单一指标绿灯。** 一个把台词当旁白判的指标，不该有权力改人物的嘴。
  > **若将来有人跑审校看到此报错 —— 这就是有意为之。不要"修"它。** 要动，须先改画像的 catchphrase，而不是改文案。

## 附 G · 三结局尾声的"三个不同的模具"（回应 B16 的教训）

## 附 I · 新发现的细纲差异（**照实列，未默默改**）

**C-7｜4-6 的冯保台词需要读两个 flag（细纲没写）。** 本稿给 4-6 写了两版台词：
