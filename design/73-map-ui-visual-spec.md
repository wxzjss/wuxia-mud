## 〇、先说三件已经查实的硬事实（决定后面所有取值）

1. **房间全名的长度分布（实测 312 间房）**：最长 **9 码点**（`江口码头·货栈后街`），8 码点 15 个，7 码点 47 个，6 码点 104 个，5 码点 99 个 —— **96.8% 在 7 码点以内**；**249 / 312 带「·」**。
   ⇒ 「不砍字」是可以算出来的，不是靠愿望：**格子放大到 52px + 在「·」处断行 + 最多 3 行，100% 放得下**（算法见 §3.9）。
2. **默认主题是暗色**（`--paper: #17140f` 夜墨），浅色在 `html.theme-light`。主人 2026-10-11 明确要求过「把游戏内的白色背景全变成黑色」。
   ⇒ **任何"宣纸白"方案都直接违反主人已定的裁决**，本方案不做亮纸。
3. **`--ink` 是字色不是底色**（暗色下 `--ink: #e4ded1` 近白）。实心底另有 `--solid`。本方案**零处**把 `--ink` 当底用。

另（**2026-10-12 更正**：此条初稿写错，已按三份快照核对改正，见 §5.3）：两份前端副本**在三个时间点上都一致**，不存在遗留漂移。我初稿观察到的差异是主程序做 P0 途中的瞬时状态，不是历史缺陷。落地时仍需按 §5.3 的规矩同步，但**没有"历史 bug 要先修"这回事**。

## 一、风格定义

### 1.1 气质语言：**「墨拓残卷」——夜灯下摊开的一张褐纸**

一句话：**地图不是新材质，是把游戏里那张纸「局部提亮一档、压上帘纹、洇上墨迹」。**

四条可执行规则（这就是全部视觉语言，不需要图）：

| # | 规则 | 落到 CSS / SVG |
|---|---|---|
| **G1** | **纸分三档明度**：卷没摊开（最暗）＜ 摊开了没写字（中）＜ 写过字（最亮）。**「去过」= 那片纸被墨洇亮了**，不是"涂了个颜色" | `--map-void` / `--map-paper` / `--map-paper-lit` 三个变量，加一层 `mask-image` 径向羽化做边界 |
| **G2** | **纸有帘纹，无网格**。帘纹 = 宣纸的竹帘压痕：横向一道细密、纵向一道稀疏。**间距固定 7px，永远不等于格距** | 两层 `repeating-linear-gradient`，透明度 ≤ .05 |
| **G3** | **写在纸上的只有墨与朱**：墨（暖白→淡墨四阶）写地名与路，朱（朱砂）只盖印，金只镶边与提"我" | 全表见 §四 |
| **G4** | **去色仍可读**：已探索 = **有字**，未探索 = **无字只有空心圈**，完全未知 = **连圈都没有**。形状与文字承担区分，颜色只是加成 | `.mn-seal` / `.mn-ring` / 空 DOM |

### 1.2 为什么是「墨拓残卷」，而不是另外三种

| 候选 | 判定 | 理由 |
|---|---|---|
| **宣纸（白）** | ✗ | 直接违反主人 2026-10-11「把游戏内白色背景全变成黑色」。且一张亮纸贴在夜墨页面上，眼睛要重新适应，读日志会刺眼 |
| **绢帛** | ✗ | 绢的辨识点是**织纹**（经纬高频交叉）。CSS 只能用 repeating-gradient 模拟，两种频率交叉**必然出摩尔纹**，在 2x 屏上是满屏脏波纹。做不出来就别定 |
| **羊皮** | ✗ | 气质错位。羊皮是地中海/欧洲抄本的材质，跟"江湖""州域""里数"不是一套符号系统。且羊皮要靠不规则边缘与斑驳污渍表达，程序化画出来就是"脏" |
| **墨拓** | ✅ | ① **语义天然对齐**：拓片是"人到了那儿、把碑拓下来才有"—— 与「地图 = 你去过的地方的私人笔记」是同一件事；② **明暗可控**：拓本是深底浅字，与夜墨主题同向，不打架；③ **零资源**：纯色 + 两层渐变 + 一道内阴影就能立住，不引一张图、不引一个字体文件 |

**「残卷」两个字的意思**：地图**不画边框整齐的矩形面板**。画布四边用 1px 实线 + `inset 0 1px 0 rgba(255,255,255,.04)` 内高光模拟纸的厚度，四角 `border-radius: 3px`（比面板的 6/7px 小，像纸不像卡片）。

### 1.3 字体层级（不引入任何字体文件）

沿用项目既有两栈，不新增：

| 用途 | 字体栈 | 说明 |
|---|---|---|
| 地名、州域名、出口牌、朱印上的字 | `var(--font)`（Noto Serif SC / Songti SC / SimSun… 系统衬线） | 全项目已有，**地图不另起一套** |
| 里数、耗时、计数、"未去过"这类说明字 | `var(--font-ui)`（PingFang SC / 微软雅黑…） | 数字与说明用无衬线，与地名拉开 |

字阶（桌面基准，窄屏见 §五）：

| 层级 | 字号 | 字重 | 字距 |
|---|---|---|---|
| L4 州域名 | 15px | 400 | **.22em**（大字疏排，这是"远处的淡字"唯一能被认出来的办法） |
| L1 当前房间名 | 12px | **700** | .02em |
| L2 走过的房间名 | 11px | 400 | -.1px |
| 出口牌地名 | 13px | **600** | .04em |
| 出口牌里数/耗时 | 12px | 400 | 0 |
| 悬停浮层全名 | 14px | 600 | .02em |
| 悬停浮层痕迹句 | 12.5px | 400 | 0（行高 1.7） |

### 1.4 一条总纲（地图与整体 UI 共用，一句话）

> **只有「我」配朱与金。其余一律墨阶（`--ink-1` … `--ink-4`）。**

这条一句话就能让日志区、任务面板、侧边栏、快捷栏、地图长在同一套气质上。朱红 = 「我在这里 / 这是我的」，金 = 「与我相关的边框与提亮」，其余全部是墨的四阶。地图不例外。

## 三、逐元件规格

### 3.1 L1–L4 四层规格（权重顺序照 §M.5.1，不改）

| 层 | 内容 | 形状 | 字 | 底色 | 连线 |
|---|---|---|---|---|---|
| **L1** 我在这里 | 当前房间 | **朱砂实心圆角方印**（边长 = .58 × 格距，最小 16px），金环 1.5px，外柔光 4px，印心阴刻「我」 | 全名，**金色 700**，12px | `--map-paper-lit` + 淡金足迹底 | — |
| **L2** 我从哪来 | 走过的格子 + 走过的路 | 无框，只有字（+ 上/下层的 ▲▼ 角标保留） | 全名，**浓墨 `--map-ink-known`**，11px，400 | `--map-paper-lit` | **实线**，金褐，2.2px |
| **L3** 我附近有什么 | 当前房间的直接邻居（没去过也算） | **空心圈**（直径 = .34 × 格距），描边 1.4px，无填充 | **不显示名字**（硬约束，剧透） | `--map-paper` | 虚线，极淡，1.4px |
| **L4** 远处与边界 | 州域名、州域边界、出口方向 | 无形状 | 大字淡墨，15px，字距 .22em | `--map-void`（连帘纹都淡掉） | 边界一道 `.10` 虚线 |

**L1 与 L2 的区分是三重的，不是一重的**：

1. **形状**：L1 有一枚实心方块，L2 什么形状都没有
2. **字重**：L1 = 700，L2 = 400
3. **色相**：L1 金 `#cfa64a`，L2 墨白 `#ded6c2`

去色（灰度）下 ①② 仍然成立 —— 这是「颜色不得成为唯一信息载体」的达标方式。

### 3.2 已探索 vs 未探索：**留白 + 边缘羽化**（不用云纹，不用淡墨，不用羊皮）

选 **留白**，理由：

- **云纹**：是"画上去的装饰"，它表达的是"这里有东西但被挡住了"。而未探索表达的是"**这里什么都没有，因为你没去过**"。语义反了。
- **淡墨**：淡墨仍然"画了东西"，玩家会以为那里有内容只是看不清，会去点、会去猜。而且淡墨与 L2 的浓墨是同一色相的两档，色觉差异下极易混。
- **羊皮遮盖**：气质不对（见 §1.2），且需要一个"遮盖物"图形，等于又画了一张图。
- **留白**：**未探索 = 纸本身褪回页面底色，连帘纹都淡掉**。它诚实地表达"这半张卷还没摊开"，而且**实现成本最低**（一个 `mask-image` 羽化层），不引入任何新图形。

参数：

| 项 | 值 | 说明 |
|---|---|---|
| 羽化层 | `.map-veil`，`position:absolute; inset:0; z-index:1; pointer-events:none` | 压在纸纹之上、地块（z=2）之下 |
| 遮罩 | `mask-image: radial-gradient(120% 120% at var(--map-lit-x) var(--map-lit-y), transparent 0, transparent calc(100% - var(--map-edge-soft)), #000 100%)` | `--map-lit-x/y` 由 JS 按"已探索格子的重心"算出，写在 `.map-canvas` 内联 |
| 羽化宽度 | `--map-edge-soft: 22px`（窄屏 18px） | 太窄像硬边（像黑块），太宽像没铺开 |
| 三档纸底 | `--map-void` → `--map-paper` → `--map-paper-lit` | 明度差每档约 6–9%，靠"洇开"的感觉，不靠跳变 |

**第二重编码（不依赖颜色）**：已探索 = 有字；未探索邻居 = 只有空心圈；完全未知 = 连圈都没有。灰度截图下三档仍可数出来。

### 3.3 当前房间的标记形态：**朱砂方印**（不是点 / 圈 / 旗标）

| 候选 | 判定 | 理由 |
|---|---|---|
| 点 | ✗ | 太小，压不住满屏墨字；而且"点"在图上是通用符号，不带"我"的意思 |
| 圈 | ✗ | **与 L3 的空心圈直接撞形**，玩家会分不清"这是我"还是"这是能去没去过" |
| 旗标 | ✗ | 旗标是**地图符号**（军用/探险地图），太"图"了，是"画在地图上的东西"，不是"写在纸上的记号" |
| **朱印** | ✅ | 印是**人在纸上留下的动作**，与「私人笔记」完全同构 —— 我到过这儿，我盖了个章。且实心 + 有环 + 有阴刻字，三重信息量，任何背景上都压得住 |

印的规格：

```
边长  = max(16px, 0.58 × 格距)      桌面 52px 格 → 30px；窄屏 60px 格 → 35px
圆角  = 2px                          （方印，不是圆章）
底色  = var(--map-here-fill)    #b8493c   朱砂，压暗一档为了托住白字
环    = 1.5px solid var(--map-here-ring)  rgba(207,166,74,.88)  金环
柔光  = 0 0 6px 2px var(--map-here-glow)  rgba(184,73,60,.26)
印心  = 「我」字，var(--map-here-ink) #f7f1e4，字重 700，字号 = 0.52 × 印边长
降级  格距 < 24px 时：印退化为「朱色实心圆 + 金环」，去掉「我」字（保证形状仍在）
```

> ⚠️ 关于主人的偏好：2026-10-12 主人把"你在这里"从**红字**改成了**黄字**。本方案**保留黄字**（`--map-here-name: var(--gold)`），只是**给这行字底下加了一枚朱印**。所以不是推翻主人的决定，是给它加了个托底 —— 原来只有字色一重区分，现在有三重。

### 3.4 州域出口标签：**单行三段式，不用图标字体**

内容固定为「方向 + 地名 + 里数 + 耗时」，样例：`向西 → 洛阳，四百八十里，步行九日`

| 段 | 内容 | 字号 / 字重 | 色 | 字距 |
|---|---|---|---|---|
| ① 方向 | `向西` | 12.5px / 400 | `--map-ink-far-2` | .08em |
| ② 箭头 | `→` | 12.5px / 400 | `--map-ink-far-2` | — |
| ③ 地名 | `洛阳` | **13px / 600** | `--ink-1` | .04em |
| ④ 里数 | `四百八十里` | 12px / 400 | `--ink-3` | 0 |
| ⑤ 耗时 | `步行九日` | 12px / 400 | `--ink-3` | 0 |
| ⑥ 变体（有才显示） | `骑马四日 / 走漕船六日` | 11.5px / 400 | `--ink-4` | 0 |

- **分段符**：中文逗号「，」，**不用竖线**（竖线是 UI 分隔符号，出现在句子里会破江湖味）。
- **箭头**：**不用 `→` 字符**。字符箭头在不同字体下基线歪、宽度不一致，跟格子对不齐。改用 **SVG 短箭**（`viewBox 0 0 16 8`，一条 1.2px 横线 + 2px 三角头，色取 `--map-ink-far-2`），尺寸 16×8，随段①同行居中。
  - 兜底：若实现方不愿加 SVG，用 CSS 三角形（`border` 拼）也可以，**不许**用字符。
- **字重规则**：只有地名给 600。**700 只留给 L1**，全界面不许第二处出现 700 的地名。
- **位置**：贴在画布**内侧边缘、朝那个方向的那一侧**，距边 12px；同一个方向有多个出口时纵向顺排，间距 6px。**不浮在画布中间**。
- **板感**：`--map-tag-bg` 底 + `--map-tag-line` 1px 边 + `border-radius: 4px` + `padding: 4px 9px` + 背景 `backdrop-filter: blur(2px)`（可选，压住底下的连线）。
- **对比度**：地名 ≥ 7:1，④ ⑤ ≥ 4.5:1，① ② ≥ 3:1。

### 3.5 悬停浮层：**一张补记纸条**

```
┌────────────────────────────┐
│▌江南城·长街                 │   ← 全名，14px / 600 / --ink-1，可换行，最多 3 行，不截断
│▌你在这儿跟卖馄饨的吵过一架。 │   ← 痕迹句，12.5px / 400 / --ink-3，行高 1.7，最多 2 行
│▌一层 · 走过 4 次            │   ← 元信息，11px / 400 / --ink-4（可选行）
└────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 容器 | `.map-tip`，`position: fixed`（跟随指针，不被画布 `overflow` 裁掉） |
| 底 | `--map-tip-bg` `#322b21`（比纸亮一档，比弹窗 `#241f18` 也亮一档 —— 纸条是"压在最上面的一小片"） |
| 边 | 1px `var(--map-tag-line)`（金褐），`border-radius: 4px`（比面板小一号，像撕下来的） |
| 左侧朱条 | `border-left: 2px solid var(--red)` —— 「这是我的记录」的标记，与朱印同源 |
| 最大宽 | 桌面 260px / 窄屏 `min(72vw, 260px)` |
| 内距 | 8px 11px |
| 阴影 | `0 4px 16px rgba(0,0,0,.45)` |
| 层级 | `z-index: 60`（高于 `.map-tools` 的 12 与 `.map-node.here` 的 5） |
| **出现** | **无延迟**，`opacity 0→1` + `translateY(3px)→0`，**120ms `ease-out`** |
| **消失** | 90ms `ease-in`，`opacity 1→0`，不做位移 |
| **不做** | 弹跳、缩放、旋转、模糊淡入。动效时长与缓动曲线交动画总监复核，**上限 160ms** |
| 定位 | 优先在格子正上方 8px；顶部空间不足翻到下方；左右贴边时 clamp 在视口内 8px |
| **未走过的格子** | 只显示第一行，内容 `未去过`（相邻则 `往北，未走过`）；**无痕迹行、无房间名** |
| **触控** | 移动端没有 hover：**长按 380ms** 等同悬停；浮层出现后**固定在格子上方 44px 不动**（不跟手指走，否则被手指挡住）；点空白处消失 |

> 数据依赖：痕迹句来自 `room.marks`（§附一.B「房间三段式 + `marks`」已在 P1 需求里）。**该字段落地前，第二行不渲染**，浮层退化成两行（全名 + 元信息），不留空行、不显示「暂无」。

### 3.6 「回到我」按钮：**四角准星 + 朱印心**

```
    ┌        ┐
     │   ●   │      ● = 朱砂实心方印的缩小版（边长 = 0.42 × 按钮边长，圆角 1px）
     │       │      四角 = 1.2px 淡墨直角括号，边长 = 0.28 × 按钮边长
    └        ┘
```

| 项 | 规格 | 理由 |
|---|---|---|

### 3.7 移动端窄屏断点与字号阶梯

**先修一个一致性 bug**：地图的窄屏判定是 **JS 读 `innerWidth`（阈值 640）**，而 CSS 断点是 **560 / 820**。两者不同源 —— 在 600px 宽的窗口里，CSS 已经切到窄屏样式、JS 还在走桌面分支（或反之）。

|---|---|---|---|---|---|---|---|
| **XS** | `< 380px` | **66px** | **13.5px** | 38px | 11.5 / 12 | `min(78vw, 240px)` | **48×48** |

### 3.9 「不许砍字」的可执行算法（这是硬约束的落点）

```
输入：全名 s（码点数 n），格距 C，可用宽 W = C × 0.92，基准字号 F
1. 断点：在「·」处插入 <wbr>（249/312 的房间名有「·」，断在这里最通顺：
   「江南城·长街」→「江南城 / 长街」，而不是「江南城·长 / 街」）
2. 试 1 行：n × F ≤ W                     → 用 1 行
3. 试 2 行：ceil(n/2) × F ≤ W             → 用 2 行
4. 否则 3 行：ceil(n/3) × F ≤ W           → 用 3 行
5. 三行都放不下（理论上不会）→ **不降字号**，改把该格的 width 放宽到
   ceil(n/3) × F / 0.92 并让它压过邻格（overflow visible），
   宁可这一格大一点也不许截字
6. 字号地板：F 随 z 缩放，但 **clamp 下限 10px**，永不再降
```

实测验算（`--map-cell: 52px`，`W = 47.8`，`F = 11px`）：

| 码点 | 行数 | 每行最宽 | 判定 | 房间数 |
|---|---|---|---|---|
| ≤4 | 1 | 44px | ✅ | 46 |
| 5–6 | 2 | 33px | ✅ | 203 |
| 7–8 | 2 | 44px | ✅ | 62 |
| 9 | 3（或 `·` 处断成 4+4 两行） | 44px | ✅ | 1 |

**312 / 312 全覆盖，零截断。** 现存的 `MAP_NAME_MAX = 4` 与 `mapLabel()`（取「·」后那段的砍刀）**整段删除** —— 它是「江南城·长街 → 长街」的直接元凶。
