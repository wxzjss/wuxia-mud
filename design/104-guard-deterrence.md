# 104 · 门禁威慑：戒备态、报号嗤笑与声望门槛（游有方，2026-10-14）

> 主人令：门禁威慑的台词与数值配套（引擎侧同步在修）。三件：
> ①硬闯成功后守卫**戒备态**的拦截台词（认识你、记恨你）；
> ②无名小卒报号**被嗤笑**的拒绝台词；
> ③声望门槛 **50** 与现有声望梯度的复核。
> 本文给 guards.js（design/71 §四）配套的文案与数值，台词口径照 43 家守卫
> 129 句的白描腔：短句、有实物、不解释情绪。

## 一、戒备态（硬闯打赢之后，门里记得你）

### 裁 1 · 判据：不新造 flag，读现有声望

`onGuardBeaten`（guards.js:241）硬闯打赢已写 `reputation[门派名] −30`（floor −100）。
**戒备态判据就用它**：`reputation[sd.name] ≤ −20`。

- 为什么不用新 flag：声望值天然随「再闯再记仇」加深、随「为本门做事」回升
  （89 §七·补二 裁 2：恢复靠做事，不靠花钱消）——戒备态自动有解法，
  不用另写解除逻辑；
- 为什么是 −20 不是 −30：留出「做一桩本门差事（+rep 典型 10–25）就能明显松动」
  的余地。**调参区间 −20～−30**：想更记仇取 −30（一次硬闯即刻戒备，解戒要
  两三桩差事），取 −20 则一桩大差事（+25）就能翻篇。默认 **−20**。

### 裁 2 · 戒备态改变什么（数值）

| 项 | 常态 | 戒备态 |
|---|---|---|
| 开场白 | OPEN.threshold/referral 三选一 | **OPEN.grudge**（下节台词），优先级排在门槛、恶名之前——守卫先认仇人，再谈规矩 |
| 报上名号 | 可选 | **不给**（名号在这里已经臭了，报了只会加羞辱） |
| 塞钱打点 | `wanted×20` 文 | **拒收**：「他掂都没掂，把银子推回来」——记恨不是钱能买的（89 裁 2 同源）。若主人想留缝，备选 ×3 价，**默认拒收** |
| 硬闯 | 现行（3 倍血擒下 / 起战斗） | 现行不动；打赢再记账（onGuardBeaten 每次 −30，floor −100，天然累加） |
| 冷却 | 一炷香 90 分钟 | **减半（45 分钟）**——记恨的人盯你更紧 |

### 裁 3 · 戒备态拦截台词（OPEN.grudge，三句轮换）

判据触发时的开场白，先认人、再记恨、不啰嗦：

1. `${n}老远就认出了你，手已经搭上刀柄：「好胆。上回门里那一架，忘了？」`
2. `${n}往路心一站，家伙没出鞘，眼神先到了：「门里传过你的话。再来一回，就不是拦了。」`
3. `${n}没看你，只朝身后呶了呶嘴，角门里已经有人小跑着进去报信。半晌，他转回头：「门里说了，不见你。」`

⚠️ **甲案终裁后的处置（2026-10-18 落地记档）**：戒备态实现为守卫 **hostile 起手**
（`gateBreach_<sectId>` flag 随档持久化，拔刀就上、不问话，台词由战斗句库 ambush
通路出）。上面三句**不启用，留档备件**——若日后主人要「拔刀前撂一句」，从这三句
里取，机制口不变。

## 二、报上名号的三档脸面（stateName 改口径）

现行 stateName：门槛不达 → 拒；恶名 ≥50 → 招打手；其余 → 放行。
**「其余」那档太宽**——刚下山的白身报个名号，守卫也侧身让路，威慑不起来。
改成**三档**，判据按顺序走：

### 档 0 · 门槛不达标 → 现行不动

「名号记下了，可你这样的，X不收。」——这句本来就写得好，不动。

### 档 1 · 恶名 ≥50 → 现行不动

「省得我找。」山门里涌出人影——不动。

### 档 2 · 声望 ≥50（守卫听过你）→ 放行，给脸面

判据（**落地记档，键口径改裁**）：`max(reputation[sd.id], reputation['*']) ≥ 50`
——寇豆码保底实现取**门派键与全江湖键的较高者**，**采纳**：名头是跨门流动的
东西，全江湖响当当的人到哪家山门都该被认出（比武扬名走本门键、文化项目走
`*`，两路攒的名头在这里汇合，正合「来源要有画面」的裁 3）。

台词（润色终稿）：`你报上名号。${g.name}眯眼看了你两息，忽然一抱拳：「原来是您。门里提过您的事。」侧身让开。`
sys 行保留现行：「你进了${sd.name}的山门。要拜师，就在此处『拜师 ${sd.name}』。」

### 档 3 · 声望 <50（无名小卒）→ 嗤笑**拒绝**（甲案终裁，2026-10-14 改判）

> 主人原话：「没声望为什么放我进去」——本意就是不放行。乙案「嗤笑仍放行」
> 违背本意，**作废**；甲案转正。改判记录：lead 2026-10-14 终裁。

台词（**B33 保底润色终稿，2026-10-18**——保底版「没听过。X的门，还轮不到报个名号
就进」骨架不动，收束句换成攒名声的出路）：

1. `你报上名号。${g.name}把这两个字嚼了嚼，嗤了一声：「没听过。」他往门心一站，「名字没人提过，门就没人让。」`
2. （备选）`你报上名号。${g.name}上下打量你两眼，嗤笑一声：「没听过。名号是干出来的，不是报出来的。等你的名字有人提了，再来叩门。」`

hint（保底版微调，机械措辞在 hint 层是优点，保留）：
`（声望到了 50、或进了门派、或揣着引荐信，再报不迟；要不就「硬闯」。）`

跟一条 sys 提示（口径同 repGainOnQuest 的现行数字提示，不算浮字）：

`（${sd.name}上下还没人说起过你（声望 ${rep}/50）。名字是做出来的：为本门办差、擂台扬名，都会有人念叨。）`

choices 相应收窄：**不给报上名号的后续、不给打点**（没钱可打的生人 + 无名
小卒不是一个价），只留 **「我来拜师」（豁免口，见下）／硬闯进去／转身离开**。

### 豁免双通道（防死锁，甲案必配）

档 3 拒绝后不锁死，两条正路都在 choices 里写着：

1. **「我来拜师」**：点它 → 守卫验门派门槛（`blockedBy`，与 joinSect 同一套）——
   门槛过 → 放行至拜师流程（sys：`守卫侧身让开半步，下巴朝门里一点：「拜师的去正堂，别处少逛。」`——纯文案盯人，不做移动锁）；
   门槛不过 → 回门槛那句拒绝话（「名号记下了，可你这样的，X不收」），通路照旧死不。
   入没入门仍由门派规矩管，守卫只管通传——与 design/71 §四「判据复用 joinSect」
   的纪律一致，不另起第二套判定。
2. **引荐信／门派身份照旧**：`isInsider`（同门 / `tutPass` 引荐信）在 maybeBar
   最上游放行，本件不碰——新手线那封信继续管第一个门。

死锁分析（改判后复查）：新玩家在山门外可走「我来拜师」豁免 → 进门拜师 →
接本门差事 → 声望攒上 50 → 下回来报号有脸面。链路闭合，无死锁；
代价是拜师比旧版多点一次，换来的是守卫这个角色的威慑立住了。

## 三、声望门槛 50 复核（按现行产出量级对表）

### 全库声望产出实测（2026-10-14）

| 来源 | 落点键 | 单次量级 |
|---|---|---|
| 效果级 `+rep`（任务/支线 rewards，全库 60+ 处） | 朝廷为主，丐帮/镖行/武林/`*` 少量 | **8–40，典型 15–25** |
| 比武扬名（commands.js:3104） | 本门键 | +10 + rank×10（20–60+） |
| 文化项目（culture.js） | `*` | +3 上下（小步） |
| repGainOnQuest（quest 级新口径，卷三起新案） | 各势力键 | 同效果级，10–25 |
| 硬闯记仇（guards.js） | 门派键 | −30/次 |
| 擂台入场门槛（culture.js:268，`minRep`） | `*` | 门槛 20 |
| 官府恶名线（patrol/guards） | 恶名键 | 20 盘查 / 50 招打手 |

### 结论：50 这个数，**配**——前提是键口径读对

- 报号门槛读 **`reputation[sd.name]`（该门派/势力自己的键）**，不读 `*`、
  不读侠义——守卫认的是「这一门里有没有人提过你」；
- 按典型 +15–25/桩算，**50 = 为这一方办过三五桩事**，正好是「守卫听过你的
  名字」的语义：卷二一篇章的自然量，不钝不飘；
- 梯度上它卡在两档现值中间，不成孤数：
  `20 擂台肯让你上（* 键） → 50 山门认得你（本件） → 恶名 20/50 官府两档 → 区域准入（89 §七·补二，另批）`
- 比武扬名走本门键（20–60+），一场排面比武就能跨过 50——「以武扬名」这条
  捷径语义成立，是刻意留的。

### 复核带出的两条挂账（不挡本件，移交归属）

1. **商店折扣标定失配**：commands.js:4003 按 `rep/2000` 折 15%——按逐案 +15 的
   量级，满折扣要 130+ 桩差事，这辈子吃不满。建议基线改 **500**（33 桩，一条
   长线够得着）或按上表梯度重标。归属：数值（05-balance 补一行）。
2. **`*` 键与势力键的混读风险**：culture 攒的是 `*`，报号认的是门派键——两键
   各管各的没问题，但**后续区域准入（89 §七·补二）定门槛时必须写清读哪个键**，
   否则会出现「擂台名人进不了山门」的体感矛盾。归属：89 号档执行时落。

## 五、风险

- **死锁（已解）**：甲案靠豁免双通道闭合链路——「我来拜师」验门槛放行至拜师、
  引荐信/同门照旧最上游放行。施工回归验收第③④条就是防死锁断言。
- **新手线节奏**：新玩家第一次到山门多一步「我来拜师」。教程/引导若在山门前
  有「前往拜师」提示语，需同步一句（归属：101 号档 first-minute 口径，施工时
  顺带走查，不改引导本体）。
- **戒备态误伤**：−20 判据会把「闯过一次门」与「连闯多次」同样对待——想让记仇
  分级，可在台词轮换里做（−20～−50 用第 1/2 句，≤−50 用第 3 句「不见你」），
  数值不动。
- 声望数值提示的口径已与 repGainOnQuest 现行 sys 行一致，不新增玩家可见的
  「声望面板」概念；`风声`（reputationLines）仍是名声的正文出口。
