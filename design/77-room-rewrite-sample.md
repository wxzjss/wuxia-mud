# §1 · 82 间模板房改名

## 1.0 认病：这不是「名字不好听」，是名字里没有信息

把 66 间山路房的名字摆在一起看：

```
华山·松林    少林·松林    武当·松林    峨眉·松林    大理·松林
唐门·松林    苗疆·松林    丐帮·松林    古墓·松林    黑木崖·松林    桃花岛·松林
```

十一条一模一样的「松林」，只换了前缀。玩家在地图上看到 11 座山，每座山的第 2 格都是「松林」，第 3 格都是「半山亭」，第 5 格都是「山泉」。

**问题不在「重名」，在于：这个名字没有告诉我这是哪儿。**

「少林·松林」这个名字，把「少林」去掉，剩下的「松林」可以贴在任何一座山上。前缀是地图给的，名字本身没出力。而江湖里的地名不是这样的——**你去少室山，和一千年后的人去，是同一片林子；那片林子有它自己的名字。**

> **判据**：把前缀（山名 / 村名）去掉，剩下的那两个字能不能独立指认一个地方？
> 「松林」不能，「莎萝坪」能，「卓锡泉」能，「幺店子」能。
> **改名的目标就是让每一个名字都过得了这条判据。**

## 1.1 改名的三条规矩

### 规矩一：名字要跟 desc 对得上，不能打架

现在 6 个段名对应 6 条 desc，desc 的语义是固定的：

| 段 | desc 的语义 | 新名字必须落在这个语义里 |
|---|---|---|
| path1 | 石阶，凿在岩壁上，回头看山门小成拇指 | 阶 / 磴 / 关 / 坡 / 道 |
| path2 | 一片林子，枝子横着长 | 林 / 坪 |
| path3 | 半山歇脚处，有水囊、有柴 | 亭 / 庵 / 观 / 寺 / 洞 / 寮 |
| path4 | 林中间的道，落叶陷半寸 | 径 / 道 / 坡 / 沟 |
| path5 | 石缝渗泉，石槽 | 泉 / 井 / 潭 / 池 |
| path6 | 贴崖壁走，只容一人 | 崖 / 栈 / 石 |

**为什么死守这个框**：这一批只改名、不重写 desc（desc 重写在 §2 的 20 间样张里）。名字一旦跳出 desc 的语义，玩家看到的名字和看到的第一句话就对不上，那比现在更糟。

### 规矩二：能用真地名就用真地名

这十一座山里有九座是真山（华山、嵩山、武当、峨眉、点苍、终南山…），**真地名自带一千年的人味**，凭空编不出那个味道。

- 华山的「回心石」「莎萝坪」「云门」——都是真的，位置也对
- 少林的「卓锡泉」「初祖庵」「达摩洞」——都是真的
- 峨眉的「解脱坡」「钻天坡」「一线天」「神水泉」——都是真的
- 武当的「榔梅林」「南岩栈道」「九渡涧」——都是真的
- 点苍的「无为寺」「七龙女池」——都是真的

只有黑木崖、桃花岛、丐帮总舵、苗疆是虚构的，那四处才自己编，编的时候扣住门派气质（见规矩三）。

### 规矩三：名字要带出门派气质

同一段路，在不同门派脚下，名字的调子应该不一样：

| 门派 | 气质 | 在名字上怎么体现 |
|---|---|---|
| 少林 | 禅、古、规矩 | 用佛门地名（初祖庵 / 卓锡泉 / 达摩洞），不用险怪字 |
| 武当 | 道、皇家、宫观 | 用道教科仪地名（玄岳门 / 仁威观 / 榔梅林） |
| 峨眉 | 佛、陡、猴、云 | 用「解脱」「钻天」「一线天」这种带动作感的词 |
| 丐帮 | 破、脏、人多 | 用「破凉亭」「花子径」「一碗泉」这种自嘲的、土的名字 |
| 黑木崖 | 魔、险、不讲道理 | 用「铁钉磴」「枯木林」「鬼行径」「锈泉」这种带刺的字 |
| 桃花岛 | 奇门、雅、黄药师 | 用「弹指阶」「落英林」「迷踪径」「潮声泉」这种从武功名化出来的 |
| 苗疆 | 湿热、蛊、西南 | 用「榕树坪」「瘴气沟」「溜索崖」这种南方才有的东西 |
| 唐门 | 蜀中、机关、药 | 用「百步磴」「慈竹林」「浸药泉」 |
| 古墓 / 终南 | 清、冷、道、典故 | 用「三清磴」「采药径」「寒潭」 |
| 大理 | 佛、茶花、溪 | 用「中和寺道」「十八溪径」「七龙女池」 |
| 华山 | 险、剑、凿 | 用「五里关」「云门」「回心石」 |

**反面教材**：如果 11 座山都叫「XX·一线天」「XX·绝壁栈」，那只是把「松林」换成了「一线天」，模板还是模板。**气质不同，选字的调子就要不同。**

# §2 · 20 间三段式样张

## 2.0 三段式：一间房由三段拼起来

玩家 `look` 一间房，看到的东西分三段：

| 段 | 来源 | 变不变 | 说什么 |
|---|---|---|---|
| **① 固定描写** | `room.desc` | 永远一样 | 这地方长什么样。**与玩家无关，你不在它也在** |
| **② 动态句** | `room.ambient[weather]` / `room.ambient.night` | 每次看可能不同 | **此刻**这儿正在发生什么 |
| **③ 痕迹句** | `p.roomNotes[roomId]` | 只有你在这儿做过事才有 | **你**在这间房留下过什么 |

**顺序不能变：痕迹句永远在最后。**

理由：第一段是地方，第二段是时间，第三段是你。**先有地方，再有此刻，最后才有"你"**。反过来放，玩家第一眼看到的就是自己，地方的实感就没了。

### 2.0.1 痕迹字段口径（已定案，别改回去）

```
p.roomNotes[roomId]        // ✅ 用这个
```

**`p`** 是玩家对象，**`roomNotes`** 是「你对各间房的记性」，**`roomId`** 是房间 id。

| 不能写成 | 为什么 |
|---|---|
| ❌ `p.marks` | **`p.marks` 已经被人占了**。它是玩家的**人生标记数组**（`'丧亲' / '新婚' / '得子'`），喂 `portraitMoodBias()`（`world.js:99`）。画像的表情就是靠它变的。撞了就是：你在一间柴房里生了堆火，你这辈子所有画像的性格就变了 |
| ❌ `room.marks` | `w.data.rooms` 是**进程级共享模板**。你在华山点了一堆火，别的档、别的玩家进华山也看得见那堆火 |
| ❌ `world.roomMarks` | **全仓 grep 为空，这个字段不存在**。等它出现的人可以死心了 |
| ❌ 数组 `p.roomNotes[id] = []` | 见下 |

### 2.0.2 为什么是单值不是数组

**一个人对一间房的记忆，最后只剩一件事。**

你在华山·水帘洞灌过一次水囊，也在那儿躲过一次雨。**三天以后你回来，你想起的是哪一件？**

——只有一件。另外一件被盖掉了。

这不是「省事」，这是**设计**。理由有三条：

1. **玩家的情感记忆本来就是会覆盖的。** 数组会把「我在这里做过的十三件事」全列出来，那是**记账**，不是记忆。
2. **数组会越长越长。** 一间常去的房间，到第三十个小时会攒出三十句痕迹句，玩家每次 `look` 都要往下翻一屏。单值永远只有一行。
3. **「被覆盖」本身可以写进文本。** 痕迹句可以写成「你在这儿歇过脚。后来你还在这儿打过一架，那次的事你记得更清楚。」——**覆盖变成了叙事。**

> ⚠️ **给主程序**：覆盖的时候**不要提示**，**不要写「原痕迹已被覆盖」**。悄悄换掉。玩家自己会发现，发现的那一下比任何提示都好。

### 2.0.3 动态句：房间级池子只管「天气 + 夜」

引擎里已有的三个接口（`src/core/world.js`）：

```js
this.weather          // ∈ ['晴','阴','雨','雪','风','雾']，6 个值
isNight()             // m < 300 || m >= 1140
isMealTime()          // 660–780（午）/ 1020–1140（酉）
shichen(minutes)      // '子'…'亥'，12 时辰
seasonCN()            // 四季
```

**取句规则**：

```
1. isNight() 且房间有 night 句  →  取 night 句（夜句优先于天气）
2. 否则                          →  取 weather 句
3. room.ambient 里没有这一条     →  **不显示**（不兜底、不复用别的天气的句）
```

**第 3 条是硬的。** 一间屋子在下雪天里没有可写的东西，那就**不写**。用一句通用的兜底句填上去（比如「雪落在屋檐上。」），就等于告诉玩家「这句话不是为这间房写的」——**那正是模板味**。

**节气不进房间。** `season.js` 已经有一套全局节气句（24 节气各一句，写着"这一天该有的样子"），那是**日子**层面的，全世界的房间共用。房间级池子只管**天气与昼夜**，这两样是**地方**层面的。两套混在一起，就会出现「大雪节气 + 晴天的南方屋子」这种自己打自己。

## 2.1 文风五戒（本节必须写进文档，是这一次的验收重点）

> 前四条是范可控转达主人原话的精神，我把它拆成可执行的戒律，每条配「怎么查」。
> **第五条是朱雀跑出来的红**（破折号密度超项目铁律），范可控指出它与戒一同源，遂并入成第五条。

| 戒 | 一句话 | 判据 | 实测 |
|---|---|---|---|
| 一 | 不要句句都是精巧观察 | 删掉最后一句，段落还成立吗 | ✅ 18/20（另 2 段是规则文本） |
| 二 | 要有短句 | 最长分句 − 最短分句 ≥12 字 | ✅ 20/20 |
| 三 | 不要每段都在同一位置收一个观察 | 连读 6 段，同收法 ≥4 段即犯 | ✅ 最多一种 7/20 |
| 四 | 数字与具体名词优先于比喻 | 明喻 ≤4 处，不在固定描写末句 | ✅ 4 处，固定描写 0 处 |
| 五 | 破折号：房间描写不用 | 密度 ≤2.38/千字 | ✅ 0.00 |

### 戒一 · 不要句句都是精巧观察

**病长这样**：

```
一间柴房，门是坏的。阳光从破缝里漏进来，落在地上，像一条金线。
```

第一句「门是坏的」是**事实**，第二句「像一条金线」是**观察**。现在的问题是：第二段每一句都有，一句都不放过。

**改法**：允许句子**停在事实那儿**。

```
一间柴房，门是坏的。
```

就停在那儿。不补尾巴。

> **判据**：把一段描写的**最后一句**删掉，这段话是不是还成立？
> 如果删掉最后一句就「没写完」，那最后一句就不是描写，是**作者在自己后面补的一句话**。

### 戒二 · 要有短句

**病长这样**：一整段全是 25–40 字的长句，句子都一样长，读着累，读完记不住任何一句。

**改法**：长句之间插 4–8 字的短句。

```
一池水，从石壁底下渗上来，池边砌着石头。水面上浮着一层东西，绿的，是药。
池边一溜竹架，架上摊着根须，摊开晾着。风一过，药味压过别的味道。
```

六字、七字、十二字、二十字——长短交替。

> **判据**：一段描写里，最长句与最短句的字数差 **≥ 12 字**。
> 差不到 12 字的段落，读起来是平的。

### 戒三 · 不要每段都在同一个位置上「收一个观察」

**这条是主人闻出来的那个味，是四条里最要紧的一条。**

**病长这样**：

```
段落一：...枝子横着长，把路遮得半明半暗。风过时满山响，像有人在远处说话。
段落二：...槽沿磨得圆了。上上下下的人在这里歇一歇，喝一口。
段落三：...庙前的香炉里插着半截没烧完的香。
```

**每一段都在最后一句收一个"有意味的观察"**。单看每一段都不错，连着看三间房，玩家就认出来了：**这个作者每一段都要在最后一个句号前抖一下。**

**改法**：把"收尾"这件事**打散**。

| 手法 | 例子 |
|---|---|
| **停在事实** | 「坪边一眼泉，泉边搁着半个葫芦。」——句号，没了 |
| **停在动作** | 「上上下下的人到这儿都要停一停，喝一口。」——动作，不是观察 |
| **停在数字** | 「石阶从关口凿上去。走到第五十三级的时候回头，山门已经小成拇指大。」 |
| **停在对话/规矩** | 「门口立着一块木牌，牌上写着四个字：取一还一。」 |
| **停在一样东西** | 「墙角一架石磙，磙子上还沾着麦壳。」 |

**五种收法轮换，哪一种都不要连用三次。**

> **判据**：连读 6 间房的固定描写，数一数**最后一句的收法**。
> 6 段里有 ≥4 段是同一种收法（比如都是"一个有意味的观察"），就是犯了这一条。

### 戒四 · 数字与具体名词优先于比喻

**病长这样**：「像...」「仿佛...」「似乎...」一个接一个。比喻是**解释**，解释多了，玩家就没有想象的空间了。

**改法**：用**可以数的数字**和**叫得出名字的东西**代替比喻。

| 比喻 | 换成 |
|---|---|
| 像有人在远处说话 | 风过的时候满山响 |
| 仿佛时间在此停留 | 槽沿磨得圆了，磨了几十年才磨成这样 |
| 像一条金线 | 阳光落在地上，一条 |

> **判据**：20 间样张里，明喻（「像 / 仿佛 / 似 / 如同」）**≤ 4 处**，且**不出现在固定描写的最后一句**。

### 戒五 · 破折号密度 ≤ 2.38/千字（**项目铁律，本次新触发**）

> 这条不是我定的，是项目早先的标点铁律。之前的文本里破折号少，没触发；20 间样张**触发了**，朱雀的「标点痕迹」维度抓到了。
> 范可控实测：20 段固定描写 **1455 字 / 6 处破折号 / 4.12 每千字**，其中 **A3 华山·毛女洞一段独占，单段 14.3 每千字**——它也是 20 段里唯一上 40 分的。

**改法**：把 6 处破折号全拆了。

| 原句 | 改成 | 为什么这么改 |
|---|---|---|
| 「有人在这儿歇过**——**地上有一堆柴」 | 「有人在这儿歇过。地上有一堆柴」 | **句号比破折号重**。「歇过」和「有柴」是两件事，本来就该断成两句 |
| 「上山去的人**——**香客、挑夫、赶考的**——**都在这儿歇一歇」 | 「上山去的人，有香客，有挑夫，也有赶考的。都在这儿歇一歇」 | 破折号在这里是**当括号用**。中文有逗号，不必借破折号 |
| 「翻的都是外头的功夫**——**唐门自己的功夫不在书里」 | 「翻的都是外头的功夫。唐门自己的功夫不在书里，在人身上」 | 同上 |
| 「格子里搁的东西不相干**——**一柄剑，一只瓷瓶…」 | 「格子里搁的东西不相干**：**一柄剑，一只瓷瓶…」 | **引出列举，冒号比破折号准** |
| 「墙上挂着几样兵器，都是断的**——**断了也留着」 | 「墙上挂着几样兵器，都是断的。断了也留着」 | 句号 + 四字短句，**正好同时示范戒二** |
| 「地上没有影子**——**树太高了」（C3 晴句） | 「地上没有影子。树太高了」 | 同上 |
| 「纸上一个字也没有**——**那一卷要自己写」（点苍独有句） | 「纸上一个字也没有。那一卷要自己写」 | 同上 |

**改后：全部样本文本 5650 字，破折号 0 处，密度 0.00 每千字。**

#### ⚠️ 一句关于"度量单位"的话（这条会影响后面每一批）

**2.38/千字这个数，在整段文字上量和在单段描写上量，是两个意思。**

一段固定描写大约 **85 字**。按 2.38/千字算，85 字只许有 **0.2 个破折号**——**等于一个都不许有。**

> **所以这条铁律落到「房间描写」这个文体上，它的实际口径是：**
> **房间描写里不许出现破折号。**
> 不是"少用"，是**不用**。

**这条要写清楚，否则下一批写台词的人（D-1 那 165 句）会这么算**：「我一整段 200 字，用 2 个破折号 = 10/千字，超了 4 倍」——然后他就去凑长句把分母做大。**那是对着量具写，不是对着读者写。**

**正确的记法**：

| 文体 | 口径 |
|---|---|
| 长篇（整章、整卷，≥2000 字） | 密度 ≤2.38/千字，**按字数算** |
| 房间描写 / 台词 / 单段（<300 字） | **不用破折号**，不按密度算 |

**背后的道理跟戒一同源**：破折号在中文里最常干的事就是**补充说明**，而补充说明常常就是你在定量——**"有人在这儿歇过"说完就完了，你非要补一句"地上有柴"**。**戒一说"停在事实那儿"，破折号就是停在事实那儿的头号障碍：它让你觉得你还能再补一句。**

> **少林的藏经阁和唐门的藏经阁，不可能长一个样。**
> 少林的藏经阁里有扫地僧，唐门的藏经阁里有铁栅和药味，丐帮的藏经阁是一间地窖。
> 现在它们都是「纸味与霉味混在一处」。

## 3.1 收编办法：**共有骨架 + 门派独有句**

不重写 66 条 desc（那要 66 × 80 字 = 5000 多字，且不好维护）。改成：

```
一段固定描写 = 【这一类重地共有的骨架】 + 【这个门派独有的一句】
```

### 3.1.1 共有骨架（每类一句，全类共用）

| 类 | 共有骨架 | 说明 |
|---|---|---|
| **藏经阁** | 「一架一架的书，从地面堆到梁上。窗纸糊得厚，屋里终年不见太阳。」 | 保留原模板的前两句。**第三句（「纸味与霉味混在一处」）换成门派独有句** |
| **藏宝阁** | 「木架上分着格子，每格插着一片木牌，写着名目。」 | 取原模板的**第一句与第三句**，去掉中间那句罗列（「兵器、瓶罐、符纸…」）——**那句罗列本身就是模板味的来源，各家搁的东西不一样，不能共用一句** |
| **库房** | 「一间不大的屋子，堆着几口箱子，箱盖半开着。」 | 保留原模板的前两句。**第三句（「看屋的老头坐在门口打盹」）换成门派独有句** |

**为什么保留而不是全换**：这三句写的是**这一类重地在物理上长什么样**——藏经阁就是书堆到梁上，库房就是几口箱子。这部分本来就该一样。**不一样的是里面放了什么、谁在看、有什么规矩。**

### 3.1.2 门派独有句的素材来源：`72_sects_tier.json` 的 `story` 字段

每个门派在数据里已经有**一行写着它的魂**：

```jsonc
"tangmen": { "tier": "二流",
  "story": "蜀中唐门的门规只有一条要紧：不许对外人露脸。看过的人，通常也不必再看第二次。" }
```

**门派独有句，就是从这行 `story` 里化出来的一个具体东西。**

- 不是「唐门的藏经阁很神秘」（**那是形容词，不是东西**）
- 是「楼梯口有一道铁栅，栅门挂着锁」（**一样看得见的东西，它替你说完了"神秘"**）

### 3.1.3 门派独有句的三条规矩

1. **一句话，不超过 35 字。**
2. **必须写一样看得见摸得着的东西**（架子、箱子、瓶子、牌子、锁、刀、账本…），**不写形容词**（神秘、森严、古老、阴森）。
3. **这一样东西要能反推出门派的脾气。** 把门派名删掉，读这句话，还能猜出是谁家的——就算过。

## 3.5 收编时顺手要处理的三件事

### 3.5.1 少林有两间藏经阁（必须处理）

| id | 现名 | 来源 |
|---|---|---|
| `shaolin_cangjing` | **少林·藏经阁** | 老地图里的少林寺建筑 |
| `shaolin_library` | **少林派·藏经阁** | `82_treasury_place.json` 加的三层重地 |

**同一个 region 里两间房都叫「藏经阁」** ——这正是我们在 §1 里要消灭的东西，不能在 §3 里又长出来一个。

**设计裁定：`shaolin_cangjing` 改名为「少林·碑廊」。**

- **房间不删、id 不动、出口表不动**（删房间要动出口表与存档，收益为零）
- 它变成**藏经阁的前院**：物理上你得先过碑廊，再进藏经阁
- desc 换成碑廊的东西，碑廊正好是少林「千年规矩」的物证：

> 一条廊子，两边嵌着碑。碑上的字有的还认得出，有的磨平了，磨平的那几块更老。廊子尽头是一道门，门里是藏经阁。扫地的人从这头扫到那头，一天扫两回。

**为什么是碑廊**：`shaolin` 的 `story` 是「晨钟暮鼓，**千年的规矩压着一代代人**」。碑是千年规矩唯一留下来的实体。**而且它把"扫地的人"放进了这条廊子**——扫地僧在 §2 的 D1 里坐在藏经阁灯下，在这儿他扫廊子，两处对得上。

### 3.5.2 守卫一句话（规格已有，只补一句文本）

## 4.3 骨架四禁

「骨架四禁」是我在 `design/75` 里定的四条，这次房间文本同样适用：

| 禁 | 说明 | 本文执行情况 |
|---|---|---|
| **观察腔** | 每段最后一句收一个"有意味的观察" | ✅ 20 段收法分五种，最多一种 7/20，无一段以观察收尾（见 2.3.1 / 2.3.4） |
| **对偶定义** | 「一半是…一半是…」式的对称定义句 | ⚠️ **主动用了 2 处**：`dali_library`「一半是佛经，一半是剑谱」、`hengshanN_library`「一半是剑谱，一半是医书」。**见下方说明** |
| **悖论对偶** | 「看似 A，实则 B」 | ✅ 0 处 |
| **对称对偶** | 两句字数相同、结构相同 | ✅ 0 处 |

**关于那 2 处对偶**：这是**故意犯禁**。理由——

「藏经阁的书架上摆着什么」这件事，**对偶是最省字也最准的写法**：大理段氏的世子爱佛经不爱武功，那么他家的藏经阁就是「佛经旧、剑谱新」；恒山派的尼姑带剑也带药箱，那么她家的就是「医书比剑谱旧」。**这两句省掉了整整一段解释。**

但它是禁条，所以要**记账**：**全库对偶句 ≤2 处，且只许出现在"一格一格摆东西"的语境里。** 谁再写第三处，就把这两处一起改掉。
