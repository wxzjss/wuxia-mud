## §3 门派生涯（`core/sectlife.js`）

### 3.1 晋升线

```
拜师入派（外门弟子）
  │  贡献够 → 「拜师 <长老>」                → 内门/执事 …
  │  贡献够 + 长老位有缺 → 「申请」           → 走门路补缺
  │  贡献够 → 「挑战 <位次高你一位的人>」      → 打赢进位
  └─ 走到头 → 掌门 → 门派经营开放
```

- `拜师 <人名>` 在**同门**时自动变成**求升**（不再当拜师处理）
- 挑战要**押贡献**（`promoteCost × 1.2`），输了这笔就没了；赢了由 `onNpcDown` 结算进位
- 三位数的贡献门槛 × 门派层级系数（一流 ×3 / 二流 ×1.8 / 三流 ×1）

### 3.2 收徒大典

- 每家门派**每 12 天开一次**，落在轮内哪一天由门派 id 哈希决定 → **各家日子都不同**
- 难度按层级：通过率底数 一流 0.20 / 二流 0.42 / 三流 0.70 / 秘境 0.12，再乘你自己的斤两
- 过了**破例入派**（大典存在的意义就是收常例不收的人，再拿 `require` 卡一道是自相矛盾）
- `参加大典` 不带名字 → 报今日开山的几家 / 最近的三家分别在几天后

### 3.3 任务处

- **门派任务处**：按职位分层（跑腿 25 贡献 → 坐镇 380），职位越高接到越好、拿得越多
- **官府任务处**：另一条线，给**功勋**；功勋够了自动补缺（白身 → 差役 → 捕头 → 巡检 → 都尉 → 将军）
- 主人定的天花板：**门派线能当宗主，官府线最多当到将军**

### 3.4 门派剧情

按门派**气质分野**写（正 / 邪 / 中立），不是一份模板套 43 家：

- **初入宗门**：正派指着两排灵牌说「这里头一半是病死的，还有七个是死在别人手里的」；
  邪派不摆香案，只问一句「你怕不怕别人骂你」；中立交给你一沓旧账，让你先学会看人情往来
- **每次升职**：正派提醒你别拿招牌欺人；邪派暗示你去把被抢的买卖讨回来；中立教你读欠条
- **继位**：前任把印信推过来，说「我坐上这把椅子的时候门里七十来号人，如今册子上四十二个，有两个三年没回来了」，然后走出去，没有回头
- **最终章 · 华山对决**：敌对门派下战书（对手取关系最差的那家）→ **剧情视角**演两边弟子按实力从弱到强一对一
  - 我方只剩玩家 + 对方还有人 → **对方一拥而上**
  - 对方只剩宗主 → **与对方宗主一对一**
  - 都没打完 → 天黑了各自收兵
- **官府最终章 · 出征**：成了将军才能点。写的是河滩上那双还在、人没了的鞋

### 3.5 关于「不能有 AI 味」

写这类文字时避开的几个东西：不写「命运的齿轮」，不排比三句，不起「这一刻他明白了」的句式，
不用破折号堆情绪。改成**具体的人 + 具体的动作 + 一句半句话**：
「他把茶盏搁下」「香灰吹到你鞋面上」「靴子陷进泥里拔不出来，索性脱了拎在手上走」。
`tools/ai-flavor-check.js` 在全量回归里守着。
