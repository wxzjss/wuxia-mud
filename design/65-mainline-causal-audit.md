# 主线因果审查 · 诊断与方案（#114 深化）

> 起因（主人 2026-10-11 原话）：
> 「调用『长篇剧情因果引擎』以及上述所有『去 ai 味』一类的技能，结合世界观各大势力及武学
> 以及各种人物画像，看一下主线支线以及新手剧情是否存在需要改动完善的地方，
> 或者是不是有更好的方案整条替代重写（**如果有可以先写好大纲**）」。

审查方法：按因果引擎的五项检查过一遍 —— **幕间因果链 / 人物告知动机 / 认知边界 /
伏笔埋设与回收 / 三结局可达性**，再拿 NPC 画像（`96`/`97`）与势力设定做交叉核对。

---

## 0. 总评

**骨架可用，需补接榫，不必重写。**

五幕主干是干净的：**半块铜牌 → 查东厂 → 北疆雪谷 → 黑木崖 → 御街面圣**，
一条线从江湖查进朝堂，三结局（交卷 / 半交 / 拒交）**flag 均有设置处与读取处、都可达**。
问题不在结构，在**榫头**：几处衔接靠玩家的偶然发现而不是剧情的必然推动。

## 2. 本轮已落地（patch 级，不动骨架）

1. **堵住「先接后拿 + 剧透」**：`q_main_sect` 加 `require: {flag:know_east_depot}`，
   并给它一句人话门槛——`requireMsg`：「东西呢？空着手来，我同你说不着。」。
   顺带给 `accept` 指令补 `requireMsg` 支持（原来只会说「你还不满足接取条件。」，
   只告诉玩家「不行」、不告诉他差什么）。
2. **把铜牌那场夜戏从「看不见」变成「看得见」**：`road_huashan_1` 的房间描述补一句
   「天擦黑时，这道上常有官车过；路边有块背风的石头，赶路的人多半在这儿歇脚。」
   ——**不剧透**，但告诉玩家这儿有戏。
3. **修好不可达分支**：`mojiao_shanmen` 加 action「探后山」，设置 `moye_backroad`
   （玩家可以另走一条路进黑木崖，而不是每次硬闯三道哨卡）。
4. **半交分支有物可交**：陈语冰抄纸那段（`65:1137`）在 `flag:chen_chaoben` 的同时
   `+item:wulin_zhenyi_chaoben:1` —— 那卷抄本真落到玩家手上。
5. **认知边界收口**：东方那句从「断言玩家的经历」改成**耳目众多 + 追问**
   ——「你鞋上沾的土，是华山道上的。那晚官车过山脚，你看见了什么，说说。」
6. **补两名 Boss 的画像**：血刀老祖、丁春秋各 13 字段 + 两条 `hooks`（见 §4）。

## 3. 后续可做（大纲，按性价比排序）

### 3.1 给 NPC 的情报加关系门槛（半天）
在 `65`/`66` 的关键揭示段，把 `cond` 从「只认进度 flag」改成「进度 flag **且** trust 达标」，
并在不达标时给一句「话到嘴边又咽回去」的过渡（不撒谎、也不白给 —— 与画像 §同类口径一致）。
涉及：方证（`65:352/397`）、东方（`66:724`）、黄药师（`66:1380`）。
> ⚠️ 要同时改**失败分支**，否则玩家会以为「这 NPC 是哑的」。

### 3.2 把断线 flag 接回去（一天）
- `heard_term_nan_ties`（终南山下有人学过三年刀）：接到第五幕黄药师那三句里，作为第 2 句的引子。
- `xuedao_knows_token` / `blood_deal_trade`：血刀门那两处抉择，改成在后面某段对话里被**提起**
  （血刀老祖或他的账房会记得你当初怎么进的寨）。
- `jiuye_fought`：第一幕的两条岔路（拦车 / 站旁边）现在只影响一句台词，
  可以再接一处——第三幕追囚车时，**被押的人认得你**（拦过车 → 他谢你；站旁边 → 他一句也不说）。
- 反向：`moye_backroad` 已修（见 §2.3）。

### 3.3 让画像与主线互相认领（一天）
- 方证的 `secret` 与主线麦高芬**合并成一件**：塔里那件三十年前收进去的，就是现在「被借走」的那卷。
- 岳不群画像补一条勾连朝廷的线索（或把主线那段改成「他在替某人保管旧物」，与画像的「残谱来路」并轨）。
- 东方画像补一层政治（他要的不是秘典，是**借秘典把朝里的人引出来**）——这样「痴」与「谋」就合得上了。

### 3.4 支线层面的同类体检（未做，规模较大）
355 条支线里，`hk_*` 那批（画像钩子支线）质量最齐；`sq_npcv_*` 那批多为
「去某房间 → 回来复命」的两段式，**缺抉择**。可照 §6 那九条文化支线的样子，
给其中「画像写得实」的二三十人补一个 `menu` 抉择。

## 4. 本轮补的两名 Boss 画像（要点）

| NPC | 给了什么「人味的逻辑」 |
|---|---|
| **血刀老祖** | 寺里杂役出身、剃度没剃成；**腿不行了**是他真正的怕；寄在他那儿的半卷是官服人留的；十五年前华山下放过一个跪着求饶的孩子——**与第一幕夜戏同一条道** |
| **丁春秋** | 早年学师父的东西学得最快、也最早想拿走；给弟子的「长生丹」里有一味慢药；**用毒养着自己，毒快认不出主人了**；每收一个弟子先让他把那句马屁喊响 |

两人的 `hooks` 都留了两条：一条 `task`（能接着往下查的线索）、一条 `reveal`（他自己的破绽）。
