**武学核心现状（最要动）：**
- 50 武学仅 `type`（拳/剑/刀/棍/鞭/暗器）武器分类，**无** 外功/内功/奇门/歪门/魔功 大类
- 修炼=`train` **消耗潜能**练功，不耗内力；`打坐` 仅回内力
- 熟练度仅数字 level（1~500），**无** 入门→登峰造极 分级效果
- **武器无绑定惩罚**：无对应武器 fallback 拳脚，不打折
- 伤害公式**二次爆炸 bug**：`(1+lv*0.02)*(1+lv*0.012)` 两线性项相乘（lv=400 出 92 万）

## 1. 设计目标

1. **修炼不靠打怪升级**：功法进度靠 打坐/炼丹/炼器/符文阵法/天材地果 推进，**消耗内力**为第一资源。
2. **功法分五大类**：外功 / 内功 / 奇门 / 歪门 / 魔功（魔功有反噬/邪气代价）。
3. **武技分系 + 武器绑定**：刀/枪/棍/剑/拳脚/乐器音波；施展须装备对应武器，否则效果大打折扣。
4. **熟练度分级**：未入门→入门→小成→大成→融会→登峰造极，每级效果不同（伤害/命中/内力消耗/特效）。
5. **内功冲奇经八脉**：打坐冲击经脉，贯通后解锁内功上限/特效。
6. **外功靠淬体**：练武馆/宗门器械/淬体法，需足够血量与药物支撑，否则有生命危险，越往后越难。
7. **资质系统**：资质越高练武越快、上限越高。
8. **NPC特性**：身法灵活→敏捷/闪避；习武奇才→练武进度飞快 等战斗/修炼向深度特性。

## 2. 内力系统（核心资源）

- `mp`/`maxMp` 已是角色字段（recalc 由 `悟性` 派生）。**重做语义**：内力 = 修炼与施展功法的燃料。
- 新增消耗模型：
  - `cultivate(skillId)`：打坐运转功法，每轮消耗 `mp`（内功高耗、外功低耗），按 资质+功法难度 结算熟练度增益。
  - `perform(skillId)`：施展绝招消耗 `mp` + `stamina` + `water`（威力越大耗越多）。
  - 内力枯竭 → 无法修炼/施展，需 `打坐` 恢复或服药/天材地果。
- **奇经八脉**：`character.meridians = { 任:0, 督:0, 冲:0, 带:0, 阴跷:0, 阳跷:0, 阴维:0, 阳维:0 }`（0~N 贯通度）。打坐有概率冲脉，贯通解锁内功等级上限 + 特效（如督脉通→内力上限+，冲脉通→伤害穿透）。
- 去等级化：角色 `level` 字段废弃（保留兼容旧档），伤害/上限不再由 level 驱动。

## 3. 功法五大类（category）

`10_skills.json` 每个技能新增 `category` 字段：
- `外功`：刀枪棍剑拳脚器械，靠淬体+对练，直接加攻防。
- `内功`：吐纳打坐，加 maxMp/内力恢复/抗性，冲奇经八脉。
- `奇门`：暗器/音波/机关/阵法，特殊机制（控场/dot/破甲）。
- `歪门`：毒/蛊/采补，见效快但有反噬或道德/邪气代价。
- `魔功`：威能最强但持续侵蚀（扣根骨/福缘/心智，邪气值累积，可被正派追杀）。

## 4. 武技分类 + 武器绑定

- 现有 `type`（拳/剑/刀/棍/鞭/暗器）→ 扩为「系」：`刀` `枪` `棍` `剑` `拳脚` `音波`（乐器）。
- **武器绑定规则**：施展某系武技时，若未装备对应武器（剑系需 `武器` 槽为剑类），`damageMult` 与 `accuracy` 按衰减系数（如 ×0.45）结算，并在日志提示"手中无剑，威力大减"。
- 拳脚无需武器；音波需乐器（琴/箫类道具）。

## 5. 熟练度分级（档位）

定义全局档位表 `PROF_TIERS`（在 character.js / 常量）：
```
未入门(0) → 入门(1) → 小成(2) → 大成(3) → 融会(4) → 登峰造极(5)
```
- 每个技能按当前 `level` 映射到档位（阈值由 `maxLevel` 归一化，如 level≥maxLevel*0.85=登峰造极）。
- 档位影响：基础 `damageMult` 倍率 ×(0.6/0.8/1.0/1.25/1.5/2.0)，命中加成，内力消耗，以及**档位特效**（如登峰造极解锁招式二段/破防）。
- 提升方式权重：**对练/生死战最大**（combat 结算给大额熟练度），其次打坐修炼，再次炼丹/天材地果临时加成。

## 6. 修炼方式（非打怪）

| 方式 | 入口 | 消耗 | 产出 |
|---|---|---|---|
| 打坐修炼 | `cultivate`/`打坐` | 内力 | 功法熟练度 + 冲脉概率 |
| 炼丹 | 新增 `alchemy` 子系统 | 药材+内力+体力 | 丹药（回内力/临时资质/突破） |
| 炼器 | 新增 `forge` 子系统 | 矿料+内力 | 兵器/防具（强化武器绑定收益） |
| 符文阵法 | 新增 `rune` 子系统 | 材料+内力 | 符/阵（战斗buff/破敌） |
| 天材地果 | 采集/奇遇获得 | — | 永久/临时资质·根骨·内力上限加成 |

## 7. 资质系统

- 新增角色属性 `资质`（默认 10，创建角色可选），与 `悟性` 区分：悟性=领悟（影响冲脉/特技），资质=练武速度+上限。
- `trainSuccessRate` / `maxSkillLevelFor` / `cultivate` 增益均引入资质。
- 天材地果可提升资质上限。

## 8. NPC特性扩展（traits）

在 `00_core.json` 的 `traits` 增：
- `agile`（身法灵活）：身法+6、闪避+10、speed+8。
- `martial_prodigy`（习武奇才）：练武进度×1.8、功法上限+。
- `iron_will`（心志坚毅）：淬体/冲脉失败惩罚减半。
- `frail`（体弱）：气血-，淬体风险↑（用于反派炮灰/特定NPC）。
- 所有新 trait 必须接 `recalc()`（已有 trait 接入机制，加 `attr`/`effects` 即可）。

## 9. 待补系统（独立 sprint）

### 9.1 反派Boss与背景主线
- 设计 1 个幕后方（如「幽冥教」或朝廷「缇骑司」）操控多起事件的阴谋。
- 落地：新增 Boss NPC（高经脉/魔功/特性）、主线 `60_quests` 起承转合、秘境房间、奇遇事件。
- 与现有邪派门派（日月神教等）串联。

### 9.2 建家 + 家园开辟新地块
- `home.js` 扩：玩家可购/开辟**多块地块**（`p.plots = []`），每块可建不同功能建筑（练武场/丹房/药圃/祠堂）。
- 地块从"里弄空地"扩展为"郊野地块"（`region: 'wild'` 新区域），买地契。

### 9.3 给NPC建家
- 玩家可替伴侣/结拜/徒弟 NPC 购置/修建住宅（`home.grantNpcHome(npcId, tier)`），NPC 迁入并影响生态（如徒弟回家练功）。

### 9.4 收徒
- 师徒关系 `character.apprentices = []` / `character.master = id`。
- 指令：`收徒 <npc>`（需声望/境界门槛）、`授艺 <徒> <功法>`（传功消耗内力）、`出师`。
- 徒弟（NPC）按师徒关系获得练武加成与剧情。

### 9.5 自建宗门 + 活动 + 大比
- `sect.js`（新）支持玩家 `开宗立派`：命名/选址/收徒/定规。
- 宗门活动（切磋/除魔/巡守）给贡献；**门派大比**周期性事件，玩家宗门可报名参与，按战力排名发奖励。
