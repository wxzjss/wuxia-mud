## 二、② 门派差事模板（35 派 × 1 条）

**目标**：解决「入门后没事做」，每派 1 条即可，不做全套。结构统一、内容按门派物象：

```json
{
  "id": "q_sect_<sect>_errand",
  "name": "<门派>的差事",
  "type": "门派",
  "giver": "<sect>_master",              // 无掌门 NPC 则挂 _gate 房动作
  "require": { "sect": "<sect>" },        // 非本门不可接
  "stages": [
    { "desc": "<本地物象的一件事>", "targets": [{ "kind": "room|kill|item", ... }], "next": 1 },
    { "desc": "回山门复命", "next": 99 }
  ],
  "rewards": [
    { "type": "+contrib", "args": ["本门", 30] },
    { "type": "+exp", "args": [180] }, { "type": "+pot", "args": [60] },
    { "type": "say", "raw": "<掌门一句>" }
  ]
}
```

**35 派清单**（35 = 43 − 已有 13 条覆盖的 8 派）：摩教/唐门/古墓/星宿/血刀/侠客岛 + 泰山/衡山/恒山/青城/崆峒/昆仑/点苍/铁掌/合欢 + 20 家三流（金刀/五虎/飞虎/镇远/神拳/铁枪/快刀/罗汉/五云/大风云/黄河/太湖/鄱阳/青竹/巨鲸/金龙/无量/伏牛/百胜/白驼）。

**差事类型按门派分配**（每派一个物象，不重复）：
- 刀/枪/剑派：护山（击退来犯 mob）、校场试手（kill 指定 mob）
- 帮派（黄河/太湖/鄱阳/青竹/巨鲸/金龙）：码头/湖面跑一趟（room target + 回禀）
- 镖局（飞虎/镇远）：押一趟货（room target 到邻镇）
- 佛道（少林已覆盖，崆峒/泰山/衡山/恒山）：巡山/扫阶/抄经（room target）
- 邪派（白驼/星宿/血刀/合欢/摩教）：带回一件「不该在山下出现的东西」（item target）
- 唐门/五毒：采一味毒草（item target，复用现有药材）
- 古墓/桃花/大理：已覆盖（古墓/桃花/大理在 13 条里）
- 侠客岛：暂不排（走大典，qa 已确认 43/43 可达）

**验收**：每派造本门弟子 → 接差事 → 走到目标 → 复命 → `+contrib 30` 到账；非本门玩家接不到（require.sect）。

## 三、③ 差事→贡献通道 + 每日巡山

1. **差事 contrib**：上面模板已含 `+contrib 本门 30`（与 69 分片里 `contrib:本门:30` 同口径）。
2. **每日巡山**：每个 `*_gate` 加一条房动作
   - `cmd: '巡山'`，`label: '巡山'`，`keywords: ['巡山','巡视','转一圈']`
   - `cond: {"and": [{"sect": "<sect>"}, {"var": "patrol_<sect>_day", "<": "<today>"}]}`（每天一次；引擎有 day 变量，实现时按现成写法取当日）
   - `effects: [narrate 一句本派山景, {type:'+contrib', args:['本门', 5]}]`
   - **不加经验**（避免刷级），只有贡献。
3. **数值锚**：差事 30 / 巡山 5 / 捐钱 10 文→1 / 大比 60~180。一小时活跃玩家的贡献期望 ≈ 30（差事）+5（巡山）×2 ≈ 40，低于大比但可日常累积。
