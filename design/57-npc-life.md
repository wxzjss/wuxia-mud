## §1 先说最扎眼的一处：**NPC 的钱袋全是 0**

463 个 NPC 里有 322 个写了 `carry` 字段，翻开一看 —— **`money` 全是 0**。
字段是有的，数从来没填过（「只定义不消费」的又一个变体：定义了，没数）。
于是**岳不群和路边乞丐的钱袋一模一样**。

补法（`tools/gen-npc-wealth.js` → `91_npclife.json`）：按「营生 × 分部」给一档家底，档内按 id 哈希浮动。

| 营生 | 钱袋（文） | 实例 |
|---|---|---|
| 太监 / 皇亲 | 5000 ~ 20000 | — |
| 富商 / 官员 | 800 ~ 8000 | 张掌柜 **1812** |
| 镖师 / 剑客 / 郎中 | 60 ~ 1000 | 岳不群 **605**、洪七公 **1218** |
| 农夫 / 船夫 | 5 ~ 120 | — |
| 乞丐 / 难民 | **0 ~ 12** | 小叫花 **6** |

- 分部系数：A 层 ×3 / B ×1.4 / C ×0.6 / mob ×0.25
- **随身物证**：按营生补一件 —— 剑客的伤药、盗贼的碎银、郎中的药、猎人的肉干、文人的书。
  （原来 322 人里大多是空的，「看得出他是个什么人」的物证一件没有。）
- 补钱袋 164 人，作者手填过的一律不动。

## §2 日常：该干什么看他自己的状态（`core/npclife.js`）

`decide()` **不是随机抽**，是看状态：

| 状态 | 干什么 |
|---|---|
| 内力见底（< 三成）且会武 | **打坐**（回四成内力） |
| 身上不到 30 文 | **去挣**（按营生不同的说法：摆渡 / 锄草 / 讨饭 / 打铁…） |
| 内力足 + 有功夫 | **练功**（真的加一级，真的耗内力） |
| 钱多 + 掷骰 | **吃点喝点**（要一碗热汤面 / 两个肉包 / 半只烧鸡…，回一点气血） |

玩家在附近时，屏幕上就是：

> 张掌柜要了一碗馄饨，吃完把碗一推。
> 小叫花讨了半天，讨到 14 文。
> 洪七公在院角打了一遍降龙十八掌，收势时衣角还在抖。
> 岳不群盘腿坐下了，闭着眼细细地调息。

## §3 社交：合不合得来，按性格相性

同屋两个人碰上了先打招呼（**九种性格九套招呼语**），然后按 `affinityOf` 那套规矩判：

- **相性好**（豪爽×豪爽、侠义×侠义…）→ 越说越近，**双方各加一点好感**
- **相性差**（侠义×阴鸷 −8、暴躁×暴躁 −6…）→ 话不投机；差到 −4 以下且两边都有武力，**可能动手**
  > 「{甲}先动了手。三招两式，{乙}被架开，退到墙根站住了。」
  > 「屋里的人往两边让了让，没人上去拉。」

## §4 讲价：老板的性子说了算

`haggle(world, 买家, 卖家, 价)` —— 让步率按老板性格：
**怯懦 0.75 / 豪爽 0.7 / 油滑 0.6 / 温婉 0.6 / 侠义 0.55 / 木讷 0.4 / 冷漠 0.15 / 阴鸷 0.1 / 暴躁 0.05**。
买方越会磨（油滑 0.95 / 暴躁 1.0）越容易成，怯懦的买家 0.5 磨不动。

- 答应：「张掌柜叹了口气：「就这一回。」」→ 价钱真的降了
- 不答应：「张掌柜眼皮都没抬：「嫌贵就别买。」」

## §5 拍卖行竞价：抬急了会结仇

两个硬脾气（暴躁 / 阴鸷 / 豪爽）抬到一块儿，六成概率翻脸：

> {甲}把茶碗往桌上一顿：「你算什么东西，也配跟我抢？」
> {乙}站起来：「这话你再说一遍。」
> 两边的人各自把手按在刀上。掌事的掌柜赶紧出来打圆场，把两人隔开。
> （{甲}从此记恨上了{乙}。）

记恨是真的记下来（`_grudge`），不是一句台词就完。

## §6 宗门大比：不同性格说不同的话

九套开场白：豪爽「请了——别留手，留手没意思」/ 暴躁「三招之内打不倒你，我自己跳下去」/
阴鸷「师兄手下留情」（笑）/ 怯懦「我、我尽力」（声音发紧）/ 冷漠「（把外袍解了，扔给同门）」…

## §7 频率（最容易做坏的一处）

**抽样**，不遍历：每次 tick 只挑 4 个人，且**只挑与玩家同区域**的（看不见的地方不花算力，
也免得满屏陌生人的消息）；同一个人**一天只做一件大事**（`_lifeDay`）。
播报走 `emit('storyline')` → `_tickLines` → 玩家下一条指令时带出来（与 W5/W7 同一条通道）。

## §8 踩的坑（都写进注释了）

1. 🔴 **`.def` 有两副面孔**：在**实例**上它是模板对象的引用（老约定），
   可在**模板自己**身上，`def` 是**防御力数值**（数据里就是 `"def": 180`）。
   第一版直接写 `npc.def.carry`，拿模板跑时当场炸在「Cannot create property 'carry' on number '180'」。
   现在取模板一律走 `tplOf()`（先判 `typeof === 'object'`）。
2. 🔴 **内功的基础武学 id 是 `basic_force` 不是 `basic_neigong`** ——
   测试里写错 id，`getSkill` 取不到，「练了却没涨级」假红一次。
3. 测试自己的老毛病又犯一回：断言只用窄词（前几轮的 `看了` / 这一轮的 `看`），
   而句式里有「对上一眼」这种不含该字的写法。
