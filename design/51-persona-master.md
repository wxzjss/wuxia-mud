## §3 性格数据播种（`tools/gen-persona.js` → `87_persona.json`）

**动手前的问题**：`personality.js` 里九种性格与说辞早就写好了，但**数据层是空的** ——
463 个 NPC 只有 2 个手写过，其余全靠 `personalityForTag` 兜底，而兜底默认值是「木讷」，
结果落成一片木讷（183 人 / 40%），「暴躁」**一个都没有**。相性系统按性格算，一片木讷等于白做。

**分配顺序**：作者手写 → **人物点名表** → 门派气质 → 身份 tag → 名字/描述关键词 → 确定性哈希。

**播种后分布**：油滑 98(21%) · 温婉 88(19%) · 豪爽 65(14%) · 侠义 49(11%) · 冷漠 44(10%) ·
阴鸷 37(8%) · 木讷 28(6%) · 暴躁 26(6%) · 怯懦 25(5%)。

> ⚠️ **点名表是必需的**：第一版只靠「门派 + 哈希」，跑出来**岳不群 = 豪爽、东方不败 = 侠义**
> —— 门派对了、人完全错了。加 `NAMED` 表（约 50 人）后：
> 岳不群/东方不败/左冷禅 = 阴鸷，黄药师/杨过/小龙女 = 冷漠，灭绝师太/任我行 = 暴躁，
> 令狐冲/洪七公 = 豪爽，郭靖/张三丰 = 木讷，韦小宝/赵敏 = 油滑。

## §4 拜师（NPC 面板新增按钮）

`拜师 <人名>` 与 `拜师 <门派名>` 走同一个指令的两条路：
- **拜个人** → `p.masters[mid]`，此后他是你的师父
- **拜门派** → 入山门（原来的 `join`，一行未改）

**收徒条件**（主人把判断权给了我，定的是三条）：
① 他手上得真有货（有能教的、且你还没会的功夫）；
② 不是无名杂辈（C 层且最深的功夫不到 60 级的，自己会说「这几手粗浅把式哪配当人师父」）；
③ 你与他不是陌路（**好感 ≥ 15**，不够就明说缺什么、怎么补）。

成了之后 NPC 面板上「拜 师」变成「请 教」（两者互斥，同一位置只出一个）。

## §5 请教（必定成功）

- `请教 <师父>` → 列出他能教的（**已学会的直接不列**，免得点一个空）
- `请教 <师父> <武学>` → **必定学会到 1 级**，不再看好感与银钱
  （主人原话：「拜师后请教必定成功」）
- **附带把整条 `base` 链一并教给你**：养吾剑法 → 华山剑法 → 基本剑法。
  链上任一环没练上去，衍生功夫的 `effectiveMax` 就被卡死 ——
  玩家学了招式却一级都涨不动，只会当游戏坏了。师父教徒弟本来就该从基本功教起。

## §6 练武学（快捷键 + 面板）

屏幕下方快捷键新增「练武学」，点开是**已学会的各门武学**（一格一门，标着 `等级/上限`），点一门就开始练。

- **自动消耗内力**，内力够就一直练下去（一次最多 60 轮，防内力判据出错时空转）
- 内力见底 / 到进境上限，自动停手并说明原因
- **内力上限越高练得越快**：`learnSkillByTrain` 里加了 `1 + maxMp / 1200` 的加速因子
- 等级越低越快（本来就是 `skillExpNeed(level)` 随等级递增的曲线）
