# 匪类自主行为系统 落地报告

> 对应主人 2026-10-08：
> 「玩家经过一些 NPC 身边时会触发被 NPC 看了的提示…山贼会仔细打量玩家然后判断实力与身上财物，
> 再决定是动手抢劫还是逃跑，还是觉得玩家太穷没抢劫价值但很弱于是打晕玩家卖掉…
> 有武力且性格不同的 NPC 或许会主动攻击山贼打晕装麻袋交给衙门…山贼遇到比他强的会第一时间逃跑，
> 那些有武力的 NPC 会根据性格选择追还是不追（按轻功判断能否追上）…追不上会放弃，
> 此时如果经过玩家身边玩家会触发剧情会弹出是否拦截」
> 版本戳 `?v=20261011e`

---

## §0 先回答主人那句：「有交给衙门这个系统吗？」

**有**，而且是早就有的：`world.arrestCriminal(npc)` ——
犯人类 NPC 被打晕后，若**同屋有官差**（`tag` 为 `constable` / `official` / `escort`），
就会被锁上押回衙门大牢，玩家还能得 100 文赏钱（接了悬赏另算）。

但它原来只挂在**玩家打倒 NPC** 这一条路上。这次把它接到了「旁人打晕山贼」这条路上 ——
**同一个出口，两个入口**。

## §1 这套东西怎么转（`core/outlaw.js`）

一条链，每一环都是**先看，再决定**：

```
① 互看        匪类与旁人互相打量（进屋时按性格给一句）
② 量你        山贼算三样：你的斤两、你身上的钱、你行囊里东西的估价
③ 决定        打不过 → 溜    ·    有油水 → 动手抢    ·    又穷又弱 → 打晕搜刮
④ 旁人        屋里有武力的按性格决定出不出手；打赢了 → 打晕 → 装袋 → 交衙门
⑤ 追逐        匪类遇强第一时间就跑；追不追看性格，追不追得上看轻功
⑥ 拦不拦      追不上、人正好从你身边擦过去 → 弹「拦不拦」
```

### ②③ 山贼怎么量你

三样东西一起算：**实力**（`powerOf`：攻 / 气血 / 内力 / 属性加权）、
**现钱**、**行囊估价**（按物品 `price × count`）。然后：

| 情形 | 结果 | 台词 |
|---|---|---|
| 你比他强 1.45 倍以上 | **溜** | 「他量完了，脸上那点意思就散了…有些账不用算第二遍。」 |
| 你身上过 300 文（含货值） | **抢** | 「路远。留下买路的钱，你走你的道。」 |
| 你身上没钱、又比他弱得多 | **打晕搜刮** | 「穷。」他同旁边的人说了一句，语气很平。 |
| 其余 | 不动 | 「没看出什么值得动手的地方，把眼挪开了。」 |

> ⚠️ 判定顺序踩过一次坑：第一版写的是「有油水 **且** 不算太弱才抢」，
> 于是**又弱又有钱**的人两个条件都不满足，直接落到「不值得动手」——
> 可那明明是最肥的羊。改成**先看有没有油水，再看弱不弱**。

打晕搜刮是**搜走六成现钱**，人没事（玩家不会死，只会昏过去）：
「再睁眼时天已经黑了。你躺在道边，鞋还在，钱袋空了。」

### ④ 旁人出手 —— 也看性格

| 性格 | 出手倾向 |
|---|---|
| 侠义 1.0 / 暴躁 0.9 / 豪爽 0.85 | 基本一定上 |
| 冷漠 0.45 / 阴鸷 0.35 / 油滑 0.3 | 看心情 |
| 木讷 0.25 / 温婉 0.15 / 怯懦 0.05 | 多半只看着 |

打赢了：**打晕 → 装袋 → 有官差就当场交出去**；没官差就捆了搁墙根等巡街的。
打不过就不硬撑（「退后半步，没再上」）。

### ⑤ 追逐 —— 轻功说了算

追不追得上看**双方轻功等级差 + 实力差**，算出一个「优势值」，再折算成追几段街、能不能追上。
轻功差 900 级的人追山贼是几步的事；差 0 级就只追出一条巷子：

> 追出 2 条街，那身影拐进一条窄巷就不见了。{名字}停在巷口喘了两口气，啐了一口，转身往回走。

⚠️ 逃掉的人**真的会换个房间**（`neighborOf` 往外走两站，且**不许绕回走过的地方** ——
第一版会绕回原地，「逃掉」等于没动，玩家下次进屋他还杵在那儿）。

### ⑥ 拦不拦

追不上时若正好从玩家身边过，弹一句：

> 山贼正从你身边擦过去，肩膀撞了你一下——他连头都没回。
> 　① 拦住他　② 让开

拦了：**你 + 追来的那位 + 附近同样够胆的人一起上**（每人 60% 概率跟上）。
人够多就按住，人不够就自己挨一刀 ——「他随手一刀逼开你，从缺口挤了出去。你袖子上开了一道口子。」
选「让开」也有话说：「你侧了侧身。他从你手边擦过去，脚步没慢。」

## §2 频率

**同一伙人一天只闹一次**（`_outlawAt` 冷却 240 分钟），进屋时掷骰（互看 30% / 动手 40%）。
不然走三步被抢一次，那不叫江湖，叫收费站。

## §3 前端

给服务端来的「选择」加了一条通道：行里带 `choices` → 前端**先照常落日志，再弹选择框**
（顺序不能反，否则弹窗会被随后的日志顶掉）。选项点下去就是发一条指令（`拦截 <名字>` / `让开`）。

## §4 测试

`tools/smoke-outlaw.js`（**37 项全绿**）：匪类识别（**不拿 `hostile` 当判据** —— 野兽也是 hostile）、
五种决策分支、打晕真掉钱、旁人出手的胜负两支、追逐的轻重功两支、拦截的胜负两支、
冷却与互看句式、以及「这些句子里没有 AI 腔」。
