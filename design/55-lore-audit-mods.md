## §1 看人分工修正（主人纠正的那处）

**我原来把「看了一眼」放错地方了** —— 塞进了「看」那一路。现在按主人说的分开：

| 入口 | 说什么 | 长什么样 |
|---|---|---|
| 点「看」/「打量」 | **仔细观察**：看得见的证据 | 你仔细打量岳不群——**虎口上有一层茧，右手比左手厚出一分**——是常年握剑磨的。<br>岳不群好像没发觉，又好像早知道了——他连眼皮都没抬。 |
| **点名字**开互动面板 | **看了一眼**（过渡句） | 你朝岳不群那边多看了两眼——这人身上有点说不清的地方。 |

「仔细观察」那句的**证据按营生走**（19 种）：剑客看虎口的茧、郎中看指甲和药色、
乞丐看露在草鞋外的脚趾、官员看袖口那圈官服压出来的暗痕、太监看走路时不动的手。
没有营生的退回看神情（按性格九套）。

「看了一眼」那句随 `npcProfileOf` 一起下发，前端开面板前先落进日志 —— **先抬眼、再细看，读着才顺**。

## §2 设定一致性审计（新 `tools/lore-consistency-check.js`）

**查出 3 类真问题，都修了：**

### ① 重地守卫「一门本派功夫都不会」 🔴 42 人

「华山派的扫地僧」拿着江湖通用的棍法（`jh_staff`）—— **写在名字里的门派和他手上的功夫对不上**。
重地的守卫本来就是藏在自家藏经阁里的高人，改成本派武学：

```
华山派的扫地僧  旧：{ 棍: jh_staff, 内功: jh_neigong }   武器: 竹棍
                新：{ 剑: huashan_sword, 内功: zixia_gong }   武器: 精钢长剑
```

兵刃跟着招式走（挑到剑法就配剑，没有就退回棍），`smoke-npc-skills` 的两条硬不变量仍然成立。

### ② NPC 的 `tier` 与画像 `tier` 打架 🔴 28 人

画像写 A、字段写 B（或反过来）。**以画像为准**（画像是工作室先写的人物设定），
对齐写进 `90_lore_fix.json`（顶层键必须是 `npcs`，包一层 `loreTierFix` 会被合并器忽略 —— 第一版就这么错的）。

### ③ 示例 mod 的 NPC 没有性格 🔴 3 人

`demo_skill/太虚居士`、`demo_npc/白发渔翁`、`demo_quest/游侠` 只有数值和描述，
没有 `tag` 也没有 `personality` → 在性格系统里他们是「没有性格的人」。

> 顺带说：`tag` 决定「细看此人」看得出什么行当细节，`personality` 决定性格相性、说话动词、
> 目击者反应 —— 这两个字段现在等于必填。已补成 `swordsman/lengmo`、`boatman/lengmo`、`swordsman/xiayi`。

**审计里我自己先踩的两条坑**（都是"太聪明的判据"）：
- 「门派武学没有 base 链」—— **基本内功、基本剑法本来就是根**，没有 base 是对的。
  改成三分类：有 base（正常）/ 被别的武学当 base（是根，正常）/ 都不是（孤岛，才报）。
- 「画像提到的门派不存在」—— 中文没分词，`{2,4}` 会把「**在**丐帮」「**当铺对**门」「**皇城**门」整段吃掉，
  报 8 条假警报。**改成反向查**：拿真实门派名去画像里找，找到就比对他的 `sect` 字段
  ——「画像说在丐帮，可他挂在华山」才是真有意义的对不上。

## §4 Mod 制作器完善

制作器本来是**完整的**（13 个 tab：基础 / 房间 / 区域 / 人物 / 物品 / 武学 / 门派 / 剧情 /
对话 / 功能 / 教程 / JSON / 报告）—— 我一开始 grep 漏看了 `tabNpcs` / `tabSkills`，差点误判。

**真正缺的是字段**：NPC 表单只有数值与描述，**这轮新增的四项一个都填不了**：

| 补上的字段 | 作用 |
|---|---|
| 营生（tag） | 「细看此人」看出的行当细节按它走 |
| 性子（personality） | 九种性格下拉 —— 相性、说话动词、目击反应全靠它 |
| 分部（tier） | A 名角 / B 有名字的 / C 寻常人 / mob 杂兵 |
| 门派（sect） | 填 id 归入某派，留空即散人 |

NPC 表单字段数 **17 → 21**。理由是：示例 mod 是给人抄的模板，
**制作器填不出同样的东西，模板就白给了**。
