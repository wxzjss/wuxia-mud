# 第十七轮：存档时间 · 装备 · 绑架判定 · 夜色底 · 青楼线 · 楼里新来的

（2026-10-11）主人一次点七件。全量回归 **90 套全绿**。

## 1 读取存档界面时间全是 1970-01-01 08:00

渲染那一行读的是 `s.time` —— 那是**游戏内的分钟数**（开局 481 分钟），
`new Date(481)` 就是 1970-01-01 08:01。真正的存档时刻是 `s.savedAt`
（`world.serialize()` 里写的 `Date.now()`），一直在数据里躺着，只是没人用。
改成 `savedAt`，并顺手把「游戏内第 N 天」也标出来。

## 2 装备界面

- 屏幕下方快捷条默认加「装备」（面板本来就有，只是藏在 ☰ 菜单里）。
  ⚠️ 老玩家的快捷键存在 localStorage，**默认表加了他们也看不到** ——
  读的时候把「默认有、他这份没有」的追加到末尾（不覆盖他自己改过的顺序与文字）。
- 「状态」面板加一栏装备：部位 + 件名 + 加成。
  加成只从 `it.stats` / `it.attr` 取 —— `recalc` 就是拿这两处算的，
  玩家看到的必须跟身上真生效的是同一份，不另编一套口径。

## 3 绑架成功率

`kidnap.assess(world, p, npc)`：
昏迷 → 100%（必定成功）；否则
`0.18 + 实力差(±) + 残血(≤0.45) + 负面状态(每个 0.08，≤0.24)`，钳在 5%~95%。

🔴 **面板上显示的那份，与真动手时掷的那次骰子，必须走同一个函数**。
两处各写一套，迟早就出现「写着 70% 却打十次输十次」。

新指令 `绑架 <名>`：得手 → **当场套袋（不开打）+ 一段掳人描写**；
没成才撕破脸开打（赢了对方自然晕，回来再点就是 100%）。

**踩的坑**：
- 站着硬掳时，**目标本人会被当成拦路的**（`interceptor` 没排除自己），
  跳出来「一声暴喝：住手！你扛的是什么！」—— 自己拦自己。加 `excludeId`。
- 🔴 **潜伏 bug**：`kdArg(ctx)` 读的是 `ctx.args`，而内置指令的分派是 `entry.run(ctx, args)`
  —— `ctx` 上根本没有 `args` 这个键。于是 `装人 张三` **一直在忽略名字**，
  永远抓房间里第一个晕倒的人（14 处调用点）。参数要从第二参取。

## 4 默认夜色底

主人：「浏览器的夜间模式下此时游戏背景是黑色的更有氛围感，把游戏默认背景改为这样的。」

做法是**留纸、换案子**：`html/body` 改成一整片夜墨（`--night`），
左（sidebar）/ 中（stage）/ 右（scene）三块纸色**不透明**地压在上面，
看着像夜里在书案上摊开的几卷纸；顶栏本来就是深木色，正好连成一片。

⚠️ 三条都得做，少一条就难看：
- 三块面板原来分别是 `.84 / .82 / .9` 的半透明（那是配浅色画布调的）——
  半透明压深底会变成一层灰糊，纸不像纸、字也不清楚。
- 远山（`#bg-art .mount`）原来是深 wash 压浅纸，在夜墨上**一点都看不见** → 翻成淡 wash；
  底部那层白雾会在深底上横一道发光的白带 → 改成融进夜色。
- 声明 `color-scheme: dark`：不然浏览器（主要是移动端自动深色）会再把这套纸色反相一次。

## 5 青楼

**男身默认卖不了身**（主人改的口径）。要卖，得先过一条青楼支线：

`q_brothel_sell`「楼里的门道」（`94_brothel.json`，委托人＝老鸨苗春 `npcv_220`）
1. 在望江阁替鸨母招呼三趟客人（房间动作「招揽」→ `incvar` 计数）
2. 回门厅回话 → 收尾阶段的 effects `flag:brothel_permit`

判据就是这个 flag，**一处两端**：支线给的就是卖身看的那个。
`望江阁`（`jn_brothel_3`）选它是因为它**原本一个 action 都没有** ——
房间 action 是数组、整段替换，往有 action 的房间里塞新的必须把旧的抄回来。

**「接客」原来是一句模板**（「你强颜欢笑，应酬了一夜的客人」），接一百次也是这句。
改成六位客人、六段戏（赶考的举子 / 跑远路的茶商 / 边镇回来的军汉 /
家道中落的老秀才 / 刚接手家业的年轻东家 / 两个结伴的行商），
按 `served` 取下标（**取模步进**，前六次一位不重 —— 别用哈希，撞车就重复）。
