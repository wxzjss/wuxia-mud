## §1 重地（R5 剩下那一半）

| 重地 | 谁有 | 规矩 |
|---|---|---|
| **藏经阁** | 一流 7 家 + 二流 15 家 | **分三层**，按品级分段存**非本门派**武学 |
| **藏宝阁** | 同上 | 武器 / 丹药 / 符箓 / 阵法 / 特殊宝物 / 天材地果 |
| **库房** | 三流 20 家 | 货少、门槛低（小门派配不起藏经阁，合理） |
| **国库** | 皇宫 | 朝廷的东西，比门派阔气也贵得多 |
| **衙门库房** | 衙门 | 原来的 `jn_yamen_store` 补上了守卫与货架 |

**藏经阁三层**（`81_treasury.json`）：

| 层 | 品级 | 门槛 | 进门费 |
|---|---|---|---|
| 外阁 | 七/八/九品 | 外门弟子 + 100 贡献 | 20 |
| 内阁 | 四/五/六品 | 执事 + 400 贡献 | 50 |
| 密阁 | 一/二/三品 | 首座 + 1000 贡献 | 120 |

- **架上是别家的功夫**：`shelfOf()` 会把本门派已授的武学剔掉 —— 想学别派的绝学，得进别派的藏经阁
- **抄录**花贡献（一品 600 / 九品 40），抄完成你自己的
- 贡献来源：门派大比（+60~180）、门派任务；与门派晋升共用一个池子

**守卫**：每处重地一位「扫地僧」级人物，**层级按势力层级配**（`guard.byTier`：一流→A、二流→B、三流→C）。
皇宫的守库太监、衙门的守库老吏都在。拦人时说「牌子不够」。

## §2 战斗外秘技（在 NPC 交互界面用）

**共同规矩**（主人原话落地）：
- **只对实力比自己弱的 NPC 使得出**（`powerOf` 比气血/内力/攻防身法；对方不弱于你 → 直接封死）
- **按实力差距掷骰**：`chance = base × (0.35 + 差距比 × 1.3)` —— 差得越远越稳
- 须**先运起**对应功法（装在槽位上，或作为散手激活着）

| 秘技 | 需运起 | 效果 |
|---|---|---|
| **迷晕** | 基本毒术 / 唐门毒术 / 迷魂手 | 人倒地（可搜身、可装袋） |
| **致幻** | 苗疆蛊术 / 迷魂手 / 奇门遁甲 | 认不得路，**只在附近几条街打转**（`worldTick` 每 tick 挪一格，同区不越界） |
| **注入暗劲** | 基本内功 / 合欢引气诀 / 锦衣内功 | 经脉里埋一缕劲，**任何人打他都吃大亏**（`combat` 里伤害 ×1.6） |
| **暗中下毒** | 基本毒术 / 唐门毒术 / 苗疆蛊术 | 挂持续掉血 |
| **催眠** | 摄魂香 / 迷魂手 / 易容术 | 短时间对你言听计从（好感大涨，有时限） |
| **采补** | 合欢采补大法 | 见 §3 |
| **双修** | 双修秘要 / 合欢采补大法 | 双方内力上限各涨，好感涨（与采补不同：对方知情） |

**UI**：NPC 详情面板底部多了「秘 技」「结 缘」两个按钮。
秘技面板把**能不能用、几成把握、为什么不能用**都写出来（数据由 `arts.listFor` 算好，前端只画按钮）。
失手不是「什么都没发生」——对方会留了心（好感 −4）。

## §3 合欢宗（青楼背后的势力）

- 门派 **43 家**里的一员，**二流**，据点就设在**青楼区**（`region: qinglou`），山门/演武场/掌门齐全
- **入宗不走拜师**：先在青楼**卖身**（男身也可以 —— 这一条是本轮放开的），再**接待满十位**，
  宗里自有人来问一句话，答了就把素色牌子推给你
- **关系**：与华山 −45 / 少林 −50 / 武当 −40 / 峨眉 −35；与魔教 +25、星宿 +30、五毒 +20
  （梁子文案：少林说它「以人补人」，合欢宗说少林管得宽…）
- **功法**：15 门（二流 = 核心二品 / 中阶五品 / 入门八品），招式带「惑」（`confuse`）；
  核心三门另给了名字与说明（合欢引气诀 / 双修秘要 / **合欢采补大法**）

**采补**（主人定的数）：
- 每次抽走对方**当前内力上限的 1/10**，转成自己的内力上限（改的是 `maxMpBase`，不是当下的余量）
- **同一个人最多被抽 10 次**（`vars.drained` 记账，用完就取不出东西了）
- 冷却 6 小时；对方「记得」的是**自己愿意**，但反应按性格与有没有家世分岔
  （有家世的匆匆走了 / 性情刚烈的摔门 / 其余的笑着当没事）

**迷惑类**（`charm`）：好感越高越容易成（`baseChance + 好感/300`，上限 +0.35），
成功后好感 +40 但**有时限**（120 分钟）；采补一次会把这份好感提前抹掉。

## §4 结缘线

NPC 面板点「结 缘」→ 打开新的互动面板：

```
未表白 → [ 表 白 ]              （异性、好感 ≥40，成功后成为男女朋友）
       → [ 结 义 ]              （拜把子，走既有 makeBond）
已表白 → [ 结 婚 ] [ 纳 妾 ]     （走既有 propose / takeConcubine）
同性   → 明确告知走不通
```

- **必须先表白**：`提亲` 与 `纳妾` 两条指令都加了门禁（"先去表白 <人名>"）。
  门禁只加在**指令层**，不动 `marriage.js` 的 API —— 剧情与测试直调仍走得通。
- 表白成功进 `p.lovers`（面板会显示「已说开」）；表白失败好感 −6。
- 已有婚配的人会提示「已与某某有约」。

## §7 顺手修掉的坑

- **两个生成器往同一间房上加出口**，把对方的边写坏（合欢宗山门 ↔ 藏经阁）。
  规矩改成：**host 只从原始地图（`50_map.json`）里挑**，各生成器互不越界。
- **`learnSkill` 会把新学的自动塞进空槽** → 测试里「没运起功法」根本测不出来（一学就运着）。
- **`powerOf` 只看加权属性**：给测试靶子单独加内力上限，会让它反而"强过"玩家 —— 秘技全被封死。
- **`actions-check` 是同一个角色把全图 action 走一遍**：走过青楼执行一次卖身，后面所有打工全被拦。
  已把 `sellbody` 排除并注明（它是不可逆的身份改变，交给 `smoke-survival` 专测）。
- **改完生成器忘了重跑** → 合欢宗只有藏经阁没有山门（"数据看着全，实际半截"）。
- 旧断言随内容增长过期 6 处（门派数 42→43、男身卖身由「拒绝」改「获准」、门派名后缀要认「宗」等），
  已逐条更新并注明原因。
