## §0 一句话

### 主人口径 R1 / R2 / R5

- **R1 品级 = 147 / 258 / 369**：一流 1/4/7、二流 2/5/8、三流 3/6/9 —— 数据层已按此生成，并有断言钉住
  （`smoke-sects` ③：没有落在本层品级之外的自家武学）。
- **R2「单独激活 3 本」判据 = 有没有基础武学**：新增《基本暗器》《基本毒术》《基本医术》《基本乐理》四门基础武学；
  毒术/医术照样绑定激活；真正无根基的散手（醉八仙/奇门遁甲/龟息功/易容术/缩骨功/辟毒诀）进池，合计 ≤3。

  「藏经阁三层 / 藏宝阁 / 国库衙门 / 扫地僧守卫」**仍是设计待落稿**（见 §5）。

## §3 引擎改动（按文件）

- **`character.js`**：`effectiveMax()` / `skillRoot()` / `isStandalone()` / `standaloneActive`；
  `learnSkill(id,{force})` 卡 base 链；`maxSkillLevelFor` 上限公式重标定（`wis*10+apt*14+ngLv*1.2`，凡人 240 起、绝顶摸到 1000）；
  `profTierOf` 分母改 `effectiveMax`；导出 `SLOT_ROOT` / `STANDALONE_MAX`。
- **`combat.js`**：`oneAttack(..., move)` 支持武技（额外内力/体力、倍率、额外效果）；
  `applySkillEffect` 新增 `confuse` / `silence` / `mp` / `aoe`；`isConfused` / `isSilenced` / `alliesOf`；
  `pickSkill` 先判封穴、武器槽表补 `音波`；`step` 里迷幻改打同侧。
- **`world.js`**：`combatStep` 支持 `{skill, moveId}` + `battle.cooldowns`；`stepEnemyOnly` 迷幻/冷却递减；
  `initWorldDynamics` 支持 `relationsOverride`；`factionFeudOf` / `factionRelWord`；
  `onRoomEnter` 加门派摩擦。
- **`commands.js`**：`enable` 绑定校验 + 散手池；`perform` 支持武技名；
  新增 `bid` / `consign` / `auction`(文本兜底) / `寻访` / `邦交` / `门派大比`。
- **`auction.js`（新）**：场次懒生成、拍品（固定池 + 按品级加权的高价值位）、NPC 跟价、落槌、寄拍结算。
- **`modapi.js`**：`learnskill` 效果走 `force`（剧情传功不算自学）。
- **`engine.js`**：`skillList` 下发品级/绑定基础武学/上限来源/槽位/武技；新增 `auctionView`。
- **`ui.js`（含 `server/public` 副本）**：武学面板改三块（已激活 / 散手 / 未激活 + 上限提示）；
  战斗快捷栏加「已激活武学的武技」按钮；新增拍卖行面板；快捷栏加「拍卖」。

## §6 顺手修掉的坑

- `map-check` 只读单个 JSON 文件 → 增量数据整体逃检（假绿）；已改为并入 73。
- 门派 `entrySkills` 过滤时漏了 71 里的新基础武学 → 唐门/五毒弟子拿不到《基本暗器》《基本毒术》，本门功夫永远 0 级。
- NPC 武学槽写成了「武器」（**装备**槽）→ `pickSkill` 认不出来，新门派掌门只会抡拳。
- `门派大比` 别名被 sectFounder 抢注（`reg` 后者覆盖前者）→ 打「门派大比」只会得到「你尚未创立宗门」。
- 高价值位抽到 6/7/8 品时无书可出 → 整档落空；改为退到最接近的品级。
- 门派山门出口与「入内堂」方向撞键（`{n: hall, [OPP[dir]]: host}` 当 dir='s' 时同键）→ 演武场成孤儿。
- 门派摩擦用「一辈子只说一次」的布尔标记 → 走开一步回来就装不认识；改成按游戏时辰冷却。
