# 掳人 · 奴役 · 护院 系统规格（SPRINT3-B）

> 需求来源：主人三轮追加
> ① 「青楼可以为别人赎身 / 把晕倒的 NPC 装进麻袋带走 / 醒来会报官 / 按性格反应 / 路人议论报官 /
>    武艺高会拦你 / 麻袋里武艺高于玩家会冲出来杀你 / 被装的人可卖进青楼或地下场所」
> ② 「性格恶劣、贪财、非善的亡命之徒 NPC 也会概率这么做」
> ③ 「NPC 会掳走晕倒的玩家与其他 NPC；山贼会主动打晕路人装袋去卖；玩家可主动买奴隶；
>    家园可买护院（每天工资）；奴隶可干活/跟随（好感>60 且会因事离开）；
>    护院可监督奴隶干活（否则低服从度逃跑）；奴隶打完工回家园/客栈等待并交钱；
>    服从低的会反抗逃跑」

---

## 零、设计红线（先立规矩，实现必须守）

1. **这是「玩法」不是「奖励」**：掳人给的是钱和人力，**代价按大明律来定**（见 §十一）。
   现实里「略卖良人为奴婢」是**杖一百、流三千里**的重罪，
   略卖三人以上或再犯 → **枷号一月、发边充军**，三次 → **极边永远充军**。
   游戏里就照这个阶梯给 wanted，侠义 NPC 见面即敌、官府必然追查。
2. **不得凭空生成 NPC**：一切被掳的人必须来自 `world.instances.npcs` 里的真实实例
   （`spawnNpc` 出来的），不许临时造人。
3. **麻袋里的人不许凭空消失**：从 `instances.npcs` 摘出来后，必须在 `p.kidnap.bags` 里留完整快照
   （含 defId / 属性 / 好感 / 画像），醒来时能原样装回去，存档也能往返。
4. **不改动既有 P0 修复**：`def` = 模板引用、`defFinal` = 防御力数值、`hp=maxHp` 出生满血、
   `countItem` 按 count 累加 —— 这几条血泪约定本系统一律遵守。
5. **随机源统一走 `world.rng`**（xorshift32，seed 固定），测试才可复现。禁止裸 `Math.random()`。
6. **不可逆操作要留痕**：卖进青楼/地下场所后，那个人从此属于对方，不在本系统里复活。
7. **蓄奴按律法限额**（主人「参考现实古代情况」的落点，见 §十一·三）：
   明清律法对奴婢数量有明文限制，且**买奴知情与略卖同罪** —— 所以：
   - 奴数上限按玩家**家资等级**（不是随便就能买满）；
   - 在青楼/黑市**公开买奴本身就是重罪**，被撞见即重罚。

## 一、数据结构

### 1.1 玩家私有数据 `p.kidnap`

```js
p.kidnap = {
  bags: [ /* 麻袋 */ {
    uid, npcId, defId, name, gender,           // 身份
    putAt,                                      // 装进去的时刻（world.clockMinutes）
    wakeAt,                                     // 预计醒来时刻（按概率算出来）
    state: 'out' | 'struggling' | 'burst',      // 昏迷 / 挣扎 / 已冲出
    hurt: 0.35,                                 // 重伤比例（醒来时 hp = maxHp * hurt）
    burstTried: false,                          // 是否已试过冲出来
  } ],
  slaves: [ /* 奴役 */ {
    uid, npcId, defId, name, gender,
    boughtAt, buyPrice,
    obedience: 60,      // 服从度 0~100
    favor: 30,          // 好感 0~100
    task: null,         // 当前派的活 { kind, at, until, earning }
    fatigue: 0,
    escaped: false,
  } ],
  guards: [ /* 护院 */ {
    uid, npcId, defId, name,
    hiredAt, wage,       // 日薪
    power,               // 武艺值（用于判定能否拦住逃跑的奴隶）
    loyalty: 60,
  } ],
  wageDue: 0,           // 欠薪（跨天才发）
  wanted: 0,            // 掳人恶名（0~100，影响被报官概率）
}
```

### 1.2 麻袋物品

新增物品 `sack_coarse`（粗麻袋）：
- `type: 'tool'`、`value: 30`、`tags: ['sack']`
- `desc`: 「一只粗布麻袋，口子用麻绳扎着。装人装货都成。」
- 玩家初始行囊给 1 个（`00_core.meta.startItems` 加一项）。

### 1.3 NPC 模板补充字段

给 `40_npcs.json` 的 NPC 增可选字段（**不改已有 320 条的数值**，只补「恶人」标记）：

```json
"wickedness": 70,          // 恶性 0~100：掳人/卖人的倾向（缺省按 personality+tag 推断）
"greed": 60,               // 贪财 0~100：见钱眼开的程度
```

推断规则（`kidnap.wickednessOf(npc)`）：
- 模板显式写了就用模板的
- 否则按 tag：`thief/gambler` +40、`escort` +10、`official/constable` −30
- 否则按 personality：`yinzhi/baozhao` +20、`youhua` +15、`lengmo` −10、`xiayi` −25

## 二、玩家侧：装麻袋

### 2.1 指令

| 指令 | 别名 | 作用 |
|---|---|---|
| `装人 <人名>` | `麻袋 <人名>`、`掳 <人名>` | 把地上**已晕倒**的 NPC 装进麻袋 |
| `扛麻袋` | `扛人`、`背麻袋` | 查看/携带状态（把袋子甩到肩上） |
| `放人` | `放出来`、`松袋` | 把袋里的人放出来（可能反抗/逃走） |
| `卖人 <人名>` | `转卖`、`鬻` | 把袋里的人卖给青楼/地下势力 |
| `赎人 <人名>` | `赎身`、`赎` | 在青楼为 NPC（甚至自己）赎身 |
| `买奴` | `买人`、`买奴隶` | 在地下场所买人 |
| `卖奴` | `发卖` | 把已买的奴隶转卖 |
| `奴册` | `奴隶`、`我的奴`、`名下` | 查看名下奴/护院/麻袋一览 |
| `使唤 <人名> <活>` | `派活`、`干活` | 派工（做工/跑腿/采买） |
| `跟随 <人名>` | `跟班`、`带上` | 邀请跟随（好感>60） |
| `雇护院` | `买护院`、`请护院` | 家园雇护院（每日工资） |
| `发工钱` | `发饷`、`付薪` | 结清护院欠薪 |
| `监督` | `盯梢`、`看紧` | 让护院去盯某个奴隶 |

### 2.2 装人的前置条件（缺一不可）

1. 玩家在同一房间。
2. 目标 NPC 满足 `npc.knockedOut === true`（战斗打晕的算；**只有晕的能装**，活人不行）。
3. 玩家行囊里有 `sack_coarse`，且 `p.kidnap.bags.length < 3`（最多扛三个）。
4. 目标不是关键 NPC（有 `def.hostile` 且是 BOSS / 有 `def.quest` 的不装）。

### 2.3 装人的当场代价（主人明确要求）

**「如果当作别的 NPC 面前这样做，那么 NPC 必定报官」** —— 只要**场内有目击者**，装人当刻即判定：

```
目击者 = 同房间、清醒（非 knockedOut）、非敌对 hostiled 的 NPC
```

- 至少 1 名目击者 → `p.kidnap.wanted += 1`，立刻有人喊「有贼！」，且**必报官**
  → 之后所在区域内官差会来查（见 §四 报官机制）。
- 目击者性格影响反应与传播速度（见 §三 性格反应表）。
- 无目击者（深夜/荒野/密室）→ 不报官，但 `wanted` 不涨（只是有风险）。

### 2.4 武艺拦截（主人明确要求）

**「若是 NPC 有武在身则会试图拦下你」**

同房间里有武艺值高于玩家 `interceptable` 的 NPC（非敌对）→ 它会当场喊破并**进入战斗**
（或至少喝止，被你「打晕」脱身）。判定：

```
martialPower(npc) > martialPower(player) * 0.8
```

拦截成功 = 该 NPC 加入战斗，麻袋动作被中止（人没装上）。

## 三、麻袋里的人：醒来与反应

### 3.1 醒来概率（主人：「一段时间有概率醒来，时间越久概率越大」）

每次 `world.advanceTime` 推进时，对每个袋里的人判定：

```
minutesIn = now - putAt
// 概率随时间递增，上限 85%
rate = min(0.85, 0.04 + minutesIn / 90)
if rng.chance(rate) → 醒来
```

醒来后 **hp = maxHp * 0.35（重伤）**，无法行动，`state = 'struggling'`。

### 3.2 性格反应（主人：「根据不同 NPC 性格会做出不同反应，比如哭泣或惊恐大喊大叫或愤怒大骂」）

| 性格 | 醒来反应（袋内） | 喊叫强度 |
|---|---|---|
| `qienuo` 怯懦 | 呜呜咽咽地哭，不敢挣扎 | 0.35（小声哭） |
| `wenwan` 温婉 | 柔声求饶「好汉饶命」 | 0.4 |
| `mune` 木讷 | 闷声不响，蜷成一团 | 0.15 |
| `lengmo` 冷漠 | 一言不发，冷冷地盯着你 | 0.1 |
| `youhua` 油滑 | 油嘴滑舌地套近乎，趁机求饶 | 0.45 |
| `baozhao` 暴躁 | 破口大骂「王八蛋！有种放我出去！」 | 0.8 |
| `yinzhi` 阴鸷 | 阴恻恻地笑「你敢动我？」 | 0.6（威胁型） |
| `haoshuang` 豪爽 | 破口大骂 + 挣扎最凶 | 0.85 |
| `xiayi` 侠义 | 厉声呵斥「光天化日掳人！」 | 0.75 |

`喊叫强度` 决定后续被路人听见的概率（见 §3.3）。

### 3.3 路人议论 / 报官（主人：「玩家路过其他 NPC 时根据不同性格那些会议论纷纷甚至报官」）

玩家扛着麻袋**进入新房间**时，若房内有清醒 NPC：

```
被听见 = rng.chance(shoutStrength * 0.5)
```

听见之后的分流（按性格）：

| 性格 | 反应 |
|---|---|
| `xiayi` 侠义 | **当场报官 + 喊打喊杀**（拦你，见 §2.4） |
| `baozhao` 暴躁 | 破口大骂「你在搞什么鬼！」，引人围过来 |
| `lengmo` 冷漠 | 瞥一眼，默默走开（不报官，但有概率记住 → 议论扩散） |
| `qienuo` 怯懦 | 吓得绕道走，不报官 |
| `youhua` 油滑 | 围上来套近乎打听，八卦传播 → **传播到官府的渠道** |
| `wenwan` 温婉 | 轻声劝阻，会去报官（概率 60%） |
| `haoshuang`/`mune`/`yinzhi` | 议论纷纷，欠口唾沫星子，`wanted` 缓慢上涨 |

**议论扩散**：`wanted` 每被 3 次目击 +1。`wanted` 越高，官府追查越紧。

### 3.4 冲出麻袋（主人：「若麻袋里醒来的 NPC 武艺高于玩家则有概率从麻袋里冲出来誓要杀你」）

```
if (martialPower(npc) > martialPower(player)) {
  if (rng.chance(0.25 + (powerGap / powerRatio) * 0.15)) → 冲出
}
```

冲出结果：
- NPC 重伤但肾上腺素爆发，`hp = maxHp * 0.5`。
- 若玩家 hp < 玩家 maxHp*0.5 → NPC 直接攻击玩家并逃跑（玩家重伤濒死）。
- 否则 NPC 逃跑，`npc.vars.swearRevenge = playerName`，`wanted += 2`。
- 逃到 `nearestEatery` 附近的随机房间（养伤），**3 天后** 回来找玩家复仇（`npcdown` 触发）。

### 3.5 报官 / 通缉机制（§2.3 的后果落地）

```
p.wanted += 1                        // 现有字段，farm.js 已用
w.kidnapReports = (w.kidnapReports||0) + 1
// 官差追查：每次 advanceTime，若 wanted >= 3，在玩家所在区域官差房生成「巡捕」追玩家
```

`p.wanted >= 5` → 官府发通缉令，接 `通缉` 指令可被追捕（复用现有 bounty 机制）。
被追上 → 玩家被关进 `w.jail`（复用现有 jail 机制）+ 麻袋全部被官府查获充公。

## 四、青楼赎身 / 买奴 / 卖人

### 4.1 赎身（主人：「青楼可以为别人赎身」）

在青楼房间（`/青楼|楚馆|平康坊/`）：

```
赎人 <人名>
```

- 若 `人名` 是自己 → 复用现有 `work.redeem`（还债）。
- 若 `人名` 是 NPC（该 NPC 在青楼名册里）→ 付「赎金」（按 NPC 品级 300~5000 文）
  → NPC 恢复自由身，`favor +60`，成为可用「跟随」的对象（好感够）。

### 4.2 卖人（主人：「被装进麻袋的 NPC 可以被玩家买进青楼或其他地下场所」）

```
卖人 <人名>
```

- 只能卖**在麻袋里的人**或**已买的奴隶**。
- 目的地随机：青楼（女/男 → 分别为妓院/清倌馆）、地下场所（黑市 / 秘境·黑市 / 牙行）。
- 卖价 = NPC 品级基价 × 恶性折价（恶性越高越便宜，因为难管）：
  ```
  base = 200 + level * 80 + attrTotal('资质') * 12
  price = base * (1 + greed/200) - wickedness * 4
  ```
- 卖出去 → **NPC 从玩家控制中永久移除**，进入 `w.soldSlaves[defId]`（青楼/黑市名册）。
- 玩家得钱，`karma -= 3`，`reputation.仁义 -= 1`。

### 4.3 买奴（主人：「玩家甚至也可以主动去买奴隶」）

在地下场所（黑市/牙行）：

```
买奴
```

- 有价目表（按品级 1~9 品），随机刷 3~5 个「待售」NPC。
- 买入 → 进入 `p.kidnap.slaves`，初始 `obedience 50 / favor 20`（买来的不认人）。
- 交易本身不涨 `wanted`（有合法牙行掩护），但若在**青楼以外**公开买妾被官差撞见 → `wanted += 1`。

## 五、奴隶系统（主人第三轮）

### 5.1 名册

```
奴册
```

分三栏：**麻袋里**（待处理）、**奴**（已买）、**护院**（已雇）。

### 5.2 使唤干活（主人：「玩家可要求奴隶干活」+ 工钱结算）

```
使唤 <人名> <活>
```

活种：
- `做工`：土工/搬运，日结 80~200 文，耗时 4 个时辰（400 分钟）
- `采买`：进城采买，来回，日结 60~140 文
- `跑腿`：送信看家，日结 30~60 文
- `洗衣`：家务，日结 40 文

**完成的判定**：每 15 分钟推进时检查 `task.until` 到了没，到了就：
1. 玩家 `p.money += earning`（钱是**直接给玩家**的，符合主人「给玩家赚钱」）
2. 奴隶 `obedience += 2`（被使唤听话会稍微更服）、`fatigue += 30`
3. **奴隶回到玩家家园等待**；无家园 → 回**最近的客栈**等待（用 `w.nearestEatery`）。
   → 打工人作息：辰时（480）开工，酉时（1080）收工 ≈ 主人说的现实作息。
4. 玩家回房间时可 `收工钱` 结算显示。

### 5.3 夜间打工惩罚（主人明确要求）

**「除了了一些喜欢夜晚出行的 NPC，夜间让 NPC 打工会大幅降低服从度」**

```
若 workAt is 夜间（19:00~05:00）:
  若 NPC 模板有 def.schedule.day != def.schedule.night（作息与常人不同 → 夜猫子）
    → 不扣（这人是「喜欢夜晚出行」的）
  否则 obedience -= 12, fatigue += 40
```

### 5.4 服从与逃跑 / 反抗（主人：「服从度低的奴隶有概率试图反抗或逃跑」）

每次推进时对每个奴隶判定（**仅当没有主人在场时**）：

```
free = obedience >= 80 || favor >= 80        // 主人：「除非服从度>80或好感度>80」
supervised = 该奴隶当前被护院盯着

if (!free && !supervised) {
   // 极大概率逃跑（主人：「有极大概率逃跑」）
   if (rng.chance(0.30)) → 逃跑（转 slave.escaped，玩家可追）
   else if (rng.chance(0.10)) → 反抗（对玩家或护院触发战斗）
}
if (free) 逃跑概率极低（0.02），反抗 0.01
```

**反抗触发战斗**：若主人在附近 → 奴隶与玩家战斗；玩家不在 → 与监督的护院战斗。
（复用现有 `combat` 引擎的 NPC 对玩家战斗入口。）

### 5.5 跟随邀请（主人：「增加邀请跟随系统，好感度>60，且 NPC 有概率有事离开」）

```
跟随 <人名>
```

- 条件：`favor > 60`，且 NPC **不在麻袋里**、不是奴隶（奴隶本来就跟随不了主人走远）。
- 成功后 NPC 加入玩家队伍（`npc.followPlayer = true`），移动时跟随。
- **「有概率有事离开」**：每次推进时 `rng.chance(0.01)` 触发一次「有事」事件，按 schedule 走：
  - 吃饭 → 去 `nearestEatery`（1 小时后回来）
  - 回家睡觉 → 回 `def.home`（夜间）
  - 办事（见恩人/采买/送信）→ 去别的房间（2~3 小时）
  - **触发后玩家可用「随行/回来」召回**，但会降低好感 −3（人家有事你还催）。

## 六、护院系统（主人：「增加为家园购买护院功能，每天要给护院工资」）

### 6.1 雇护院

```
雇护院
```

- 只能在**玩家的家园**（`p.homes[0]` 或自己开的宅院房间里）雇。
- 价：`200 + power * 60`（一次性），日薪：`30 + power * 12`（每天结算）。
- 护院 `power = martialPower(npc)`，武力越强越贵（主人明确要求）。
- 每个家园最多 3 名护院。

### 6.2 每日工资（主人：「每天要给护院工资」）

跨天判定（`world.clockMinutes / 1440` 变化时）：

```
dailyWage = Σ guards.wage
if (p.money >= dailyWage) → 扣钱，忠诚 +1
else → 欠薪累进 w.wageDue += dailyWage，loyalty -= 8
     loyalty <= 20 → 护院跑路（离职，骂你一句）
```

- 玩家可 `发工钱` 一次结清（含欠薪），忠诚大幅回升。
- 欠薪 3 天 → 护院跑，且 `wanted` 不涨但名声受损（reputation.义气 −）。

### 6.3 监督（主人：「让护院去盯着奴隶去工作，否则该奴隶有极大概率逃跑」）

```
监督 <奴隶名>
```

- 需要至少一名**空闲**护院（护院同时只能盯一个奴隶）。
- 效果：该奴隶本轮 `supervised = true` → 不触发逃跑/反抗。
- 护院武力与奴隶比较：`guard.power >= slave.power` 时监督有效；
  若护院打不过 → 监督失败，且护院重伤（`hp * 0.6`），**奴隶还是逃了**。
- 监督期间护院不会做别的事（不能同时监督两个）。

## 七、NPC 反向掳人（主人第二、三轮）

### 7.1 亡命之徒 NPC 掳人（主人第二轮）

每次 `worldTick()`（30 分钟一次）对同房间 NPC 判定：

```
wicked = kidnap.wickednessOf(npc)
if (wicked < 50) skip
rate = (wicked - 50) / 300 * (night ? 0.15 : 0.05)   // 夜里更敢干
if (rng.chance(rate)) → 掳人事件
```

目标优先级：**晕倒的 NPC > 玩家（若玩家单独且非.pk 状态）> 其他清醒 NPC（女性/无武优先）**。

### 7.2 山贼主动掳人卖（主人第三轮）

`mob_bandit` / `mob_bandit_chief` / `mob_assassin` / `mob_mo_disciple` 这类 `hostile` 山贼：

- 他们**本来就会主动攻击**（现有 `hostile` 机制）。
- 打完把玩家打晕后 → 有概率（60%）**把玩家装进麻袋扛走卖进黑市**（主人：「NPC 会掳走晕倒的玩家」）。
- 也会主动**打晕路过的 NPC 装袋带走**（主人：「山贼…甚至会主动把玩家或其他路过的 NPC 打晕装进麻袋卖」），
  触发条件：房内除玩家外有 NPC 且山贼数量 ≥1，概率 30%。
- 后果：玩家被卖掉 → `p.kidnap.capturedBy = { by, at, until }`，
  醒来在黑市（`秘境·黑市` 或该 region's 黑市房间），
  **要么赎自己（付钱），要么给黑市打工还债（转成 `w.jail` 式的债务）**。

### 4.4 玩家被掳后的四条通路（主人钦定：赎 / 打工还债 / **武力突围** / 死亡）

玩家被山贼/亡命徒打晕装袋卖进黑市后，醒来在 `秘境·黑市`（或该 region 的黑市房间）。
**四条出路**：

| 通路 | 条件 | 后果 |
|---|---|---|
| **① 掏钱赎回** | 有 `赎回价`（`800 + level*200` 文） | 自由身，但 `wanted` 不减（你确实被卖过） |
| **② 为黑市打工还债** | 无钱时可选 | 债额 = 赎回价，分 5 天，每天工钱抵债；期间行动受限 |
| **③ 武力突围**（主人指定） | `martialPower(player) >= 镇场武者.power` | **直接打赢看守打出去**，钱货两失但保住自由 |
| **④ 死亡** | 突围失败 | `deathCount + 1`，在黑市重生，债务翻倍 |

**「镇场武者」（主人：「如果你武力够强能打过黑市那些高价钱聘请来的武者」）**：
黑市高价聘请的高手，实力档位随黑市等级递增：

| 黑市 | 镇场武者 | 战力门槛 | 备注 |
|---|---|---|---|
| 秘境·黑市 | 独眼男人（`mob_blackguard`） | `power >= 260` | 主角级难度，劝退 |
| 各地黑市（东市/平康坊地下） | 寻常护卫 ×2 | `power >= 120` | 打赢给 200~400 文「私活钱」 |
| 官媒牙行 | 书吏 + 护丁 | `power >= 80` | 最低门槛，新手可闯 |

**突围设计要点**：
- 战斗是**真实 combat 引擎**对打（不是掷骰子），看守有名字、有属性、会死。
- 看守 `power` 用 `martialPower` 算；玩家低于门槛不是必败，而是**被打趴**（进通路④）。
- 高于门槛 1.2 倍 → **秒杀**，看守死，玩家还搜一笔钱（战斗后掉落）。
- 突围成功 `wanted -= 1`（黑市本身就是法外之地，官府睁只眼闭只眼）。

### 7.4 玩家被掳的判定（山贼打晕后）

```
victim = 玩家
if (rng.chance(0.60)) → 被卖（进黑市，见 §4.4）
else → 搜刮后放走（丢钱丢装备）
```

- 结果：那人消失（进 `w.soldSlaves`），若玩家后来去青楼赎人可能就是他。

## 十一、平衡（按律法定，不拍脑袋）

### 一、掳人代价 —— 照《大明律·刑律·贼盗》「略人略卖人」条

> 「凡设方略，而诱取良人及略卖良人为奴婢者，皆杖一百，流三千里。…」
> 万历条例：略卖三人以上或再犯 → 枷号一百斤一月，发边充军；三次 → 极边永远充军。
> **知情买方与犯人同罪。**

游戏化成一档 `wanted`（0~100），**换算成律罪档位**：

| wanted | 律罪档 | 现实对照 | 游戏后果 |
|---|---|---|---|
| 0~2 | 未及罪 | — | 没人管，但欠债/欠名声的账已经记上 |
| 3~5 | 杖一百 | 初犯 | 官府派差役查你；侠义 NPC 见你举报 |
| 6~11 | 流三千里 | 略卖成案 | 官差**主动追杀**；城门盘查；门派把你逐出 |
| 12~19 | 枷号一月 + 充军 | 略卖三人以上/再犯 | 抓进牢 3 天 + 全部麻袋充公；`karma` 大跌 |
| 20+ | 极边永远充军 | 三犯 | **永久敌对**：所有官差见面即捕，客栈酒馆不收留 |

**关键设计**：单次装人不涨 wanted（只是记在 `p.kidnap.reports`），
**要「卖出去」才涨 wanted**（因为「略卖」才论罪，「略」未卖按律也罚但轻）。
→ 所以「装了不卖」有窗口期去青楼/黑市脱手，脱手那一脚才是致命的。
**主人规则照办**：装人当刻只要有 NPC 在场，**必定报官**，`reports +1`（一次告发）。

### 二、买奴规模 —— 照唐律《唐会要·奴婢》「王公之家不得过二十人」的限额精神

现实里的限额是**身份越高可养越多**，普通平民根本没资格养奴。
游戏里照这个逻辑，用玩家**家资等级**（由宅院/地块/家产折算）当上限：

| 家资等级 | 依据 | 奴上限 | 护院上限 |
|---|---|---|---|
| 寒素 | 无宅无产 | **0**（买不了，只能赎） | 0 |
| 小康 | 有一处宅院 | 3 | 2 |
| 富户 | 宅院 + 二级地块 | 8 | 3 |
| 豪家 | 宅院 + 四级地块 + 存钱过万 | 15 | 4 |
| 巨室 | 全地块 + 家产五万 | 30 | 6 |

> 「唐会要」：一品 12 人、二品 10、三品 8、四品 6、五品 4、六品 2、八九品 1。
> 按身份给数，一品比九品多十几倍 —— **上限是身份给的，不是钱给的**。
> 钱只决定买不买得起（汉代奴市价「一二万钱，约合一二亩膏腴田」）。

**护院另有硬上限 6**（现实里奴多则必然配兵，且「僮仆成林」本身就是逾制的把柄）。

### 三、奴价 —— 照汉代奴市「一二万钱 ≈ 一二亩膏腴田」

现实折算：1 文 ≈ 今天的 1 元量级，一亩地 ≈ 5000 文 → **一个奴 ≈ 5000~10000 文**。
但本作起始资金才 200 文，直接照搬会让玩家一辈子买不了奴。
按本作经济缩放 **200 倍**（即游戏内 1 文 ≈ 现实 5 文的意思）：

| 品级 | 现实价 | 本作缩放后 |
|---|---|---|
| 九品（凡人/苦力） | 5000 文 | **25 文** |
| 八品 | 1 万 | 50 |
| 七品（有一技之长） | 2 万 | 100 |
| 六品（会武） | 3 万 | 150 |
| 五品 | 5 万 | 250 |
| 四品以上 | 10 万+ | **500+**（还要有关系才买得到） |

### 四、其他数值

| 项 | 数值 | 依据 |
|---|---|---|
| 麻袋价 | 30 文 | 粗布麻袋，便宜 |
| 卖人价 | `(200 + level*80 + 资质*12) × (1+贪财/200) − 恶性*4` | 见 §4.2 |
| 买奴初始 | 服从 50 / 好感 20 | 买来的不认人 |
| 工钱 | 做工 80~200 / 采买 60~140 / 跑腿 30~60 / 洗衣 40 | 高于奴价才值得买 |
| 作息 | 辰时 480 开工，酉时 1080 收工 | 主人指定的现实打工人作息 |
| 夜间打工 | 服从 −12（作息异禀者免疫） | 主人指定 |
| 逃跑概率 | 无监督且不服 0.30；反抗 0.10；服从/好感>80 时 0.02 | 主人指定「极大概率」 |
| 护院价 | `200 + 战力*60`；日薪 `30 + 战力*12` | 武力越强越贵（主人指定） |
| 监督失败 | 护院 hp×0.6，奴隶仍逃 | 打不过就是打不过 |
| 护院离职 | 欠薪 3 天 或 loyalty ≤20 | 养不起就走人 |
| 亡命徒掳人 | `((恶性−50)/300) × (夜0.15/昼0.05)` 每 30 分钟 | 夜里月黑风高 |
| 山贼卖人 | 玩家被打晕 60% 被卖，路人被打晕 30% | 主人指定 |

### 五、买奴的「知情同罪」

在青楼/黑市**公开买奴**本身合法（牙行有官媒），但：
- 在**青楼以外**的公开场合买妾被官差撞见 → `wanted += 2`
- **知情买入后转卖**（买来再卖）→ 按「转手贩子」论，`wanted += 3`

> 依据：清律「窝藏及买者知情的要与犯人同罪」+「公然为wadameof口买卖」从重。
