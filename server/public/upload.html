发布我的 Mod

两种方式：粘贴 mod.json，或选择打包好的 .zip。
（在游戏「MOD 制作器」里点「一键上传」会更省事，这里是没有游戏时的手动通道。）

ZIP 包怎么来？ ① 在游戏「MOD 管理器」里选中你的 Mod，点「导出 ZIP」；
② 或者自己把一个含 mod.json 的文件夹压成 zip（mod.json 在压缩包根目录或第一层子目录都行）；
③ 选好文件后，本站会自动从压缩包里读出 mod.json 并发布。
发布前请确认 ✓ id 全站唯一（重复会覆盖旧版本）
✓ name 已填写
✓ 至少有一类内容（房间/人物/物品/武学/任务/规则）
✓ category 在允许列表内
