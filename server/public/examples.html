各种类型的 Mod 示例

下面是每一类 Mod 的最小可用示例，都带详细注释。直接复制 JSON，或下载成 .json 文件。

怎么用这些示例

三条路，任选：

  1. 游戏里改：打开「MOD 制作器」，在「⚙ 源码视图」把示例 JSON 粘进去，点「从源码导入到表单」，然后随便改改、保存。
  2. 网页发布：点示例卡片上的「拿去发布」，会跳到上传页并自动填好内容，改个 ID 和名字就能发。
  3. 本地安装：下载 .json 后放进 mods/你的ID/mod.json，或改后缀为 .zip 从管理器安装。

想改游戏原有的东西？

写一个同 ID 的条目，只填你要改的字段就行，其余自动保留。
比如想把「江南集市」的描述改掉：

{
  "id": "my_tweak",
  "name": "集市修缮",
  "category": "美化",
  "rooms": [
    { "id": "jiangnan_market", "desc": "集市比往日更热闹了，新添了不少摊子。" }
  ]
}
