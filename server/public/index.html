📖 三步上手

① 玩游戏

下载《武侠行》游戏本体，运行起来。在「MOD 管理器」里点「在线 Mod 市场」，一键下载安装别人做的 Mod。

② 做 Mod ⭐

游戏里打开「MOD 制作器」，填表格就能造地图、NPC、武学、任务。全程不用写一行代码。

看完整教程 →

③ 发作品

做完点「一键上传到 Mod 网站」，你的作品就出现在这里了。别人也能一键下载。

网页版上传 →

🧭 支持哪些类型的 Mod

📜 剧情 Mod

新增门派恩怨、奇遇支线、多结局。用「剧情任务 + 对话树」搭出完整故事线。

🗺 地图 Mod

加城镇、秘境、洞天。房间互联成网，区域自动归组到大地图上。

⚙ 功能 Mod

改规则：双倍经验、自动拾取、修改战斗公式、加全局事件钩子。

🥋 功法 Mod

自创武学，配毒、定身、吸血、连击等招式效果，指定学习门槛。

⚔ 物品 Mod

兵器防具丹药秘籍。支持属性加成、使用效果、堆叠、任务物品。

🏯 门派 Mod

自立门户，设职位阶梯、门派武学传承、加入条件。
