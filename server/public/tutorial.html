小白也能做 Mod

不用写代码，用游戏内置的「MOD 制作器」填表格就行。这份教程带你把第一个 Mod 做出来、发出去。

0. 准备工作：三种玩法，随便挑

先决定你怎么「开始游戏」

《武侠行》有三种进入方式，想做 Mod 的话，推荐用第 1 或第 2 种：

方式怎么进适合谁Mod 能存哪
① 网页版
最省事		 点本站顶栏的 「▶ 开始游戏」，或直接开游戏网址。电脑、手机都能玩，不用装东西。 想马上玩、想在手机上玩 存档在浏览器里；Mod 可存进你授权的本地文件夹
② 网页直接改
不用装任何东西		 点本站顶栏的 「▶ 开始游戏」进游戏，左下角「☰ 菜单 → MOD 制作器」里就能建 Mod。
做好的文件存在浏览器里，也能导出成 zip 存到本机。		 想马上改、想在手机上改 游戏内的 MOD 制作器面板
③ 本地开发模式
改了立刻看效果		 有源码的话，运行 node server/combined.js，浏览器开 http://127.0.0.1:8800。

💡 网页版和离线版是同一个游戏，Mod 格式、玩法完全一样。 唯一区别：网页版的存档存在浏览器里（换浏览器或清缓存会丢），离线版存在硬盘上更稳。
📁
在网页版里，Mod 存哪儿？—— 授权一个本地文件夹

浏览器不让网页随便往硬盘写文件，所以要先手动授权一次。授权之后，你在本站下载的 Mod 就直接进那个文件夹，跟存存档一样。

  1. 回到首页，找到 「📁 本地 Mod 文件夹」卡片
  2. 点 「选择 Mod 文件夹」，挑一个文件夹（建议新建一个，比如 D:\wuxia-mods）
  3. 浏览器会弹一个确认框，点「允许编辑」/「保存更改」
  4. 搞定 ✅ 之后在本站下载任何 Mod，都会直接写进这个文件夹
⚠ 用的是 Chrome 或 Edge 吗？这个功能只在它们上有效。用 Safari / Firefox 的话， 下载会照常存到你的「下载」文件夹，手动挪进 mods/ 一样能用。

想让网页版用上这些 Mod，进游戏后打开 「MOD 管理器」→ 点「加载本地 Mod 文件夹」， 选同一个文件夹，里面的 Mod 就会被装进游戏（只在本机生效，不会被上传）。

1. 起个名字

1
打开制作器 →「① 基本信息」

游戏主界面左侧「MOD 制作器」，或主菜单直接进。

只需要填两个必填项：

  • Mod 名称：玩家看到的名字。比如「江南奇遇记」。
  • Mod 标识 ID：英文小写+下划线，全站唯一。比如 jiangnan_story。用拼音最省事。
💡 ID 就像身份证号。传过之后不要再改，否则网站会当成两个不同的 Mod。

2. 造一间房子

2
「② 地图房间」→ 新建房间
  • 房间名称：游戏里显示的大字，如「听雨小筑」。
  • 房间 ID：英文唯一，如 tianyu_xiaozhu。
  • 房间描述：这里的风景。越有画面感越好，支持换行。
  • 出口：填「目标房间的 ID」。第一次做可以先不填，进游戏看看再说。

怎么把新房间接到游戏原有地图上？在出口输入框里点一下，会有下拉提示，列出所有已有房间 ID，比如 jiangnan_street、road_jiangnan_1。填进去就通了。

⚠ 记住：连接是双向的。A 有出口通到 B，B 也要有出口通回 A，不然会走成死胡同。

3. 放一个人物

3
「④ 人物 NPC」→ 新建人物
  • 姓名 / ID：「白发渔翁」/ fisher_old。
  • 所在房间：下拉选你刚建的房间。
  • 气血 / 攻击：新手村的 NPC 建议气血 60~150、攻击个位数起步（引擎没有等级字段，强度看气血与攻击）。
  • 打招呼：玩家输入 talk 白发渔翁 时他说的话，每行一句。

勾选「可请教武学」，玩家就能 learn 白发渔翁 学武功；勾「是商人」，就能 list 看货 buy 买东西。

4. 加一件物品

4
「⑤ 物品装备」→ 新建物品
  • 名称 / ID：「九转还魂丹」/ jiuzhuan_dan。
  • 类型：丹药选「消耗品」，兵器选「武器」并填「装备部位 = 武器」，秘籍选「书籍」。
  • 使用效果：填 +hp:200 就是回血 200；填 learn:basic_sword 就是学会基础剑法。
  • 属性加成：武器铠甲填攻击 / 防御 / 气血加成，装备上就生效。

5. 写一段剧情（进阶但很值）

5
「⑧ 剧情任务」+「⑨ 对话树」

任务由若干「阶段」组成，玩家完成一个自动进下一个，最后发奖励。阶段达成类型有五种：

类型目标关键词填什么什么时候算完成
对话/标记 flag标记名，如 q_demo_start触发了这个标记
收集物品 item物品 ID，如 jinchuang_yao身上有够数量
击杀目标 killNPC ID，如 mob_bandit_chief杀够数量
到达地点 room房间 ID走进这个房间
变量达成 var变量名变量达到数值

对话树是一串「节点」。每个节点有 ID、说话人和台词，还有若干「选项」，每个选项指向下一个节点，或者执行一个效果。

选项格式（每行一个）：
我愿往 -> n2　（进入节点 n2）
（开战） -> kill　（触发战斗效果）
收下酬金 -> +money:200

把对话里的选项效果写成 quest:你的任务ID:2，玩家点了就直接把任务推进到第 2 阶段。

6. 检查 → 保存 → 发布

6
三步收尾
  1. 点右上角 检 查。它会检查房间出口、武学类型、物品名称、NPC 所在房间、书籍指向的武学、任务阶段等，把问题全列在「✔ 检查报告」页。
  2. 点 保存到本地。Mod 会写进游戏目录 mods/你的ID/，去「MOD 管理器」启用并「重载全部」就能在游戏里玩到。
  3. 点 一键上传到 Mod 网站。第一次要先登录（右上角「登录」，两秒注册一个昵称 + 口令）， 之后填一句更新说明，上传完成会给你一个网页地址 —— 你的作品就公开了。
    发过的作品都收在左边 「📦 我制作的 Mod」里，随时点「载入编辑」把它读回表单改一版再发。
💡 想改游戏里已有的东西（某个人物、某门武学、某个房间、某段剧情）？去左边 「🎭 游戏内 ID」：按类别列出游戏里当前全部有 ID 的事物，点「改这个」把它现在的样子载进表单， 改完保存/上传就是同 ID 覆盖。不用从零造，也不用会写代码。
在「⚙ 源码视图」还能看到编译出来的 mod.json，可以下载留档，也可以直接复制到网页版上传页去发布。
如果你用的是网页版（没装离线包），就跳过第 2 步，直接去 上传页粘贴 JSON 发布。

7. 把你做的 Mod 装到游戏里

做完的 Mod 有三条路进游戏，看你用哪种方式玩游戏：

你在用怎么装
网页版 把 Mod 存进你授权的本地文件夹（见第 0 节），然后游戏里「MOD 管理器」→ 「加载本地 Mod 文件夹」 → 选那个文件夹。
也可以通过 Mod 市场点「下载」，直接写进文件夹。
本地离线版 「MOD 管理器」→ 「从文件安装」选 .zip，或 「从文件夹安装」选整个目录。
手动方式：把文件夹丢进游戏目录的 mods/ 下，重启游戏。
从本站下载别人的 在 Mod 市场或详情页点 「下载」：
· 授权过文件夹 → 直接存进去（提示「✔ 已存进文件夹」）
· 没授权 → 存到「下载」文件夹（提示「✔ 已下载」），手动挪进 mods/
🔒 「本地私有 Mod」不会被上传。从你本地文件夹加载进来的 Mod 会带上「本地」标签， 它们的「导出 ZIP」按钮是禁用的 —— 你机器上的东西不会莫名其妙跑到 Mod 站上。

效果语法速查

很多输入框（房间进入效果、对话选项、任务阶段完成效果、物品使用效果、NPC 打招呼）都能填「效果」。格式是 动作:参数，多个之间用空格或分号隔开。

写法含义
say:你好让 NPC / 环境说话
narrate:天色暗了下来旁白式叙述（斜体）
me:微微一笑动作描述
+hp:100 / -hp:50气血增减
+mp:50内力增加
+money:500给 500 文钱
+exp:200经验 +200
+pot:50潜能 +50（引擎已不用它；留给 Mod 自建经济，玩家面板不显示）
contrib:华山:50门派贡献 +50（数值可负，扣到 0 为止；走门派贡献台账）
+item:长剑:2获得 2 把长剑
-item:长剑:1拿走 1 把长剑
learn:basic_sword学会一门武学
+skill:basic_sword:10武学等级 +10
forgetskill:basic_fist遗忘一门武学
goto:room_id把玩家传送到某房间
spawn:mob_wolf当前房间刷出一个 NPC
despawn:mob_wolf移除一个 NPC
flag:got_letter打上剧情标记
unflag:got_letter清除标记
quest:q_xxx:2任务推进到第 2 阶段
questdone:q_xxx直接完成某任务
joinSect:huashan让玩家加入门派
+title:剑客给玩家一个称号

combatWith:mob_wolf与场上某个 NPC 开打（没刷出来会明说，不静默）
giveRandom:长剑:馒头:草鞋随机给一件（随机池用 : 分隔）
damage:50对玩家造成 50 点伤害
heal:100治疗 100 点
ending:结局名触发结局
sound:click播放音效
sleep:1000停顿 1 秒

弹选择框

menu:标题|选项A>效果;;选项B>效果

menu:要不要帮我?|要，我这就去>flag:help_yes;;算了吧>say:那你走吧

条件语法速查

条件用来判断「什么时候才触发」，写在「触发条件」「学习条件」「任务阶段条件」等处。

写法含义
level>=10等级 ≥ 10
realm>=2境界 ≥ 小有所成（0 不通武艺 / 1 初窥门径 / 2 小有所成 / 3 登堂入室 / 4 炉火纯青 / 5 登峰造极）
attr.悟性>=20悟性 ≥ 20
skill.basic_sword>=50基础剑法 ≥ 50 级
money>=1000身上钱 ≥ 1000 文
kills>=100杀敌数 ≥ 100
{"rep":"华山派",">=":50}在华山派的声望 ≥ 50（声望要带门派名，用对象写法）
hasitem:长剑身上有长剑（要两把写 hasitem:长剑:2）
flag:got_letter有某剧情标记
sect:华山派属于某门派
rank>=3门派职位 ≥ 3
chance:0.330% 概率通过
{"and":["level>=10","hasitem:长剑"]}同时满足（组合用 JSON 数组写法）
{"or":["sect:华山派","sect:武当派"]}满足其一
{"not":"got_letter"}取反

五种 Mod 类型，各自怎么做

📜 剧情 Mod

用「剧情任务」+「对话树」两页。先建任务写好阶段，再建对话，把选项效果写成 quest:任务ID:阶段号。

🗺 地图 Mod

用「地图房间」+「区域」。房间互联靠出口，两边都要连上。区域让地图自动归组、上色。

⚙ 功能 Mod

用「功能 Mod」页。调经验倍率就选「倍数调整」，目标填 exp，数值填 2。常用预设一键添加。

🥋 功法 Mod

用「武学功法」页。类型选对（拳/剑/刀/内功/轻功），威力倍率 1.5 以上算强，配一两个「招式效果」。

⚔ 物品 Mod

用「物品装备」页。武器记得选部位「武器」并填攻击加成；丹药填「使用效果」；秘籍用 learn:武学ID。

进阶：手写 mod.json

制作器最终产出的是一个 mod.json。熟悉之后，你可以直接在网页版上传页粘贴 JSON 发布，也可以放进游戏目录 mods/你的ID/mod.json。

最小可用的 mod.json 长这样：

{
  "id": "my_first_mod",
  "name": "我的第一个 Mod",
  "version": "1.0.0",
  "author": "你的名字",
  "category": "地图",
  "desc": "在江南边上加了一个小院子。",
  "rooms": [
    {
      "id": "my_yard",
      "name": "我的小院",
      "region": "jiangnan",
      "desc": "院里一棵老槐树，树下有张石桌。",
      "exits": { "s": "jiangnan_street" }
    }
  ],
  "npcs": [
    {
      "id": "my_cat",
      "name": "黄猫",
      "room": "my_yard",
      "level": 1,
      "hp": 20,
      "desc": "一只肥硕的黄猫，正眯着眼晒太阳。",
      "talk": ["喵。"]
    }
  ]
}
增量覆盖：想改游戏原有内容，就写一个同 ID 的房间 / 物品，只填要改的字段。
比如想把「江南集市」的描述改掉，就写 {"id":"jiangnan_market","desc":"新描述"}，其他字段原样保留。
加载顺序：多个 Mod 改了同一个 ID 时，在「MOD 管理器」里越靠下的越晚加载，覆盖力越强。

常见问题

Q：手机上能玩吗？能，但操作习惯不太一样

直接用手机浏览器打开游戏网址就行，界面会自动适配。手机上更适合看剧情、跑任务； 要精细打指令的话，还是键鼠更顺。存档存在手机浏览器里，换设备不通用。

Q：「选择 Mod 文件夹」点了没反应 / 按钮不出现？

说明你的浏览器不开放「文件夹授权」这项能力。手机浏览器一律不行（不是你的手机坏了）， 电脑上也要 Chrome 或 Edge 才有。
不影响玩：Mod 站下的 Mod 会走普通下载，存进「下载」文件夹； 要装进游戏就在「MOD 管理器」里点 「从文件安装」（或「加载本地 Mod 文件夹」， 不支持时会自动改成选文件的界面），挑那个 .zip 就行。 电脑上想省事、让下载直接落进固定文件夹，再用 Chrome / Edge 授权。

Q：在网页版做的 Mod，怎么让游戏用上？

把 Mod 存进授权的本地文件夹（或从 Mod 市场下载进那个文件夹）， 然后游戏里「MOD 管理器」→ 「加载本地 Mod 文件夹」 → 选同一个文件夹。 加载进来的 Mod 会带「本地」标签，只在本机生效。

Q：房间建好了，进游戏找不到？

多半是没连接。在某个已有房间的出口里填你的房间 ID，或者把你的房间出口指向 jiangnan_street 之类的原有房间。检查报告会提示孤立房间。

Q：NPC 不出现？

检查「所在房间」是否选了、且那个房间 ID 确实存在（拼写要一致）。

Q：上传失败连不上？

分两种情况：

  • 用网页版：Mod 站就是你现在这个站，上传直接就能通，不用配任何东西。
  • 在本地跑（自己开发时）：确认游戏与本站都起来了，且游戏「设置 → Mod 网站地址」填的地址和本站一致。
Q：多个 Mod 冲突？

同名 ID 后加载的覆盖前面的。在 Mod 管理器里拖动箭头调整顺序。管理器右下角会列出检测到的冲突。

Q：能写代码吗？

可以，但入口要认对：自定义的条件/效果写进 mod.json 的声明式 functions 字段（条件体是表达式，不是任意 JS）；想写真正的逻辑脚本，在 mods/你的ID/ 里放 script.js——引擎在沙箱里执行它，能用的是 wx 对象暴露的 25 个接口。沙箱里没有 registerCond / registerEffect 这类注册函数——教程早期说的「script.js 注册自定义条件/效果」口径有误， 以本条为准。沙箱能防「脚本写挂拖垮游戏」，但它是软隔离（同进程），不防蓄意攻击。

Q：怎么确认我的 Mod 真的装上了？

看游戏内的 Mod 日志（加载报错都会写进去），或者规则/脚本有没有实际生效。 别拿引擎里的 world.mods 当「已装清单」——它只收 mod.json 里带 _mod 声明的 Mod，没声明的装上了它也是空的。判断装没装上，看 world.activeRules（规则数）和 world._scripts（脚本实例）更可靠。

Q：倍数规则为什么不生效？

检查字段名：multiply 规则的倍数字段是 value，写成 mult 引擎不认（加载时 Mod 日志会报「字段名疑似 mult」）。
