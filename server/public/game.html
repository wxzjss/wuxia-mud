什么都不用装 ✅

自带运行环境

下载包里已经带了一个 Node.js（放在 runtime\ 文件夹）。解压后双击 start.bat 直接就能玩，不需要你去装任何东西。

为什么以前会报错？

旧版的包只带代码不带引擎，脚本会去系统里找 Node.js，找不到就提示「没有找到 Node.js」。现在这个问题已经修好，包里自带。

完全离线

这个项目零依赖，没有 node_modules，不需要 npm install，玩的时候也不联网。

想手动启动？也可以

在解压出来的 jinyong-mud 目录里打开终端： 

双击 start.bat          → 同时启动游戏(8787) + Mod 站(8788)，并自动开浏览器
双击 start-standalone.bat → 游戏和 Mod 站合并到一个端口(8800)，只开一个窗口

或者手动敲（用包里自带的 Node）：
runtime\node.exe server/game-server.js     只启动游戏      → http://127.0.0.1:8787
runtime\node.exe server/mod-site.js        只启动 Mod 站   → http://127.0.0.1:8788
runtime\node.exe server/combined.js        合并单端口      → http://127.0.0.1:8800

如果你电脑上本来就装了 Node.js，把上面的 runtime\node.exe 换成 node 也一样能跑。

常见问题

窗口一闪就没了 / start.bat 打不开？

先看解压出来的文件夹里有没有 runtime\node.exe。有的话脚本会自动用它，不会报「没有找到 Node.js」。如果没有这个文件，说明压缩包没解压完整（有些解压软件会漏掉大文件），换 7-Zip / Bandizip 重新解压一次即可；实在不行再自行安装 Node.js。

端口被占用？

游戏默认 8787、Mod 站默认 8788。换端口：node server/game-server.js 8887。换完后记得在游戏「设置」里同步 Mod 站地址。

Mod 装了没生效？

先确认管理器里开关是打开的，再点「重载全部」。有冲突的话，管理器右下角会列出来。

存档在哪？会不会丢？

在 saves/ 目录，纯文本 JSON。复制文件就能备份或搬到别的机器。下载时也可以勾选「连同存档一起打包」。

目录结构

jinyong-mud/
├── start.bat              双击启动（游戏 + Mod 站）
├── start-standalone.bat   双击启动（合并单端口）
├── runtime/
│   └── node.exe           自带的 Node.js —— 所以不用另外装
├── game/
│   ├── data/              游戏世界数据（全是内容 JSON）
│   ├── src/core/          引擎：世界 / 角色 / 战斗 / 指令 / Mod API / ZIP
│   └── src/renderer/      前端界面（HTML / CSS / JS）
├── server/
│   ├── game-server.js     游戏服务（8787）
│   ├── mod-site.js        Mod 网站服务（8788）
│   ├── combined.js        合并服务（8800，单端口）
│   ├── public/            网站页面
│   └── site-data/         你上传的 Mod 存这里
├── mods/                  已安装的 Mod（每个一个文件夹）
├── saves/                 存档（纯 JSON，可自由备份）
└── tools/                 测试脚本
